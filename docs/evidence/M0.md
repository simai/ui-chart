## Framework parts needed (ordered from the dispatcher)

1. Categorical colour roles `--sf-chart-1..8` and the diverging midpoint. They
   are already ordered. Until they land, series use the primary, secondary,
   tertiary and neutral graphic tones plus dashes.
2. A public-api-axes exemption for `chart-line.data-state`, whose `error`
   value is a data state, not a validation axis. The package test carries it
   as pending. The same exemption is needed for every chart.
3. First-paint serializer: drop comment nodes inside SVG and foreign
   subtrees. The package works around this by setting the plot's markup as a
   property.
4. Linkage:
   - a derived Smart passport hardcodes owner `simai/ui-source`, so it needs a
     package owner;
   - `linkage.mjs` needs package support (the package runs its own
     `passports.mjs`).
5. The ui distr ships the larena package rule as `smart/rule.js`. It collides
   with any package's rule. The probe runners drop it.
6. `playwright` is not resolvable from the overlay runtime. The browser
   probes link it in.
7. A package reference `contracts/packages/chart.package.json` in the release,
   so the receipt can check the rules.
8. Vocabulary: the `select` event carries `{series, index, x, value}`, which
   deviates from the vocabulary's shape. This is recorded in the manifest's
   `x-decisions`.
