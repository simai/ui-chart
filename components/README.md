# Components

The Smart chart components live in `src/smart/<name>/`, one folder per
component, laid out like `simai/ui-pro/components/src/smart/` (manifest,
`js/`, templates, passport). The package build, overlay, tests and browser
probes follow `simai/ui-pro/components/` and are set up in M0 (see
`../docs/START.md`).

Nothing is here yet: the research stage comes first.
