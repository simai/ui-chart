# Smart Line Chart

`<sf-chart-line>` — линейный график: один или несколько рядов по времени, по
числу или по категориям. Оси, сетка, легенда, которая скрывает ряды, подсказка
под указателем, курсор с клавиатуры, описание словами и те же данные таблицей.

## Данные

`items` — свойство: список записей или объект столбцов. Поля называют атрибуты:

- `x` — поле по горизонтали (по умолчанию первое);
- `y` — поле значений или список через запятую, один ряд на поле;
- `series` — длинная форма: один ряд на каждое значение этого поля.

Пропущенное значение (`null`, пустая строка, слово) — разрыв линии, а не ноль.
`gaps="connect"` соединяет точки вокруг разрыва. `names` — свойство
`{ключ: «Название»}` для подписей рядов.

```html
<sf-chart-line id="sales" label="Продажи и план, 2026" x="month" y="sales,plan" y-format="integer"></sf-chart-line>
<script>
  sales.names = {sales: 'Продажи', plan: 'План'};
  sales.items = [
    {month: '2026-01', sales: 120, plan: 125},
    {month: '2026-02', sales: 132, plan: 130},
  ];
</script>
```

## Оси и вид

- `x-scale`: `auto` (даты — время, числа — числовая ось, остальное —
  категории), `time`, `linear`, `category`.
- `y-min`, `y-max`, `y-zero` — границы оси значений; `y-zero` включает ноль.
- `x-label`, `y-label` — названия осей; `x-format`, `y-format` — формат
  (`number`, `integer`, `decimal-2`, `percent`, `compact`, `currency-RUB`; для
  времени `auto`, `short`, `medium`, `long`, `full`). Числа и даты — на языке
  страницы.
- `curve`: `linear`, `step`, `smooth` (кривая не выходит за точки).
- `area` — заливка под линией; `markers`: `auto`, `always`, `none`.
- `grid`: `y`, `x`, `both`, `none`; `legend`: `auto`, `top`, `bottom`, `none`.
- `size`: `1/2`, `1`, `2` — высота графика, текст и отступы.

## Стопка

`stack` складывает ряды слоями:

- `none` (по умолчанию) — каждая линия по своим значениям;
- `stacked` — ряды лежат друг на друге: линия — верх своего слоя, заливка —
  полоса до слоя под ним; положительные значения растут вверх от нуля,
  отрицательные — вниз;
- `normalized` — в каждой точке слои составляют 100 %, ось подписана
  процентами, подсказка и курсор говорят долю и само значение: «Сайт: 50 %
  (42)».

Слой в стопке залит всегда, `area` для него не нужен. Пропуск остаётся
разрывом своего слоя и ничего не добавляет к стопке: слои над ним в этой
точке опускаются. Скрытый в легенде ряд выходит из стопки, остальные
складываются заново. Описание графика добавляет, что ряды сложены.

```html
<sf-chart-line id="channels" label="Доля каналов" x="month" y="web,shop,partners" stack="normalized"></sf-chart-line>
```

## Цвета

`colors` — свойство, свой цвет ряда: объект «ключ ряда → цвет». Цвет — роль Framework
(`primary`, `secondary`, `tertiary`, `neutral`, `success`, `warning`, `error`, `info`): берётся её графический тон, и он сам меняется со светлой и тёмной
темой. Запасной путь — любой CSS-цвет или переменная (`#0a7f6f`,
`var(--brand)`).

```html
<sf-chart-line id="sales" label="Продажи и план" x="month" y="sales,plan"></sf-chart-line>
<script>
  sales.colors = {sales: 'primary', plan: 'neutral'};
</script>
```

- Без цвета ряд берёт цвет палитры по своему месту, как раньше.
- Цвет держится за ключ, а не за порядок: переставили данные — цвета остались.
  Сервер может напечатать его в JSON-блоке `data-sf-settings`, как `items`.
  Один и тот же `colors` на нескольких графиках страницы красит одну категорию
  одинаково.
- Не цвет (опечатка, текст) отбрасывается с сообщением в консоли. Цвет с
  контрастом ниже 3:1 к фону графика рисуется, но консоль предупреждает.
- В режиме высокой контрастности цвета заменяет система; ряды различаются
  штрихом и формой.

**Готовые наборы.** `palette` — набор цветов по порядку рядов: каждый цвет —
пара для светлой и тёмной темы, контраст не ниже 3:1 к фонам 0–2 в обеих.

| `palette` | Цветов | Для чего |
|---|---|---|
| `theme` (по умолчанию) | 4 | тона темы, как раньше |
| `vivid` | 8 | разноцветный, первый — цвет бренда; первые пять различимы и при дальтонизме |
| `soft` | 8 | приглушённый |
| `warm` | 6 | тёплые тона |
| `cool` | 6 | холодные тона |
| `brand` | 4 | ступени основного цвета темы, для упорядоченных данных |

Когда рядов больше, чем цветов в наборе, набор начинается сначала.
`colors` сильнее набора для тех рядов, которые называет.

```html
<sf-chart-line palette="vivid" …></sf-chart-line>
```

## Доступность

График — `figure` с названием из `label`. Область графика — одна остановка
Tab (`role="group"`, «график»), описанная фразой о данных: диапазон, первое и
последнее значение каждого ряда, наибольшее и наименьшее. Свои слова хост
кладёт в слот `description`.

Клавиши на графике: ← → — по точкам, ↑ ↓ — по рядам, Home и End — к краям,
Page Up и Page Down — на десятую часть (больше 200 точек — шаг сотая часть).
Каждый шаг объявляется вежливо. Enter и Пробел выбирают точку, Esc убирает
курсор.

`table`: `toggle` (по умолчанию) — кнопка «Таблица» показывает те же данные
таблицей; `visible` — таблица под графиком; `hidden` — таблица только для
чтения с экрана. Варианта «без таблицы» нет.
Когда данные идут потоком, таблица обновляется не чаще раза в секунду и всегда догоняет последние данные; первые данные и редкие изменения видны в ней сразу.

Цвет — не единственное различие: в режиме высокой контрастности у каждого ряда
свой пунктир. Анимация выключена при `prefers-reduced-motion`.

## Состояния

`data-state`: `auto` (данные есть — `ready`, нет — `empty`), `loading` —
рамка без линий, `empty`, `error` — с кнопкой «Повторить», которая отправляет
`sf-chart-line-refresh`.

## События и действия

- `sf-chart-line-toggle {id, hidden}` — человек скрыл или показал ряд в легенде;
  значение `hiddenSeries` хранит скрытые.
- `sf-chart-line-select {series, index, x, value}` — выбрана точка.
- `sf-chart-line-refresh` — просьба загрузить данные заново.
- `reset()` — показать все ряды и убрать курсор.

## Много точек

Больше двух точек на столбец пикселей линия рисуется по первой, наименьшей,
наибольшей и последней точке столбца (`decimate="auto"`): 10 000 точек
выглядят как четыреста, пики остаются.

## Публичные переменные

`--sf-chart-line-height`, `--sf-chart-line-grid-color`,
`--sf-chart-line-baseline-color`, `--sf-chart-line-label-color`,
`--sf-chart-line-hover-background-color`, `--sf-chart-line-hidden-color`,
`--sf-chart-line-line-width`.

Цвета рядов пока берутся из графических тонов primary, secondary, tertiary и
neutral; роли `--sf-chart-1..8` заказаны у Framework.
