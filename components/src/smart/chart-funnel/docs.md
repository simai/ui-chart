# Smart Funnel

`<sf-chart-funnel>` — воронка: этапы процесса, где каждый следующий — часть
предыдущего. Подходит для воронки продаж, регистрации, пути заказа. Каждый
этап — строка: название, полоса, значение и доля перехода. Есть подсказка,
курсор с клавиатуры, описание словами и те же данные таблицей.

Полосы начинаются от одного края, поэтому их длины сравниваются точно. Форма
трапеции не используется: её скошенные края не несут данных.

## Данные

`items` — свойство: список записей, по одной на этап, в порядке процесса, или
объект столбцов.

- `stage` — поле этапов (по умолчанию первое);
- `value` — поле значений (по умолчанию первое числовое после него);
- `names` — свойство `{ключ: «Название»}` для этапов.

Этапы идут в том порядке, в каком даны: порядок — это сам процесс, воронка
его не сортирует. Этап без значения — пропуск: строка с пунктирной рамкой, без
полосы; доля перехода через пропуск не считается. Этап больше предыдущего
рисуется как есть (доля больше 100 %), а описание говорит, что этапы не
вложены.

```html
<sf-chart-funnel id="order" label="Воронка заказа" stage="step" value="people" value-format="integer"></sf-chart-funnel>
<script>
  order.names = {visit: 'Визиты', cart: 'Корзина', paid: 'Оплата'};
  order.items = [{step: 'visit', people: 12400}, {step: 'cart', people: 2900}, {step: 'paid', people: 860}];
</script>
```

## Вид

- `conversion` — какая доля пишется рядом с этапом: `previous` (по
  умолчанию) — от предыдущего этапа, сколько прошли дальше; `first` — от
  первого, сколько осталось от начала; `none` — только значения. Подсказка,
  описание и таблица всегда говорят обе доли.
- `align` — `start` (по умолчанию): полосы от одного края; `center`: по
  центру, привычная форма воронки — для картинки больше, чем для сравнения.
- `color` — цвет полос: роль Фреймворка (`primary`, `tertiary`, `success` …)
  или любой цвет CSS. Воронка — одна величина, поэтому цвет один на все этапы.
- `size` — высота строки 20, 28 или 36 px и размер текста. Высота воронки —
  это её строки, она известна до первой отрисовки.
- На узком месте (уже 30rem) название этапа стоит над полосой.
- Длинные названия обрезаются с «…».

## Клавиатура и доступность

Этапы — одна остановка Tab, группа с описанием «воронка».

- Вниз и вправо — к следующему этапу, вверх и влево — к предыдущему.
- Home и End — к первому и последнему этапу.
- Каждый шаг говорится вежливо: «Каталог: 7 800, 62,9 % от предыдущего,
  62,9 % от первого».
- Enter и Пробел выбирают этап (`select`), Escape убирает курсор.

Описание говорит число этапов, от какого значения к какому, итоговую
конверсию, где теряется больше всего и сколько пропусков. Таблица: этап,
значение, доля от предыдущего, доля от первого. В режиме высокой
контрастности полосы сплошные, текущая — системным цветом выделения.

## События

- `sf-chart-funnel-select` — `{series, index, x, value}`: поле значений,
  место этапа, его ключ, как в данных, и значение (`null` для пропуска).
- `sf-chart-funnel-refresh` — из состояния ошибки нажали «Повторить».

## Состояния

`data-state`: `auto` (готово с данными, пусто без них), `loading`, `ready`,
`empty`, `error`.

## Переменные CSS

`--sf-chart-funnel-color`, `--sf-chart-funnel-label-color`,
`--sf-chart-funnel-bar-radius`.
