# Smart Pie Chart

`<sf-pie-chart>` — круговая диаграмма: части одного целого секторами круга или
кольца с суммой в середине. Доли внутри секторов, легенда с долями, которая
скрывает части, подсказка, курсор с клавиатуры, описание словами и те же данные
таблицей.

## Данные

`items` — свойство: список записей или объект столбцов, одна часть на запись.

- `category` — поле названий частей (по умолчанию первое);
- `value` — поле значений (по умолчанию первое числовое);
- `names` — свойство `{категория: «Название»}`.

Сектор бывает только у положительного значения. Ноль, отрицательное число и
пропуск остаются строками таблицы.

```html
<sf-pie-chart id="orders" label="Заказы по каналам, октябрь" category="channel" value="orders" value-format="integer"></sf-pie-chart>
<script>
  orders.names = {web: 'Сайт', shop: 'Магазин'};
  orders.items = [{channel: 'web', orders: 540}, {channel: 'shop', orders: 310}];
</script>
```

## Вид

- `hole="ring"` — кольцо; `total="auto"` пишет в середине сумму видимых частей.
- `max-parts` (по умолчанию 7): сверх этого числа самые маленькие части
  сводятся в «Другое». Таблица сохраняет все строки. Когда данные идут потоком, таблица обновляется не чаще раза в секунду и всегда догоняет последние данные; первые данные и редкие изменения видны в ней сразу.
- `share-labels="inside"` — доля внутри сектора, где она помещается.
- `legend="visible"`: части с долями стоят справа от круга, когда диаграмма
  широкая (от 30rem), и под ним, когда узкая. Решает CSS, поэтому первая
  отрисовка не сдвигается.
- `value-format`, `size`, `table`, `summary` — как у `sf-bar-chart`.

## Клавиатура и доступность

Диаграмма — одна остановка Tab. Стрелки вправо и вниз идут к следующей части по
часовой стрелке, влево и вверх — назад, Home и End — к первой и последней. Шаг
звучит: «Сайт: 54 % (540)». Enter и пробел выбирают часть, Escape убирает курсор.

Фраза о данных: «Частей: 4, всего 1 000. Сайт: 54 % (540). …», по убыванию.

## События, действия и значения

- `sf-pie-chart-toggle` `{id, hidden}` — часть скрыта или показана кнопкой
  легенды. `hiddenParts` — категории скрытых частей (для «Другое» — `other`);
  доли остальных считаются от оставшегося.
- `sf-pie-chart-select` `{series, index, x, value}`: `x` — категория, `index` —
  строка данных (у «Другое» — −1).
- `sf-pie-chart-refresh` — повтор из состояния ошибки.
- `reset()` — показать все части.

## Переменные CSS

`--sf-pie-chart-height`, `--sf-pie-chart-label-color`,
`--sf-pie-chart-hover-background-color`, `--sf-pie-chart-hidden-color`,
`--sf-pie-chart-gap-width`.
