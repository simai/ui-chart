# Smart Parts Bar

`<sf-chart-parts>` — полоса частей: части одного целого одной тонкой полосой. Если
задана ёмкость, в конце полосы — свободный остаток. Подходит для диска, квоты,
контекста модели, бюджета по статьям. Под полосой список «название — значение —
доля», над ней — сколько занято. Есть подсказка, курсор с клавиатуры, описание
словами и те же данные таблицей.

## Данные

`items` — свойство: список записей или объект столбцов, одна часть на запись.

- `category` — поле названий частей (по умолчанию первое);
- `value` — поле значений (по умолчанию первое числовое);
- `names` — свойство `{категория: «Название»}`.

Частью полосы бывает только положительное значение. Ноль, отрицательное число и
пропуск остаются строками таблицы.

```html
<sf-chart-parts id="disk" label="Диск" category="kind" value="size" max="100" value-format="integer"></sf-chart-parts>
<script>
  disk.names = {system: 'Система', apps: 'Приложения'};
  disk.items = [{kind: 'system', size: 22}, {kind: 'apps', size: 13}];
</script>
```

## Ёмкость

- `max` — ёмкость. Полоса — вся ёмкость, а то, что осталось от частей, —
  последняя часть полосы, «Свободно» (`free-label` меняет название). Доли
  считаются от ёмкости. Над полосой: «45 из 100 (45 %)».
- Без `max` полоса — сумма частей, остатка нет, над полосой: «всего 1 000».
- Если части больше ёмкости, полоса заполнена целиком, доли считаются от суммы,
  а описание говорит: «Занято 45 из 40: больше на 5».

## Вид

- `legend="list"` (по умолчанию) — под полосой строка на часть: название,
  значение, доля; остаток последним. `inline` — названия с долями в одну
  переносимую строку, для плитки. `none` — только полоса.
- `max-parts` (по умолчанию 7): сверх этого числа самые маленькие части
  сводятся в «Другое». Таблица сохраняет все строки. Когда данные идут потоком,
  таблица обновляется не чаще раза в секунду и всегда догоняет последние данные;
  первые данные и редкие изменения видны в ней сразу.
- `total="none"` убирает «45 из 100» рядом с названием.
- `size`: `1/2` — тонкая полоса и мелкий текст для плитки, `2` — для отдельной
  страницы. Полоса рисуется без замера ширины, поэтому первая отрисовка — уже
  готовая полоса.
- `value-format`, `table`, `summary` — как у `sf-chart-pie`. В плитке удобно
  `table="hidden"`: таблица остаётся для экранных чтецов, кнопки нет.

## Цвета

`colors` — свойство, свой цвет части: объект «категория → цвет». Цвет — роль Framework
(`primary`, `secondary`, `tertiary`, `neutral`, `success`, `warning`, `error`, `info`): берётся её графический тон, и он сам меняется со светлой и тёмной
темой. Запасной путь — любой CSS-цвет или переменная (`#0a7f6f`,
`var(--brand)`).

```html
<sf-chart-parts id="disk" label="Диск" category="kind" value="size" max="100"></sf-chart-parts>
<script>
  disk.colors = {system: 'neutral', apps: 'primary'};
</script>
```

Свободный остаток красится своей переменной `--sf-chart-parts-free-color`.

- Без цвета часть (и «Другое») берёт цвет палитры по своему месту, как раньше.
- Цвет держится за ключ, а не за порядок: переставили данные — цвета остались.
  Сервер может напечатать его в JSON-блоке `data-sf-settings`, как `items`.
  Один и тот же `colors` на нескольких графиках страницы красит одну категорию
  одинаково.
- Не цвет (опечатка, текст) отбрасывается с сообщением в консоли. Цвет с
  контрастом ниже 3:1 к фону графика рисуется, но консоль предупреждает.
- В режиме высокой контрастности цвета заменяет система; ряды различаются
  штрихом и формой.

## Клавиатура и доступность

Полоса — одна остановка Tab. Стрелки вправо и вниз идут к следующей части по
ходу чтения (на странице справа налево вправо — значит назад), влево и вверх —
назад, Home и End — к первой и последней части, остаток тоже. Шаг звучит:
«Система: 22 (22 %)». Enter и пробел выбирают часть (остаток не выбирается),
Escape убирает курсор.

Фраза о данных: «Занято 45 из 100 (45 %). Система: 22 (22 %). … Свободно: 55
(55 %).», части по убыванию.

## События

- `sf-chart-parts-select` `{series, index, x, value}`: `x` — категория, `index` —
  строка данных (у «Другое» — −1).
- `sf-chart-parts-refresh` — повтор из состояния ошибки.

## Переменные CSS

`--sf-chart-parts-thickness`, `--sf-chart-parts-free-color`,
`--sf-chart-parts-label-color`, `--sf-chart-parts-gap-width`.
