# Smart Sparkline

`<sf-chart-sparkline>` — мини-график: один ряд линией, площадью или столбиками, без
осей. Ставится в ячейку таблицы, в строку текста или в слот `chart` плитки
`sf-chart-metric`.

## Данные

`items` — свойство: список чисел, список записей или объект столбцов.

- Для списка чисел порядок — порядок списка.
- Для записей `x` называет поле порядка (по умолчанию первое), `y` — поле значений
  (по умолчанию первое числовое).

Пропуск (`null`, пустая строка, слово) — разрыв, а не ноль.

```html
<sf-chart-sparkline id="visits" label="Посещения, 12 недель" y-format="integer"></sf-chart-sparkline>
<script>
  visits.items = [340, 362, 355, 401, 395, 410, 430, 452, 440, 461, 470, 488];
</script>
```

## Вид

- `shape` — `line` (по умолчанию), `area` (с заливкой) или `bar` (столбики от нуля).
- `curve` — `linear`, `step` или `smooth` (кривая не выходит за точки).
- `mark` — точка на последнем значении (`last`, по умолчанию), на наибольшем и
  наименьшем (`extremes`) или без точек (`none`).
- `y-zero` — шкала включает ноль; у `bar` всегда.
- `size` — высота по лестнице размеров: `1/2` (20 px, строка мелкого текста),
  `1` (32 px, строка таблицы), `2` (64 px, плитка показателя).
- Ширина — `--sf-chart-sparkline-width` (по умолчанию 128 px); в слоте плитки он
  растягивается по ширине.

## Цвет

`color` — цвет линии, заливки и столбиков. Роль Framework (`primary`, `secondary`, `tertiary`, `neutral`, `success`, `warning`, `error`, `info`) берёт
свой графический тон и меняется с темой; запасной путь — любой CSS-цвет или
переменная. Настройка сильнее переменной `--sf-chart-sparkline-color`. Не цвет
отбрасывается с сообщением в консоли; цвет с контрастом ниже 3:1 к фону
рисуется, но консоль предупреждает.

```html
<sf-chart-sparkline label="Оплаты" color="success"></sf-chart-sparkline>
```

## Доступность

Мини-график — изображение, а не элемент управления: у него нет места в порядке
Tab, подсказки и событий. Имя — подпись и фраза о данных:
«Посещения, 12 недель: от 340 до 488, наибольшее 488, наименьшее 340».
`summary="none"` оставляет одну подпись, когда текст рядом уже говорит это.
`y-format` задаёт, как числа звучат во фразе.

Если человеку нужны сами значения, это `sf-chart-line` с осями и таблицей.

## Состояния

- `data-state="auto"`: с данными — график, без них — пунктирная линия и «нет
  данных».
- `loading`: держит размер тихим блоком, ничего не сдвигается при приходе данных.
- Ошибку показывает окружение (таблица, `sf-chart-metric`).

## Переменные CSS

`--sf-chart-sparkline-width`, `--sf-chart-sparkline-height`, `--sf-chart-sparkline-color`,
`--sf-chart-sparkline-mark-color`, `--sf-chart-sparkline-line-width`.
