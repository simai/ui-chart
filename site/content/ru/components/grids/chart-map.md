# Карта по областям sf-chart-map

`<sf-chart-map>` — карта с заливкой по областям (хороплет): доля или
показатель на душу по регионам, районам, зонам. Каждая область окрашена
ступенью шкалы своего значения, рядом легенда ступеней. Подсказка, курсор с
клавиатуры, описание словами и все области таблицей.

Не подходит для количеств: большие области кажутся «больше». Поделите на
население или площадь, или возьмите `sf-chart-bar`.

## Границы даёт страница

В пакете нет ни одной карты. Границы областей передаёт сайт в свойстве
`shapes` в формате GeoJSON: `FeatureCollection` или список `Feature` с
геометрией `Polygon` или `MultiPolygon` (острова и дырки — озёра —
поддерживаются). За источник границ, их лицензию и спорные границы отвечает
сайт.

- Ключ области — `id` объекта, иначе `properties.id`; `shape-key` называет
  другое свойство.
- Название — `properties.name`; `shape-name` называет другое свойство.
- Объект без ключа или без многоугольника и повторный ключ пропускаются.

## Данные

`items` — свойство: список записей или объект столбцов, строка на область.

- `region` — поле ключа области, по умолчанию первое текстовое поле.
- `value` — поле значения, по умолчанию первое числовое поле.
- Строка, чей ключ не найден на карте, и строка без числа пропускаются;
  описание говорит, сколько строк без области. Область без значения
  рисуется пустой с пунктирным контуром и «нет данных» в легенде.

```html
<sf-chart-map id="jobs" label="Безработица по районам, %"
  region="district" value="rate" value-format="decimal-1"></sf-chart-map>
<script>
  jobs.shapes = districts; // GeoJSON, который даёт сайт
  jobs.items = [
    {district: 'Лесной', rate: 4.1},
    {district: 'Речной', rate: 6.4},
  ];
</script>
```

## Проекция

`projection` — как долгота и широта ложатся на плоскость, север сверху:

- `mercator` (по умолчанию) — сохраняет углы: город, небольшая страна;
- `albers` — сохраняет площади по двум параллелям карты: большая страна,
  например Россия;
- `equirectangular` — градусы как есть;
- `plane` — координаты как есть, y вниз: схема склада, план этажа.

Карта, пересекающая 180-й меридиан, остаётся целой. Карта вписывается в
график с сохранением пропорций.

## Цвета

Шкала та же, что у тепловой карты: ступени на тонах темы.

- `scale="sequential"` (по умолчанию) — от слабого к сильному в одном
  семействе цветов (`scheme`).
- `scale="diverging"` — два семейства от нейтральной середины (`middle`,
  по умолчанию 0) для изменений и отклонений; `better` — какая сторона
  хорошая.
- `steps` — число ступеней, 3–9; `min` и `max` — границы шкалы.
- `legend` — легенда сверху, снизу (по умолчанию) или без неё.

В режиме высокой контрастности области — контуры, значения — в таблице.

## Подписи

Название области пишется в её середине, если область достаточно высокая,
и обрезается по ширине. `labels="none"` убирает подписи.

## Клавиатура и доступность

График — одна остановка Tab. Вправо и влево — по областям в порядке
чтения (сверху вниз, слева направо), вверх и вниз — к ближайшей области
выше или ниже, Home и End — к первой и последней. Каждая область звучит:
«Речной: 6,4, место 1 из 8» или «Степной: нет данных». Enter и пробел
выбирают область (`sf-chart-map-select`), Escape убирает курсор.

Фраза о данных — сколько областей и сколько с данными, диапазон, больше и
меньше всего, области без данных, строки без области на карте. Таблица
всегда есть, строка на область по убыванию значения с местом.

## События и действия

- `sf-chart-map-select` `{index, region, name, value, rank}` — выбрана
  область; `index` — её место в `shapes`, `rank` — место по значению (0
  без значения).
- `sf-chart-map-refresh` — повтор из состояния ошибки.
- `reset()` — убрать курсор.

## Состояния

`data-state`: `auto` (с областями и значениями — карта, без — «Нет
данных»), `loading`, `empty`, `error` (с «Повторить»).

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `label` — `string`, по умолчанию пусто. Что показывает график, в нескольких словах: его доступное имя и подпись таблицы. На практике обязателен: без него график называется «График».
- `region` — `string`, по умолчанию пусто. Поле строк с ключом области; если не задано, берётся первое текстовое поле.
- `value` — `string`, по умолчанию пусто. Поле строк со значением; если не задано, берётся первое числовое поле, кроме поля области. Доля или отношение на карте читаются правильно; количество выгодно выделяет крупные области.
- `shape-key` — `string`, по умолчанию пусто. Свойство объекта (feature) с ключом области; если не задано, берётся id объекта, иначе properties.id.
- `shape-name` — `string`, по умолчанию пусто. Свойство объекта (feature) с названием области; если не задано, берётся name, иначе ключ.
- `projection` — `string`, по умолчанию `mercator`, значения: `mercator`, `albers`, `equirectangular`, `plane`. Как долгота и широта рисуются на плоскости, север вверху: mercator сохраняет углы (город, небольшая страна), albers сохраняет площади по двум параллелям карты (большая страна вроде России), equirectangular берёт градусы как есть, plane берёт координаты как есть, ось y вниз (план этажа, схема). Карта через 180-й меридиан остаётся целой.
- `scale` — `string`, по умолчанию `sequential`, значения: `sequential`, `diverging`. sequential: от слабого к сильному в одном семействе цвета, для количества или нагрузки. diverging: два семейства, встречающиеся в нейтральной середине, для изменения или отклонения от нормы.
- `scheme` — `string`, по умолчанию `primary`, значения: `primary`, `secondary`, `tertiary`, `neutral`, `success`, `warning`, `error`, `info`. Семейство цвета последовательной шкалы. Его тона — тона темы: самое сильное значение — самый тёмный тон в светлой теме и самый светлый в тёмной.
- `better` — `string`, по умолчанию `up`, значения: `up`, `down`, `none`. Какая сторона хороша на расходящейся шкале: up красит то, что выше середины, в success, а ниже — в error, down наоборот; none использует primary и tertiary, которые ничего не значат.
- `steps` — `number`, по умолчанию `5`. Сколько в шкале ступеней цвета, от 3 до 9; у расходящейся шкалы число нечётное, чтобы была средняя ступень. Ступени читаются увереннее, чем плавный переход.
- `middle` — `number`, по умолчанию `0`. Середина расходящейся шкалы: норма, план, ноль для изменения. Шкала идёт от неё в обе стороны на одинаковое расстояние.
- `min` — `number`. Низ шкалы; если не задан, берётся минимум данных.
- `max` — `number`. Верх шкалы; если не задан, берётся максимум данных.
- `labels` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto пишет название области в её середине, обрезая многоточием по ширине, если область выше полутора строк; название маленькой области остаётся в подсказке, живой строке и таблице. none оставляет названия только там.
- `legend` — `string`, по умолчанию `bottom`, значения: `top`, `bottom`, `none`. Легенда шкалы: образец для каждой ступени с её диапазоном и пропуск, если он есть. none — только если страница сама объясняет шкалу.
- `tooltip` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: под указателем или курсором показываются название области, её значение и место среди областей.
- `value-format` — `string`, по умолчанию `number`. number, integer, `decimal-<n>`, percent (доля 0..1), compact или `currency-<CODE>`, на языке страницы.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень размера: высота области графика, текст и промежутки. 1/2 для карточки, 2 для отдельной страницы.
- `table` — `string`, по умолчанию `toggle`, значения: `toggle`, `visible`, `hidden`. Те же данные в виде таблицы: toggle даёт кнопку, которая заменяет область графика таблицей, visible показывает её под областью графика, hidden оставляет только для программ чтения с экрана. Никогда none: таблица — это текст графика.
- `summary` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: предложение о том, что делают данные (области и те, у которых есть данные, диапазон, наибольшее и наименьшее, области без данных и строки без области на карте); читается перед областью графика. Слот description добавляет слова страницы.
- `data-state` — `string`, по умолчанию `auto`, значения: `auto`, `loading`, `ready`, `empty`, `error`. auto: ready при наличии областей и значений, иначе empty. loading рисует рамку без отметок; error предлагает «Повторить», что отправляет refresh.
- `items` — `array`, по умолчанию `[]`. Значения: список записей или объект столбцов, по строке на область с ключом и значением ([{region, value}, …]). Строка, ключ которой не соответствует ни одной области на карте, или без числа, отбрасывается; описание словами говорит, сколько таких. Если ключ задан дважды, остаётся последний.
- `shapes` — `object`, по умолчанию `{}`. Области: GeoJSON, FeatureCollection или список Feature с геометрией Polygon или MultiPolygon, в долготе и широте (или в плоских координатах при projection plane). Их даёт страница: в пакете карты нет, поэтому границы, их источник и лицензия остаются за страницей. Объект без ключа или полигона, а также с уже встречавшимся ключом, отбрасывается.

## События

События приходят на сам элемент и всплывают.

- `sf-chart-map-select` — `detail`: `{ index: number, region: string, name: string, value: number, rank: number }`. Пользователь выбрал область: щёлкнул по ней или нажал Enter или Пробел на курсоре с клавиатуры. index — её место в shapes, region — ключ, name — название, value — значение (null, если его нет), rank — место по значению, наибольшее первым (0, если значения нет).
- `sf-chart-map-refresh` — `detail` не описан. Человек снова запросил данные из состояния ошибки; страница загружает их и задаёт `items`.

## Методы

- `reset()` — возвращает `object`. Убирает курсор.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-chart-map-height` | `length` | Высота области графика. |
| `--sf-chart-map-label-color` | `color` | Цвет подписей. |
| `--sf-chart-map-hover-background-color` | `color` | Цвет фона при наведении. |

## Доступность

- Роль: `figure`.
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, `PageUp`, `PageDown`, `Enter`, `Space`, `Escape`.
- Фокус: Одна остановка Tab на области графика, затем кнопка таблицы. Описание словами служит описанием области графика; каждое движение курсора озвучивается вежливо.
