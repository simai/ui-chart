# Тепловая карта sf-chart-heatmap

`<sf-chart-heatmap>` — тепловая карта: одна величина по двум категориям,
сеткой ячеек. Цвет ячейки — ступень шкалы: чем сильнее значение, тем
насыщеннее тон. Подходит для нагрузки по дням и часам, активности по командам
и неделям, изменения по регионам и месяцам. Число пишется в ячейке, если
помещается. Есть шкала-легенда, подсказка, курсор с клавиатуры, описание
словами и те же данные таблицей.

Карта показывает картину, а не точные числа: точные числа — в подсказке и
таблице.

## Данные

`items` — свойство: список записей, по одной на ячейку, или объект столбцов.

- `x` — поле столбцов (по умолчанию первое);
- `y` — поле строк (по умолчанию второе);
- `value` — поле значений (по умолчанию первое числовое после них);
- `names` — свойство `{значение: «Название»}` для строк и столбцов.

Строки и столбцы идут в том порядке, в каком впервые встречаются в данных.
Пропуск (нет записи или пустое значение) — пустая ячейка с пунктирной рамкой,
не ноль. Если пара встречается дважды, остаётся последнее значение:
складывать данные — дело страницы.

```html
<sf-chart-heatmap id="load" label="Нагрузка по часам" x="hour" y="day" value="load" value-format="integer"></sf-chart-heatmap>
<script>
  load.names = {mon: 'Пн', tue: 'Вт'};
  load.items = [{hour: '9:00', day: 'mon', load: 32}, {hour: '10:00', day: 'mon', load: 44}];
</script>
```

## Шкала

Шкала ступенчатая: `steps` ступеней одинаковой ширины (3–9, по умолчанию 5).
Ступени читаются надёжнее плавного перехода. Цвета — тона темы Фреймворка:
в светлой теме сильнее — темнее, в тёмной — светлее, так что сильное значение
всегда самое контрастное. Новых токенов нет.

- `scale="sequential"` (по умолчанию) — от слабого к сильному в одном
  семействе цвета; `scheme` выбирает семейство (`primary` по умолчанию,
  `secondary`, `tertiary`, `neutral`, `success`, `warning`, `error`, `info`).
- `scale="diverging"` — два семейства сходятся к нейтральной середине: для
  изменения, отклонения от плана. `middle` — середина (по умолчанию 0); шкала
  уходит от неё одинаково в обе стороны, число ступеней нечётное.
  `better` — какое направление хорошее: `up` (выше — зелёный, ниже —
  красный), `down` (наоборот), `none` (два нейтральных цвета без оценки).
- `min`, `max` — свои границы шкалы вместо границ данных.

```html
<sf-chart-heatmap label="Изменение продаж к прошлому году" x="month" y="region" value="change"
  scale="diverging" better="up" value-format="percent"></sf-chart-heatmap>
```

## Вид

- `value-labels="auto"` пишет число в ячейке, где оно помещается, цветом,
  который держит контраст 4,5:1 на этой ступени; `none` — без чисел.
- `legend` — шкала над сеткой (`top`), под ней (`bottom`, по умолчанию) или
  без неё (`none`, только если страница объясняет шкалу сама).
- `x-label` — подпись столбцов под сеткой; `y-label` — подпись строк рядом с
  названием и в первой колонке таблицы.
- `size` — высота строки 20, 28 или 36 px и размер текста. Высота графика —
  это его строки, она известна до первой отрисовки.
- Длинные названия строк обрезаются с «…»; названия столбцов, которым тесно,
  показываются через одно (или реже).

## Клавиатура и доступность

Сетка — одна остановка Tab, группа с описанием «тепловая карта».

- Вправо и влево — по строке (в направлении чтения), вниз и вверх — по
  столбцу в соседнюю строку.
- Home и End — в начало и конец строки, с Ctrl (Cmd) — в первую и последнюю
  ячейку сетки.
- Каждый шаг говорится вежливо: «Пн, 9:00: 32». Пропуск тоже проходится и
  называется «нет данных».
- Enter и Пробел выбирают ячейку (`select`), Escape убирает курсор.

Цвет — не единственный признак: число в ячейке, подсказка, строка курсора,
описание (размер сетки, диапазон, где наибольшее и наименьшее, сколько
пропусков) и таблица «строки × столбцы». В режиме высокой контрастности
ячейки — рамки, а значения — текст.

## События

- `sf-chart-heatmap-select` — `{x, y, value}`: столбец и строка, как в
  данных, и значение (`null` для пропуска).
- `sf-chart-heatmap-refresh` — из состояния ошибки нажали «Повторить».

## Состояния

`data-state`: `auto` (готово с данными, пусто без них), `loading`, `ready`,
`empty`, `error`.

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `label` — `string`, по умолчанию пусто. Что показывает график, в нескольких словах: его доступное имя, подпись таблицы и имя файла экспорта. На практике обязателен: без него график называется «Тепловая карта».
- `x` — `string`, по умолчанию пусто. Поле столбцов; если не задано, первое поле. Столбцы идут в том порядке, в каком их впервые дают данные.
- `y` — `string`, по умолчанию пусто. Поле строк; если не задано, второе поле. Строки идут в том порядке, в каком их впервые дают данные.
- `value` — `string`, по умолчанию пусто. Поле значений; если не задано, первое числовое поле после `x` и `y`.
- `scale` — `string`, по умолчанию `sequential`, значения: `sequential`, `diverging`. sequential: от слабого к сильному в одном семействе цвета, для количества или нагрузки. diverging: два семейства, встречающиеся в нейтральной середине, для изменения или отклонения от нормы.
- `scheme` — `string`, по умолчанию `primary`, значения: `primary`, `secondary`, `tertiary`, `neutral`, `success`, `warning`, `error`, `info`. Семейство цвета последовательной шкалы. Его тона — тона темы: самое сильное значение — самый тёмный тон в светлой теме и самый светлый в тёмной.
- `better` — `string`, по умолчанию `up`, значения: `up`, `down`, `none`. Какая сторона хороша на расходящейся шкале: up красит то, что выше середины, в success, а ниже — в error, down наоборот; none использует primary и tertiary, которые ничего не значат.
- `middle` — `number`, по умолчанию `0`. Середина расходящейся шкалы: норма, план, ноль для изменения. Шкала идёт от неё в обе стороны на одинаковое расстояние.
- `min` — `number`. Низ шкалы; если не задан, берётся минимум данных.
- `max` — `number`. Верх шкалы; если не задан, берётся максимум данных.
- `steps` — `number`, по умолчанию `5`. Сколько в шкале ступеней цвета, от 3 до 9; у расходящейся шкалы число нечётное, чтобы была средняя ступень. Ступени читаются увереннее, чем плавный переход.
- `value-labels` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto пишет значение в каждой ячейке, где оно помещается, цветом текста с контрастом 4.5:1 к ступени; none оставляет ячейки пустыми (значения всё равно есть в подсказке и таблице).
- `legend` — `string`, по умолчанию `bottom`, значения: `top`, `bottom`, `none`. Легенда шкалы: образец для каждой ступени с её диапазоном и пропуск, если он есть. none — только если страница сама объясняет шкалу.
- `tooltip` — `string`, по умолчанию `cell`, значения: `cell`, `none`. cell: под указателем или курсором показываются строка, столбец и значение ячейки.
- `x-label` — `string`, по умолчанию пусто. Название столбцов, подписывается под ними.
- `y-label` — `string`, по умолчанию пусто. Название строк, подписывается сбоку и становится заголовком первого столбца таблицы (если не задано, берётся имя поля y).
- `value-format` — `string`, по умолчанию `number`. number, integer, `decimal-<n>`, percent (доля 0..1), compact или `currency-<CODE>`, на языке страницы.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень размера: высота строки (20, 28 или 36 px), текст и промежутки. 1/2 для карточки, 2 для отдельной страницы.
- `table` — `string`, по умолчанию `toggle`, значения: `toggle`, `visible`, `hidden`. Те же данные в виде таблицы, строки по столбцам: toggle добавляет кнопку, которая заменяет сетку таблицей, visible показывает таблицу под сеткой, hidden оставляет её только для программ чтения с экрана. Значения none нет: таблица — это текст графика.
- `summary` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: предложение о сетке (размер, диапазон, где максимум и минимум, сколько ячеек без данных), доступно программам чтения с экрана. Слот description добавляет слова страницы.
- `data-state` — `string`, по умолчанию `auto`, значения: `auto`, `loading`, `ready`, `empty`, `error`. auto: ready при наличии данных, иначе empty. loading рисует блок на месте области графика; error предлагает «Повторить», что отправляет refresh.
- `items` — `array`, по умолчанию `[]`. Данные: список записей, по одной на ячейку ([{day, hour, load}, …]), или объект столбцов. Отсутствующее значение — пропуск, рисуется пустой ячейкой, а не нулём. Если пара задана дважды, остаётся последнее значение.
- `names` — `object`, по умолчанию `{}`. Как называются строка или столбец по их значению в данных: {mon: «Понедельник»}. Без названия используется само значение.

## События

События приходят на сам элемент и всплывают.

- `sf-chart-heatmap-select` — `detail`: `{ x: string, y: string, value: number }`. Пользователь выбрал ячейку: щёлкнул по ней или нажал Enter или Пробел на курсоре с клавиатуры. x и y — её столбец и строка так, как они заданы в данных; для пропуска value равно null.
- `sf-chart-heatmap-refresh` — `detail` не описан. Человек снова запросил данные из состояния ошибки; страница загружает их и задаёт `items`.

## Методы

Публичных методов нет.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-chart-heatmap-label-color` | `color` | Цвет подписей. |
| `--sf-chart-heatmap-empty-color` | `color` | Цвет ячейки без данных. |
| `--sf-chart-heatmap-cell-radius` | `length` | Скругление ячеек. |

## Доступность

- Роль: `figure`.
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, `Enter`, `Space`, `Escape`.
- Фокус: Одна остановка Tab на сетке, затем кнопка таблицы. Описание словами — это описание сетки; каждое перемещение курсора озвучивается вежливо.
