# Точечная диаграмма

:badge[sf-chart-scatter]{variant=main scheme=on-surface size=1} :badge[Предварительная версия]{variant=tonal scheme=warning size=1}

`<sf-chart-scatter>` — точечная диаграмма: каждая строка данных — точка на
двух мерах, чтобы было видно, как они связаны: цена и продажи товаров,
менеджеры и выручка регионов. Третья мера (`bubble`) делает точки
пузырьками: площадь пузырька пропорциональна значению.

Ряд во времени — это `sf-chart-line`. Если третью меру нужно читать
точно, дайте её таблицей или столбцами: площадь глаз оценивает плохо.

## Данные

- `items` — строки, по точке на строку: список записей или объект колонок.
  Строка без обеих мер — не точка; описание говорит, сколько таких строк.
- `x`, `y` — поля мер. Без них — первые два числовых поля.
- `bubble` — поле третьей меры, площадь пузырька. Ноль, отрицательное или
  пустое значение — маленькое кольцо без площади.
- `series` — поле, по значениям которого точки делятся на ряды: у каждого
  ряда свой цвет и своя форма точки. `names` — названия рядов по ключу.
- `point` — поле с названием точки (товар, регион). Его говорят подсказка,
  курсор, таблица и описание. Без него точка называется по номеру строки.

```html
<sf-chart-scatter id="goods" label="Цена и продажи товаров" x="price" y="sold"
  series="kind" point="product" x-label="Цена, ₽" y-label="Продано, шт."></sf-chart-scatter>
<script>
  goods.names = {electronics: 'Электроника', accessories: 'Аксессуары'};
  goods.items = [{product: 'Чехол', kind: 'accessories', price: 300, sold: 520}, …];
</script>
```

## Вид

- `x-label`, `y-label`, `bubble-label` — названия мер: под и над осями, в
  подсказке, таблице и описании.
- `x-format`, `y-format`, `bubble-format` — формат чисел: `number`,
  `integer`, `decimal-<n>`, `percent`, `compact`, `currency-<CODE>`,
  `unit-<unit>`.
- `x-min`, `x-max`, `y-min`, `y-max`, `x-zero`, `y-zero` — границы осей.
- `trend="linear"` — линия тренда каждого ряда (метод наименьших
  квадратов), пунктиром.
- `grid` — направляющие (по умолчанию `both`), `legend` — легенда (при двух
  рядах и больше — сверху); её кнопки скрывают и показывают ряд.
- `colors` и `palette` — цвета рядов, как у линейного графика.
- `size` — ступень размера: высота графика, текст, размер точек и самого
  большого пузырька.

Больше 2 000 точек рисуются на canvas под SVG: оси, курсор и все тексты
остаются в SVG и доступны.

## Доступность

График — одна остановка Tab (группа «точечная диаграмма»). Влево и вправо —
к предыдущей и следующей точке по порядку чтения (по X, затем по Y), так
каждая точка достижима; вверх и вниз — к ближайшей точке выше и ниже; Home и
End — к краям; Page Up и Page Down — на десятую часть. Каждый шаг говорится
вежливо: название точки и её меры. Enter и пробел выбирают точку, Escape
убирает курсор.

Описание говорит число точек и размах мер, размах пузырьков, связь каждого
ряда словами с коэффициентом корреляции («сильная, обратная (r = −0,96)») и
точки с наибольшим и наименьшим Y. Цвет — не единственный признак: у рядов
разные формы точек, а у пузырьков в режиме высокой контрастности — разный
пунктир контура. Таблица — каждая точка строкой.

## События

- `sf-chart-scatter-select` — выбрали точку: `{series, index, point, x, y}`,
  `index` — номер строки в `items`.
- `sf-chart-scatter-toggle` — скрыли или показали ряд: `{id, hidden}`.
- `sf-chart-scatter-refresh` — из состояния ошибки нажали «Повторить».

## Состояния

`data-state`: `auto` (готово с точками, пусто без них), `loading`, `ready`,
`empty`, `error`.

| | |
|:---|:---|

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `label` — `string`, по умолчанию пусто. Что показывает график, в нескольких словах: его доступное имя и подпись таблицы. На практике обязателен: без него график называется «График».
- `palette` — `string`, по умолчанию `theme`, значения: `theme`, `vivid`, `soft`, `warm`, `cool`, `brand`. Цвета рядов как именованный набор по порядку: у каждого светлый и тёмный тон, которые меняются с темой и держат контраст 3:1 с поверхностями 0–2. theme (собственные тона темы, как раньше), vivid (8, первый — цвет бренда), soft (8, приглушённые), warm (6), cool (6), brand (4 ступени семейства primary, для упорядоченных данных). Когда набор кончается, он начинается заново. `colors` главнее для названных в нём рядов.
- `x` — `string`, по умолчанию пусто. Поле горизонтального показателя; если не задано — первое числовое поле.
- `y` — `string`, по умолчанию пусто. Поле вертикального показателя; если не задано — следующее числовое поле.
- `bubble` — `string`, по умолчанию пусто. Поле третьего показателя, который рисуется как площадь каждой точки: точки становятся пузырьками. Значение ноль, меньше нуля или отсутствующее не имеет площади и рисуется маленьким кольцом.
- `series` — `string`, по умолчанию пусто. Один ряд на каждое отдельное значение этого поля, у каждого свой цвет и своя отметка; если не задано — один ряд.
- `point` — `string`, по умолчанию пусто. Поле, которое называет каждую точку (страна, товар); его произносят подсказка, живая строка, таблица и описание словами. Точку без него называют по номеру строки.
- `x-min` — `number`. Начало горизонтальной оси; если не задано — по данным.
- `x-max` — `number`. Конец горизонтальной оси; если не задано — по данным.
- `y-min` — `number`. Начало вертикальной оси; если не задано — по данным.
- `y-max` — `number`. Конец вертикальной оси; если не задано — по данным.
- `x-zero` — `boolean`, по умолчанию `false`. Горизонтальная ось включает ноль.
- `y-zero` — `boolean`, по умолчанию `false`. Вертикальная ось включает ноль.
- `trend` — `string`, по умолчанию `none`, значения: `none`, `linear`. linear рисует пунктиром линию наименьших квадратов по точкам каждого ряда. Описание словами всегда называет силу связи (r Пирсона), с линией или без неё.
- `legend` — `string`, по умолчанию `auto`, значения: `auto`, `top`, `bottom`, `none`. auto показывает легенду над областью графика, когда рядов два или больше. Каждая запись — кнопка, которая скрывает и показывает свой ряд.
- `tooltip` — `string`, по умолчанию `point`, значения: `point`, `none`. point: под указателем или курсором — имя точки и её показатели.
- `grid` — `string`, по умолчанию `both`, значения: `y`, `x`, `both`, `none`. Какие направляющие линии график рисует поперёк области графика.
- `x-label` — `string`, по умолчанию пусто. Название горизонтального показателя: под осью, в подсказке, таблице и описании словами; если не задано — имя поля x.
- `y-label` — `string`, по умолчанию пусто. Название вертикального показателя: над осью, в подсказке, таблице и описании словами; если не задано — имя поля y.
- `bubble-label` — `string`, по умолчанию пусто. Название показателя пузырька: в подсказке, таблице и описании словами; если не задано — имя поля bubble.
- `x-format` — `string`, по умолчанию `number`. Формат горизонтального показателя: number, integer, `decimal-<n>`, percent (доля 0..1), compact, `currency-<CODE>` или `unit-<unit>`, на языке страницы.
- `y-format` — `string`, по умолчанию `number`. Формат вертикального показателя: number, integer, `decimal-<n>`, percent (доля 0..1), compact, `currency-<CODE>` или `unit-<unit>`, на языке страницы.
- `bubble-format` — `string`, по умолчанию `number`. Формат показателя пузырька: number, integer, `decimal-<n>`, percent (доля 0..1), compact, `currency-<CODE>` или `unit-<unit>`, на языке страницы.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень размера: высота области графика, текст и промежутки. 1/2 для карточки, 2 для отдельной страницы.
- `table` — `string`, по умолчанию `toggle`, значения: `toggle`, `visible`, `hidden`. Те же данные в виде таблицы: toggle даёт кнопку, которая заменяет область графика таблицей, visible показывает её под областью графика, hidden оставляет только для программ чтения с экрана. Никогда none: таблица — это текст графика.
- `summary` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: предложение о том, что делают данные (число точек и диапазоны, диапазон пузырьков, связь каждого ряда с её силой и направлением, самая высокая и самая низкая именованная точка); звучит перед областью графика. Слот description добавляет слова страницы.
- `data-state` — `string`, по умолчанию `auto`, значения: `auto`, `loading`, `ready`, `empty`, `error`. auto: ready при наличии точек, empty без них. loading рисует рамку без отметок; error предлагает «Повторить», что отправляет refresh.
- `items` — `array`, по умолчанию `[]`. Данные: список записей, по одной точке на запись ([{country, income, life}, …]), или объект со столбцами. Строка без обоих показателей не даёт точки; описание словами говорит, сколько их отброшено.
- `names` — `object`, по умолчанию `{}`. Как называется каждый ряд, по его ключу: {eu: «Европа»}. Ряд без имени называется своим ключом.
- `colors` — `object`, по умолчанию `{}`. Какого цвета каждый ряд, по его ключу: {fact: 'primary', plan: 'neutral'}. Цвет — роль цвета Framework (primary, secondary, tertiary, neutral, success, warning, error, info), которая следует за темой, или любой цвет или переменная CSS; всё остальное отбрасывается с записью в консоль, как и цвет с контрастом ниже 3:1 к фону (но всё равно рисуется). Ряд без цвета берёт палитру по порядку. В режиме принудительных цветов ряд различается штрихом.
- `hidden-series` — `array`, по умолчанию `[]`. Ключи рядов, которые человек скрыл через легенду.

## События

События приходят на сам элемент и всплывают.

- `sf-chart-scatter-toggle` — `detail`: `{ id: string, hidden: boolean }`. Человек скрыл или показал ряд кнопкой легенды; применяется сразу (локальное переключение из словаря).
- `sf-chart-scatter-select` — `detail`: `{ series: string, index: number, point: string, x: number, y: number }`. Человек выбрал точку: щелчок по ней или Enter или Space на курсоре с клавиатуры. index — строка точки в items, point — её имя ('' без поля point).
- `sf-chart-scatter-refresh` — `detail` не описан. Человек снова запросил данные из состояния ошибки; страница загружает их и задаёт `items`.

## Методы

- `reset()` — возвращает `object`. Снова показывает все ряды и убирает курсор.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-chart-scatter-height` | `length` | Высота области графика. |
| `--sf-chart-scatter-grid-color` | `color` | Цвет линий сетки. |
| `--sf-chart-scatter-baseline-color` | `color` | Цвет базовой линии. |
| `--sf-chart-scatter-label-color` | `color` | Цвет подписей. |
| `--sf-chart-scatter-hover-background-color` | `color` | Цвет фона при наведении. |
| `--sf-chart-scatter-hidden-color` | `color` | Цвет скрытого ряда. |

## Доступность

- Роль: `figure`.
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, `PageUp`, `PageDown`, `Enter`, `Space`, `Escape`.
- Фокус: Одна остановка Tab на области графика, затем кнопки легенды и кнопка таблицы. Описание словами служит описанием области графика; каждое движение курсора озвучивается вежливо.
