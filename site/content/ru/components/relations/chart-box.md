# Ящик с усами

:badge[sf-chart-box]{variant=main scheme=on-surface size=1} :badge[Предварительная версия]{variant=tonal scheme=warning size=1}

`<sf-chart-box>` — ящик с усами: как разбросана одна мера по группам. Для
каждой группы — медиана, середина значений (от нижнего до верхнего
квартиля), усы и выбросы. Ряды рядом в группе, легенда, которая скрывает
ряды, подсказка, курсор с клавиатуры, описание словами и та же статистика
таблицей.

Подходит, чтобы сравнить группы: время доставки по складам, зарплаты по
отделам. Форму одной группы лучше показывает гистограмма (`sf-chart-bar` с
`bin`), а меньше пяти значений в группе — сами точки (`sf-chart-scatter`).

## Данные

`items` — свойство: список записей или объект столбцов.

- `x` — поле групп (по умолчанию первое), в порядке, в каком группы
  встречаются в данных;
- `y` — поле меры (по умолчанию первое числовое, кроме `x` и `series`);
- `series` — ряды: свой ящик для каждого значения этого поля, рядом в группе.

`stats` говорит, что лежит в строках:

- `raw` (по умолчанию) — каждая строка одно наблюдение (заказ, сотрудник);
  график сам считает медиану, квартили, усы и выбросы. Квартили — линейно
  между двумя ближайшими значениями, как в таблицах Excel и Google.
- `given` — каждая строка одна группа с готовыми полями `min`, `q1`,
  `median`, `q3`, `max` (и `mean`), например посчитанными на сервере. Усы
  тогда до `min` и `max`, выбросов нет. Строка без одного из полей или с
  полями не по порядку пропускается.

Строка без значения не попадает в расчёт; описание говорит, сколько таких.

```html
<sf-chart-box id="delivery" label="Время доставки по складам" x="warehouse" y="hours"
  x-label="Склад" y-label="Часов в пути" y-format="integer"></sf-chart-box>
<script>
  delivery.items = [
    {warehouse: 'Москва', hours: 18},
    {warehouse: 'Казань', hours: 27},
    // …
  ];
</script>
```

## Вид

- `whiskers` — `tukey` (по умолчанию): ус доходит до самого дальнего
  значения в пределах полутора высот ящика, значения дальше — выбросы,
  кружки на линии ящика. `range`: усы до самого малого и самого большого
  значения, выбросов нет.
- `mean` — ромбик на среднем; среднее есть и в подсказке, и в таблице.
- `y-min`, `y-max`, `y-zero` — границы оси значений; по умолчанию ось по
  данным.
- `grid` — `value` (линии на делениях) или `none`; `y-format`, `x-label`,
  `y-label`, `legend`, `size` — как у других графиков пакета.
- Длинное название группы сокращается многоточием, полное — в подсказке и
  таблице.

## Цвета

`colors` и `palette` — как у `sf-chart-bar`: роль Framework (`primary`,
`neutral`…) или любой CSS-цвет по ключу ряда, либо готовый набор. Ряд
узнаётся и без цвета: по месту в группе, как в легенде, а в режиме высокой
контрастности — по штриху обводки ящика.

## Клавиатура и доступность

График — одна остановка Tab. Стрелки влево и вправо идут от группы к
группе, вверх и вниз — по рядам в группе. Home и End — к краям, Page Up и
Page Down — на десятую часть. Каждый шаг звучит: «Москва: медиана 18,
квартили 15 – 21, усы 12 – 24, выбросов 1». Enter и пробел выбирают ящик
(`sf-chart-box-select`), Escape убирает курсор.

Фраза о данных («Групп: 4, значений: 36. Часов в пути: медиана выше всего —
Пермь (36)…») — описание графика для чтения с экрана. Таблица всегда есть:
кнопкой (`table="toggle"`), под графиком (`visible`) или только для чтения с
экрана (`hidden`). В ней по строке на ящик: число значений, пять чисел,
среднее (с `mean`) и сами выбросы.

## События, действия и значения

- `sf-chart-box-toggle` `{id, hidden}` — ряд скрыт или показан кнопкой
  легенды; `hiddenSeries` — ключи скрытых рядов.
- `sf-chart-box-select` `{series, index, group, median}` — выбран ящик.
- `sf-chart-box-refresh` — повтор из состояния ошибки.
- `reset()` — показать все ряды и убрать курсор.

## Состояния

`data-state`: `auto` (с данными — график, без — «Нет данных»), `loading`
(рамка той же высоты), `empty`, `error` (с «Повторить»).

## Параметры

Справочник собран из манифеста компонента в сборке набора с коммита `41a2b6ccf3da` и обновляется вместе с ней. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `y-format` — `yFormat`.

| | |
|:---|:---|
| Тег | `<sf-chart-box>` |
| Назначение | Ящик с усами: для каждой группы медиана, квартили, усы и выбросы одной величины, вычисленные по сырым строкам или заданные, чтобы сравнить разброс; ряды рядом в группе, легенда, которая их скрывает, подсказка, курсор с клавиатуры, который обходит ящики, описание словами и та же статистика в таблице. |
| Контракт | `smart.chart-box`, версия `0.1.0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `label` — `string`, по умолчанию пусто. Что показывает график, в нескольких словах: его доступное имя и подпись таблицы. На практике обязателен: без него график называется «График».
- `palette` — `string`, по умолчанию `theme`, значения: `theme`, `vivid`, `soft`, `warm`, `cool`, `brand`. Цвета рядов как именованный набор по порядку: у каждого светлый и тёмный тон, которые меняются с темой и держат контраст 3:1 с поверхностями 0–2. theme (собственные тона темы, как раньше), vivid (8, первый — цвет бренда), soft (8, приглушённые), warm (6), cool (6), brand (4 ступени семейства primary, для упорядоченных данных). Когда набор кончается, он начинается заново. `colors` главнее для названных в нём рядов.
- `x` — `string`, по умолчанию пусто. Поле групп, по одному ящику (или по одному на ряд) на группу, в порядке первого появления в данных; если не задано, первое поле.
- `y` — `string`, по умолчанию пусто. Поле величины, разброс которой показывает каждый ящик, при `stats` raw; если не задано, первое числовое поле кроме `x` и `series`.
- `series` — `string`, по умолчанию пусто. По одному ряду на каждое различное значение этого поля, свой ящик рядом с другими в каждой группе; если не задано, один ряд.
- `stats` — `string`, по умолчанию `raw`, значения: `raw`, `given`. raw: строки — наблюдения, и график сам считает медиану, квартили (линейно между двумя ближайшими, как в таблице), усы и выбросы каждой группы. given: каждая строка задаёт min, q1, median, q3 и max группы (и mean) в полях с такими именами, как посчитал сервер; усы тогда доходят до min и max, выбросов нет.
- `whiskers` — `string`, по умолчанию `tukey`, значения: `tukey`, `range`. tukey: ус доходит до самого дальнего значения в пределах 1,5 межквартильных размахов от ящика, а значения за ним рисуются как выбросы. range: усы доходят до наименьшего и наибольшего значения, выбросов нет.
- `mean` — `boolean`, по умолчанию `false`. Также отмечает среднее каждой группы маленьким ромбом и приводит его в подсказке и таблице.
- `y-min` — `number`. Начало оси значений; если не задано, берётся по данным.
- `y-max` — `number`. Конец оси значений; если не задан, берётся по данным.
- `y-zero` — `boolean`, по умолчанию `false`. Ось значений включает ноль.
- `legend` — `string`, по умолчанию `auto`, значения: `auto`, `top`, `bottom`, `none`. auto показывает легенду над областью графика, когда рядов два или больше. Каждая запись — кнопка, которая скрывает и показывает свой ряд.
- `tooltip` — `string`, по умолчанию `box`, значения: `box`, `none`. box: под указателем или курсором группа и ряд ящика и его статистика: максимум, квартили, медиана, минимум, среднее, если отмечено, число значений и выбросов.
- `grid` — `string`, по умолчанию `value`, значения: `value`, `none`. value рисует направляющие линии через область графика на делениях значений; none оставляет только ноль.
- `x-label` — `string`, по умолчанию пусто. Название групп под осью и первый столбец таблицы; если не задано, имя поля `x`.
- `y-label` — `string`, по умолчанию пусто. Название величины над осью и в описании словами; если не задано, имя поля `y`.
- `y-format` — `string`, по умолчанию `number`. Формат величины: number, integer, `decimal-<n>`, percent (доля 0..1), compact, `currency-<CODE>` или `unit-<unit>`, на языке страницы.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень размера: высота области графика, текст и промежутки. 1/2 для карточки, 2 для отдельной страницы.
- `table` — `string`, по умолчанию `toggle`, значения: `toggle`, `visible`, `hidden`. Те же данные в виде таблицы: toggle даёт кнопку, которая заменяет область графика таблицей, visible показывает её под областью графика, hidden оставляет только для программ чтения с экрана. Никогда none: таблица — это текст графика.
- `summary` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: предложение о том, что делают данные (число групп и значений, наибольшая и наименьшая медиана каждого ряда, самый широкий ящик, число выбросов), произносится перед областью графика. Слот `description` добавляет слова страницы.
- `data-state` — `string`, по умолчанию `auto`, значения: `auto`, `loading`, `ready`, `empty`, `error`. auto: ready при наличии ящиков, empty без них. loading рисует рамку без меток; error предлагает «Повторить», что отправляет `refresh`.
- `items` — `array`, по умолчанию `[]`. Данные: список записей или объект столбцов. При `stats` raw — одна строка на наблюдение ([{shop, minutes}, …]), разрезанная на группы по `x`; при `stats` given — одна строка на группу с min, q1, median, q3 и max (и mean). Строка без величины отбрасывается; описание словами говорит, сколько их.
- `names` — `object`, по умолчанию `{}`. Как называется каждый ряд, по его ключу: {eu: «Европа»}. Ряд без имени называется своим ключом.
- `colors` — `object`, по умолчанию `{}`. Какого цвета каждый ряд, по его ключу: {fact: 'primary', plan: 'neutral'}. Цвет — роль цвета Framework (primary, secondary, tertiary, neutral, success, warning, error, info), которая следует за темой, или любой цвет или переменная CSS; всё остальное отбрасывается с записью в консоль, как и цвет с контрастом ниже 3:1 к фону (но всё равно рисуется). Ряд без цвета берёт палитру по порядку. В режиме принудительных цветов ряд различается штрихом.
- `hidden-series` — `array`, по умолчанию `[]`. Ключи рядов, которые человек скрыл через легенду.

## События

События приходят на сам элемент и всплывают.

- `sf-chart-box-toggle` — `detail`: `{ id: string, hidden: boolean }`. Человек скрыл или показал ряд кнопкой легенды; применяется сразу (локальное переключение из словаря).
- `sf-chart-box-select` — `detail`: `{ series: string, index: number, group: string, median: number }`. Человек выбрал ящик: щелчок по нему или Enter или Space на курсоре с клавиатуры. `index` — номер группы, `group` — её имя, `median` — медиана ящика.
- `sf-chart-box-refresh` — `detail` не описан. Человек снова запросил данные из состояния ошибки; страница загружает их и задаёт `items`.

## Методы

- `reset()` — возвращает `object`. Снова показывает все ряды и убирает курсор.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-chart-box-height` | `length` | Высота области графика. |
| `--sf-chart-box-grid-color` | `color` | Цвет линий сетки. |
| `--sf-chart-box-baseline-color` | `color` | Цвет базовой линии. |
| `--sf-chart-box-label-color` | `color` | Цвет подписей. |
| `--sf-chart-box-hover-background-color` | `color` | Цвет фона при наведении. |
| `--sf-chart-box-hidden-color` | `color` | Цвет скрытого ряда. |

## Доступность

- Роль: `figure`.
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, `PageUp`, `PageDown`, `Enter`, `Space`, `Escape`.
- Фокус: Одна остановка Tab на области графика, затем кнопки легенды и кнопка таблицы. Описание словами служит описанием области графика; каждое движение курсора озвучивается вежливо.
