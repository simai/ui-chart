# Лепестковая диаграмма

:badge[sf-chart-radar]{variant=main scheme=on-surface size=1} :badge[Предварительная версия]{variant=tonal scheme=warning size=1}

`<sf-chart-radar>` — лепестковая диаграмма (радар): из центра расходятся
оси, по одной на меру, и каждый ряд — кольцо через свои значения. Легенда,
которая скрывает ряды, подсказка, курсор с клавиатуры, описание словами и
те же данные таблицей.

Подходит, чтобы сравнить два-три объекта по 3–8 мерам одной шкалы: профили
навыков, оценки товара по десятибалльной шкале. Меры в разных единицах
(рубли и проценты) и точное чтение значений — это столбцы рядом
(`sf-chart-bar`): площадь кольца растёт квадратом, а порядок осей меняет
форму.

## Данные

`items` — свойство: список записей или объект столбцов. Поля называют
атрибуты, как у `sf-chart-bar`:

- `x` — поле осей (по умолчанию первое): первая ось смотрит вверх,
  остальные идут по часовой стрелке в порядке данных;
- `y` — поле значений или список через запятую, один ряд на поле;
- `series` — длинная форма: один ряд на каждое значение этого поля.

Пропуск (`null`, пустая строка, слово) — нет значения, а не ноль: кольцо в
этом месте разрывается и не заливается. `names` — свойство `{ключ:
«Название»}`.

```html
<sf-chart-radar id="team" label="Навыки: Анна и Борис" x="skill" y="anna,boris"
  max="10" y-format="integer"></sf-chart-radar>
<script>
  team.names = {anna: 'Анна', boris: 'Борис'};
  team.items = [
    {skill: 'Аналитика', anna: 8, boris: 5},
    {skill: 'Код', anna: 9, boris: 6},
    {skill: 'Дизайн', anna: 4, boris: 8},
  ];
</script>
```

## Вид

- Шкала одна на все оси: от `min` (по умолчанию ноль) в центре до `max` на
  внешнем кольце. Без `max` — наибольшее значение, округлённое вверх; с
  известным потолком (оценка из 10) задайте его.
- `grid` — кольца шкалы: `polygon` (прямые между осями, по умолчанию),
  `circle` или `none` (только внешнее).
- `fill` — `area` (кольцо ряда слегка залито, по умолчанию) или `none`
  (только линия; для трёх рядов, которые перекрываются).
- Подписи значений шкалы стоят вдоль первой оси. Длинное название оси
  сокращается многоточием, полное — в подсказке и таблице.
- `y-format`, `x-label`, `legend`, `size` — как у других графиков пакета.

## Цвета

`colors` и `palette` — как у `sf-chart-bar`: роль Framework (`primary`,
`warning`…) или любой CSS-цвет по ключу ряда, либо готовый набор. Ряд
узнаётся и без цвета: у второго и следующих своя форма точек (квадрат,
треугольник, ромб), а в режиме высокой контрастности — свой штрих линии.

## Клавиатура и доступность

График — одна остановка Tab. Стрелки влево и вправо идут по осям по кругу,
вверх и вниз — по рядам. Home и End — к первой и последней оси, Page Up и
Page Down — на десятую часть. Каждый шаг звучит: «Код, Анна: 9». Enter и
пробел выбирают значение (`sf-chart-radar-select`), Escape убирает курсор.

Фраза о данных («Осей: 6, значения от 4 до 9. Анна: сильнее всего — Код
(9)… Анна выше, чем Борис, на осях: 3 из 6…») — описание графика для чтения
с экрана. Таблица всегда есть: кнопкой (`table="toggle"`), под графиком
(`visible`) или только для чтения с экрана (`hidden`); в ней строка на ось
и столбец на ряд.

## События, действия и значения

- `sf-chart-radar-toggle` `{id, hidden}` — ряд скрыт или показан кнопкой
  легенды; `hiddenSeries` — ключи скрытых рядов.
- `sf-chart-radar-select` `{series, index, spoke, value}` — выбрано
  значение; в пропуске `value` — `null`.
- `sf-chart-radar-refresh` — повтор из состояния ошибки.
- `reset()` — показать все ряды и убрать курсор.

## Состояния

`data-state`: `auto` (с данными — график, без — «Нет данных»), `loading`
(рамка той же высоты), `empty`, `error` (с «Повторить»).

## Параметры

Справочник собран из манифеста компонента в сборке набора с коммита `41a2b6ccf3da` и обновляется вместе с ней. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `y-format` — `yFormat`.

| | |
|:---|:---|
| Тег | `<sf-chart-radar>` |
| Назначение | Радарная диаграмма: луч на каждый показатель от центра, каждый ряд — контур через его значения на одной шкале; для сравнения нескольких объектов по нескольким показателям; легенда, которая скрывает ряды, подсказка, курсор с клавиатуры по лучам и по рядам, описание словами и те же данные в виде таблицы. |
| Контракт | `smart.chart-radar`, версия `0.1.0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `label` — `string`, по умолчанию пусто. Что показывает график, в нескольких словах: его доступное имя и подпись таблицы. На практике обязателен: без него график называется «График».
- `palette` — `string`, по умолчанию `theme`, значения: `theme`, `vivid`, `soft`, `warm`, `cool`, `brand`. Цвета рядов как именованный набор по порядку: у каждого светлый и тёмный тон, которые меняются с темой и держат контраст 3:1 с поверхностями 0–2. theme (собственные тона темы, как раньше), vivid (8, первый — цвет бренда), soft (8, приглушённые), warm (6), cool (6), brand (4 ступени семейства primary, для упорядоченных данных). Когда набор кончается, он начинается заново. `colors` главнее для названных в нём рядов.
- `x` — `string`, по умолчанию пусто. Поле лучей, по одному на каждое различное значение в порядке данных, первый строго вверх, остальные по часовой стрелке; если не задано, берётся первое поле. Лучше всего читаются от 3 до 8 лучей.
- `y` — `string`, по умолчанию пусто. Поле значений или список через запятую, по одному ряду на поле; без y берутся все числовые поля, кроме x и series.
- `series` — `string`, по умолчанию пусто. Длинная форма: один ряд на каждое различное значение этого поля, его значение берётся из поля y.
- `min` — `number`. Значение в центре; если не задано, ноль или наименьшее значение, когда оно ниже нуля.
- `max` — `number`. Значение на внешнем кольце, для шкалы с известным верхом (оценка из 10); если не задано, наибольшее значение, округлённое вверх.
- `grid` — `string`, по умолчанию `polygon`, значения: `polygon`, `circle`, `none`. Кольца шкалы: polygon (прямые между лучами), circle или none (только внешнее кольцо).
- `fill` — `string`, по умолчанию `area`, значения: `area`, `none`. area слегка заливает кольцо каждого ряда под его линией; none рисует только линию, для нескольких рядов, которые перекрываются. Кольцо, разорванное пропуском, не заливается.
- `legend` — `string`, по умолчанию `auto`, значения: `auto`, `top`, `bottom`, `none`. auto показывает легенду над областью графика, когда рядов два или больше. Каждая запись — кнопка, которая скрывает и показывает свой ряд.
- `tooltip` — `string`, по умолчанию `spoke`, значения: `spoke`, `none`. spoke: под указателем или курсором — имя луча и значения всех показанных рядов на нём.
- `x-label` — `string`, по умолчанию пусто. Название лучей, которое стоит первым столбцом таблицы; если не задано — имя поля x.
- `y-format` — `string`, по умолчанию `number`. Формат величины: number, integer, `decimal-<n>`, percent (доля 0..1), compact, `currency-<CODE>` или `unit-<unit>`, на языке страницы.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень размера: высота области графика, текст и промежутки. 1/2 для карточки, 2 для отдельной страницы.
- `table` — `string`, по умолчанию `toggle`, значения: `toggle`, `visible`, `hidden`. Те же данные в виде таблицы: toggle даёт кнопку, которая заменяет область графика таблицей, visible показывает её под областью графика, hidden оставляет только для программ чтения с экрана. Никогда none: таблица — это текст графика.
- `summary` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: предложение о том, что делают данные (число лучей и диапазон, самый сильный и самый слабый луч каждого ряда, сравнение первых двух рядов по лучам, пропуски); звучит перед областью графика. Слот description добавляет слова страницы.
- `data-state` — `string`, по умолчанию `auto`, значения: `auto`, `loading`, `ready`, `empty`, `error`. auto: ready при наличии значений, empty без них. loading рисует рамку без отметок; error предлагает «Повторить», что отправляет refresh.
- `items` — `array`, по умолчанию `[]`. Данные: список записей, по одной на луч ([{skill, anna, boris}, …]), или объект со столбцами. Отсутствующее значение — пропуск: кольцо ряда в этом месте разорвано и не опускается до нуля.
- `names` — `object`, по умолчанию `{}`. Как называется каждый ряд, по его ключу: {eu: «Европа»}. Ряд без имени называется своим ключом.
- `colors` — `object`, по умолчанию `{}`. Какого цвета каждый ряд, по его ключу: {fact: 'primary', plan: 'neutral'}. Цвет — роль цвета Framework (primary, secondary, tertiary, neutral, success, warning, error, info), которая следует за темой, или любой цвет или переменная CSS; всё остальное отбрасывается с записью в консоль, как и цвет с контрастом ниже 3:1 к фону (но всё равно рисуется). Ряд без цвета берёт палитру по порядку. В режиме принудительных цветов ряд различается штрихом.
- `hidden-series` — `array`, по умолчанию `[]`. Ключи рядов, которые человек скрыл через легенду.

## События

События приходят на сам элемент и всплывают.

- `sf-chart-radar-toggle` — `detail`: `{ id: string, hidden: boolean }`. Человек скрыл или показал ряд кнопкой легенды; применяется сразу (локальное переключение из словаря).
- `sf-chart-radar-select` — `detail`: `{ series: string, index: number, spoke: string, value: number }`. Человек выбрал значение: щелчок по отметке или лучу либо Enter или Space на курсоре с клавиатуры. index — номер луча, spoke — его имя; value равно null в пропуске.
- `sf-chart-radar-refresh` — `detail` не описан. Человек снова запросил данные из состояния ошибки; страница загружает их и задаёт `items`.

## Методы

- `reset()` — возвращает `object`. Снова показывает все ряды и убирает курсор.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-chart-radar-height` | `length` | Высота области графика. |
| `--sf-chart-radar-grid-color` | `color` | Цвет линий сетки. |
| `--sf-chart-radar-baseline-color` | `color` | Цвет базовой линии. |
| `--sf-chart-radar-label-color` | `color` | Цвет подписей. |
| `--sf-chart-radar-hover-background-color` | `color` | Цвет фона при наведении. |
| `--sf-chart-radar-hidden-color` | `color` | Цвет скрытого ряда. |

## Доступность

- Роль: `figure`.
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, `PageUp`, `PageDown`, `Enter`, `Space`, `Escape`.
- Фокус: Одна остановка Tab на области графика, затем кнопки легенды и кнопка таблицы. Описание словами служит описанием области графика; каждое движение курсора озвучивается вежливо.
