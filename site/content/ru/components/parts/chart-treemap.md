# Плиточная диаграмма sf-chart-treemap

`<sf-chart-treemap>` — плиточная диаграмма: из каких частей состоит целое.
Каждая часть — прямоугольник, его площадь — доля части. Части можно
собрать в группы: тогда это два уровня, например выручка по направлениям
и товарам. Подсказка, курсор с клавиатуры, описание словами и те же
данные таблицей.

Не подходит, когда частей мало и их нужно сравнить точно: это лучше
читается на `sf-chart-bar`. Отрицательные значения площадью не показать:
их рисуют `sf-chart-waterfall` и `sf-chart-bar`.

## Данные

`items` — свойство: список записей или объект столбцов, строка на часть.

- `x` — поле названия части. По умолчанию первое поле, кроме значения и
  группы.
- `y` — поле значения. По умолчанию первое числовое поле.
- `group` — поле группы, для второго уровня. Без него все части — один
  уровень одного цвета.
- Строка без значения или со значением ноль и меньше пропускается;
  описание говорит, сколько таких.

```html
<sf-chart-treemap id="sales" label="Выручка по направлениям, млн ₽"
  x="name" y="value" group="area" y-format="integer"></sf-chart-treemap>
<script>
  sales.items = [
    {name: 'Смартфоны', value: 420, area: 'Электроника'},
    {name: 'Ноутбуки', value: 310, area: 'Электроника'},
    {name: 'Мебель', value: 260, area: 'Дом'},
  ];
</script>
```

## Вид

- Прямоугольники раскладываются так, чтобы были ближе к квадрату:
  площади так легче сравнивать. Крупные — первыми, слева сверху.
- Между соседями 2 px. У группы сверху полоса с её названием, если группа
  достаточно высокая.
- В части написано её название, обрезанное многоточием, а под ним
  значение, если помещается. Совсем маленькая часть остаётся без
  подписи: её слова — в подсказке и таблице. `labels="none"` убирает
  подписи всегда.
- `y-format`, `x-label`, `size` — как у других графиков пакета. Доля
  всегда в процентах.
- Больше двух уровней, приближение группы и круговая «солнечная»
  диаграмма в 0.1.0 не рисуются.

## Цвета

Группа берёт цвет графиков Framework по своему месту (крупнейшая —
первый): светлая заливка и линия того же цвета вокруг каждой части. Текст
— цвета страницы, он читается на любой заливке. `colors` — свойство
`{ключ группы: цвет}`: роль Framework или любой CSS-цвет. В режиме высокой
контрастности все части — цвета фона с линией цвета текста.

```html
<script>
  sales.colors = {Электроника: 'primary', Дом: 'tertiary', Одежда: 'warning'};
</script>
```

## Клавиатура и доступность

График — одна остановка Tab. Стрелки влево и вправо идут от части к
части, крупные первыми, группа за группой; вверх и вниз — к первой части
соседней группы. Home и End — к краям, Page Up и Page Down — на десятую
часть. Каждая часть звучит: «Электроника — Смартфоны: 420 (24 %)». Enter и
пробел выбирают часть (`sf-chart-treemap-select`), Escape убирает курсор.

Фраза о данных — сумма и число частей, крупнейшая часть с долей, число
групп и крупнейшая из них (без групп — доля трёх крупнейших частей).
Таблица всегда есть: кнопкой (`table="toggle"`), под графиком (`visible`)
или только для чтения с экрана (`hidden`).

## События и действия

- `sf-chart-treemap-select` `{index, row, x, group, value, share}` — выбрана
  часть; `index` — её место в порядке клавиатуры, `row` — строка в
  `items`, `group` — ключ группы (`''` без групп), `share` — доля от 0 до 1.
- `sf-chart-treemap-refresh` — повтор из состояния ошибки.
- `reset()` — убрать курсор.

## Состояния

`data-state`: `auto` (с данными — график, без — «Нет данных»), `loading`
(рамка той же высоты), `empty`, `error` (с «Повторить»).

## Параметры

Справочник собран из манифеста компонента в сборке набора с коммита `993536a2f943` и обновляется вместе с ней. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `y-format` — `yFormat`.

| | |
|:---|:---|
| Тег | `<sf-chart-treemap>` |
| Назначение | Древовидная карта: значения как площади прямоугольников, которые выкладываются по области графика алгоритмом squarified, от самого большого; один уровень или два (части в группах под именем группы); группа — в цвете графика со светлой заливкой и линией вокруг каждой части; имя и значение части написаны внутри, где помещаются; ключ групп; подсказка с долей; курсор с клавиатуры по частям и между группами; описание словами; те же данные в таблице. |
| Контракт | `smart.chart-treemap`, версия `0.1.0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `label` — `string`, по умолчанию пусто. Что показывает график, в нескольких словах: его доступное имя и подпись таблицы. На практике обязателен: без него график называется «График».
- `x` — `string`, по умолчанию пусто. Поле имён частей; если не задано — первое поле, кроме значения и группы.
- `y` — `string`, по умолчанию пусто. Поле значений, положительных величин; если не задано — первое числовое поле, кроме x и группы.
- `group` — `string`, по умолчанию пусто. Поле групп, для двух уровней: части группы лежат вместе в её прямоугольнике, под её именем, в её цвете. Если не задано: один уровень, все части одного цвета.
- `labels` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto пишет имя части внутри неё, с многоточием, а под именем её значение, если есть место; часть, слишком малая для трёх букв, остаётся пустой. none оставляет их подсказке и таблице.
- `legend` — `string`, по умолчанию `auto`, значения: `auto`, `top`, `bottom`, `none`. auto показывает ключ групп над областью графика, если есть группы, none — без них.
- `tooltip` — `string`, по умолчанию `part`, значения: `part`, `none`. part: под указателем или курсором — имя части, её группа, её значение и её доля от целого.
- `x-label` — `string`, по умолчанию пусто. Название частей, столбец частей в таблице; если не задано — имя поля x.
- `y-format` — `string`, по умолчанию `number`. Формат значений: number, integer, `decimal-<n>`, compact, `currency-<CODE>` или `unit-<unit>`, на языке страницы. Доли всегда в процентах.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень размера: высота области графика, текст и промежутки. 1/2 для карточки, 2 для отдельной страницы.
- `table` — `string`, по умолчанию `toggle`, значения: `toggle`, `visible`, `hidden`. Те же данные в виде таблицы: toggle даёт кнопку, которая заменяет область графика таблицей, visible показывает её под областью графика, hidden оставляет только для программ чтения с экрана. Никогда none: таблица — это текст графика.
- `summary` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: предложение о том, что делают данные (итог и число частей, самая большая часть с её долей и число групп с самой большой, а без групп — доля трёх самых больших частей); звучит перед областью графика. Слот description добавляет слова страницы.
- `data-state` — `string`, по умолчанию `auto`, значения: `auto`, `loading`, `ready`, `empty`, `error`. auto: ready при наличии частей, empty без них. loading рисует рамку без отметок; error предлагает «Повторить», что отправляет refresh.
- `items` — `array`, по умолчанию `[]`. Данные: список записей, по одной на часть ([{name, value, group}, …]), или объект со столбцами. Площадь части — её доля от целого. Строка без значения или со значением ноль или меньше отбрасывается; описание словами говорит, сколько их.
- `colors` — `object`, по умолчанию `{}`. Цвета групп по ключу ({Электроника: 'primary'}): роль цвета Framework, которая следует теме, либо любой цвет или переменная CSS; всё остальное отбрасывается с сообщением в консоль, как и цвет с контрастом ниже 3:1 к фону (но он всё равно рисуется). Группа без цвета берёт цвет графика своего места, от самой большой.

## События

События приходят на сам элемент и всплывают.

- `sf-chart-treemap-select` — `detail`: `{ index: number, row: number, x: string, group: string, value: number, share: number }`. Человек выбрал часть: щелчок по ней или Enter или Space на курсоре с клавиатуры. index — её место в порядке клавиатуры (группы от самой большой, затем части от самой большой), row — её строка в items, x — её имя, group — ключ её группы ('' без групп), value — её значение, share — её часть целого, от 0 до 1.
- `sf-chart-treemap-refresh` — `detail` не описан. Человек снова запросил данные из состояния ошибки; страница загружает их и задаёт `items`.

## Методы

- `reset()` — возвращает `object`. Убирает курсор.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-chart-treemap-height` | `length` | Высота области графика. |
| `--sf-chart-treemap-label-color` | `color` | Цвет подписей. |
| `--sf-chart-treemap-hover-background-color` | `color` | Цвет фона при наведении. |

## Доступность

- Роль: `figure`.
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, `PageUp`, `PageDown`, `Enter`, `Space`, `Escape`.
- Фокус: Одна остановка Tab на области графика, затем кнопка таблицы. Описание словами служит описанием области графика; каждое движение курсора озвучивается вежливо.
