# Солнечные круги sf-chart-sunburst

`<sf-chart-sunburst>` — солнечные круги: иерархия кольцами вокруг центра.
Внутреннее кольцо — верхний уровень, каждое следующее — уровень глубже,
а дуга занимает долю от дуги родителя. Например, выручка по направлениям,
а внутри направлений — по товарам; место на диске по папкам. В центре —
общая сумма. Подсказка, курсор с клавиатуры, описание словами и все части
таблицей.

Не подходит, когда размеры нужно сравнить точно: это `sf-chart-bar` или
`sf-chart-treemap`. Отрицательные значения дуга не покажет.

## Данные

`items` — свойство: список записей или объект столбцов. Два способа задать
иерархию.

**Узел и родитель.** Строка — узел со своим `id` и `parent`.

- `node` — поле id узла, по умолчанию `id`. (Настройка называется не `id`:
  это собственный атрибут элемента.)
- `parent` — поле родителя, по умолчанию `parent`. Узел, чей родитель не
  найден среди id, становится верхним.
- `name` — поле названия на дуге; по умолчанию сам id.

**Путь.** Строка — конечная часть со своим путём, списком названий сверху
вниз: `{path: ['Фото', '2026', 'Отпуск'], size: 35}`. Промежуточные узлы
создаются сами, один и тот же путь дважды складывается.

- `path` — поле пути. Без `node` и `parent` поле со списком находится само.

**Значения.**

- `value` — поле величины. По умолчанию первое числовое поле, кроме id,
  родителя и пути.
- Значение родителя — его собственное плюс значения детей. Собственное
  остаётся пустым местом после детей на следующем кольце.
- Строка без id или пути, узел без положительного значения и без детей,
  повторный id и цепочка родителей, которая замыкается в круг,
  пропускаются; описание говорит, сколько таких.

```html
<sf-chart-sunburst id="revenue" label="Выручка по направлениям, млн ₽"
  y-format="integer"></sf-chart-sunburst>
<script>
  revenue.items = [
    {id: 'Электроника'},
    {id: 'Смартфоны', parent: 'Электроника', value: 420},
    {id: 'Ноутбуки', parent: 'Электроника', value: 310},
    {id: 'Дом'},
    {id: 'Мебель', parent: 'Дом', value: 260},
  ];
</script>
```

## Вид

- Верхние узлы делят круг по часовой стрелке от двенадцати часов, крупные
  первыми; ребёнок занимает часть угла родителя по своей доле.
- Кольца делят радиус поровну, внутри — отверстие с общей суммой (когда
  она в нём помещается).
- Название пишется по середине дуги, в нижней половине круга
  перевёрнутым, чтобы читалось. Оно обрезается многоточием по месту в дуге.
  Слишком маленькая дуга остаётся без подписи: её слова — в подсказке и
  таблице. `labels="none"` убирает подписи всегда.
- `y-format` и `size` — как у других графиков пакета. Доли всегда в
  процентах.

## Цвета

Верхний узел берёт цвет графиков Framework по своему месту, а вся его ветвь
сохраняет этот цвет: светлая заливка с линией цвета вокруг каждой дуги,
дальше первого кольца — светлее. Названия пишутся цветом текста страницы.
`colors` — свойство `{верхний узел: цвет}`: роль Framework или любой
CSS-цвет. В режиме высокой контрастности дуги — цвета фона с линией цвета
текста.

## Клавиатура и доступность

График — одна остановка Tab. Курсор ходит по дугам: вправо и влево — по
кольцу (вправо — по часовой стрелке, по кругу), вниз — наружу к самому
крупному ребёнку, вверх — назад к родителю, Home и End — к первой и
последней дуге кольца. Каждая дуга звучит с путём и долями: «Дом /
Мебель: 260; 59,1 % от «Дом», 14,7 % всего». Enter и пробел выбирают дугу
(`sf-chart-sunburst-select`), Escape убирает курсор. Указатель тоже
показывает дугу.

Фраза о данных — число уровней и частей, общая сумма, крупнейшая ветвь и
крупнейшая конечная часть с долями, пропущенные строки. Таблица всегда
есть, строка на узел, каждая ветвь под своим родителем: кнопкой
(`table="toggle"`), под графиком (`visible`) или только для чтения с
экрана (`hidden`).

## События и действия

- `sf-chart-sunburst-select` `{index, node, name, path, depth, value,
  share}` — выбрана дуга; `index` — её место в порядке клавиатуры (кольцо
  за кольцом, по часовой), `node` — id, `path` — названия сверху вниз,
  `depth` — кольцо с нуля, `share` — доля всего, от 0 до 1.
- `sf-chart-sunburst-refresh` — повтор из состояния ошибки.
- `reset()` — убрать курсор.

## Состояния

`data-state`: `auto` (с данными — график, без — «Нет данных»), `loading`
(рамка той же высоты), `empty`, `error` (с «Повторить»).

## Параметры

Справочник собран из манифеста компонента в сборке набора с коммита `166cbbc09735` и обновляется вместе с ней. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `y-format` — `yFormat`.

| | |
|:---|:---|
| Тег | `<sf-chart-sunburst>` |
| Назначение | Солнечная диаграмма: иерархия в виде колец вокруг центра, по кольцу на уровень от верхних узлов наружу; каждая дуга — доля своего родителя; читается по id и parent или по путям; верхний узел — в цвете графика, который сохраняет его ветвь, светлее за первым кольцом, с линией вокруг каждой дуги; имя вдоль дуги, где помещается, и итог в центре; подсказка с долями; курсор с клавиатуры по кольцам, внутрь и наружу; описание словами; каждый узел — строка таблицы. |
| Контракт | `smart.chart-sunburst`, версия `0.1.0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `label` — `string`, по умолчанию пусто. Что показывает график, в нескольких словах: его доступное имя и подпись таблицы. На практике обязателен: без него график называется «График».
- `node` — `string`, по умолчанию пусто. Поле id узла; если не задано — id. (Настройка называется не id: это собственный атрибут элемента.)
- `parent` — `string`, по умолчанию пусто. Поле id родителя узла; если не задано — parent. Родитель, которого нет среди id, делает узел верхним.
- `path` — `string`, по умолчанию пусто. Поле с путём листа — списком имён сверху вниз. Если задано, или если node и parent не заданы, а поле содержит списки, строки читаются по пути, а не по id и parent.
- `value` — `string`, по умолчанию пусто. Поле значений, положительных; если не задано — первое числовое поле, кроме id, parent и path.
- `name` — `string`, по умолчанию пусто. С id и parent — поле имени узла, которое пишется на его дуге; если не задано — id.
- `labels` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto пишет имя узла вдоль середины его дуги, с многоточием по месту, если кольцо толщиной в полторы строки; слишком малая дуга оставляет слова подсказке, живой строке и таблице. none оставляет их всем этим.
- `tooltip` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: под указателем или курсором — путь дуги, её значение, доля от родителя и от целого.
- `y-format` — `string`, по умолчанию `number`. Формат значений: number, integer, `decimal-<n>`, compact, `currency-<CODE>` или `unit-<unit>`, на языке страницы. Доли всегда в процентах.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень размера: высота области графика, текст и промежутки. 1/2 для карточки, 2 для отдельной страницы.
- `table` — `string`, по умолчанию `toggle`, значения: `toggle`, `visible`, `hidden`. Те же данные в виде таблицы: toggle даёт кнопку, которая заменяет область графика таблицей, visible показывает её под областью графика, hidden оставляет только для программ чтения с экрана. Никогда none: таблица — это текст графика.
- `summary` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: предложение о том, что делают данные (уровни, части и итог, самая большая ветвь и самая большая конечная часть с их долями, отброшенные строки); звучит перед областью графика. Слот description добавляет слова страницы.
- `data-state` — `string`, по умолчанию `auto`, значения: `auto`, `loading`, `ready`, `empty`, `error`. auto: ready при наличии частей, empty без них. loading рисует рамку без отметок; error предлагает «Повторить», что отправляет refresh.
- `items` — `array`, по умолчанию `[]`. Данные: список записей или объект со столбцами. Либо узел на строку с его id и parent ([{id, parent, value}, …]), либо лист на строку с его путём — именами сверху вниз ([{path: ['Дом', 'Мебель'], value}, …]); один и тот же путь дважды суммируется. Значение родителя — его собственное вместе со значениями потомков. Строка без id или пути, узел, которому нечего показать, id, названный дважды, и цепочка родителей, возвращающаяся к себе, отбрасываются; описание словами говорит, сколько их.
- `colors` — `object`, по умолчанию `{}`. Цвета ветвей по имени верхнего узла ({Электроника: 'primary'}): роль цвета Framework, которая следует теме, либо любой цвет или переменная CSS; всё остальное отбрасывается с сообщением в консоль, как и цвет с контрастом ниже 3:1 к фону (но он всё равно рисуется). Ветвь без цвета берёт цвет графика места своего верхнего узла, от самого большого.

## События

События приходят на сам элемент и всплывают.

- `sf-chart-sunburst-select` — `detail`: `{ index: number, node: string, name: string, path: array, depth: number, value: number, share: number }`. Человек выбрал дугу: щелчок по ней или Enter или Space на курсоре с клавиатуры. index — её место в порядке клавиатуры (кольцо за кольцом, по часовой стрелке), node — её id (путь, склеенный нулевым символом, при настройке path), name — её имя, path — имена сверху вниз, depth — её кольцо, считая с 0, value — её значение вместе со значениями потомков, share — её часть целого, от 0 до 1.
- `sf-chart-sunburst-refresh` — `detail` не описан. Человек снова запросил данные из состояния ошибки; страница загружает их и задаёт `items`.

## Методы

- `reset()` — возвращает `object`. Убирает курсор.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-chart-sunburst-height` | `length` | Высота области графика. |
| `--sf-chart-sunburst-label-color` | `color` | Цвет подписей. |
| `--sf-chart-sunburst-hover-background-color` | `color` | Цвет фона при наведении. |

## Доступность

- Роль: `figure`.
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, `PageUp`, `PageDown`, `Enter`, `Space`, `Escape`.
- Фокус: Одна остановка Tab на области графика, затем кнопка таблицы. Описание словами служит описанием области графика; каждое движение курсора озвучивается вежливо.
