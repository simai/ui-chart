# Полоса частей sf-chart-parts

`<sf-chart-parts>` — полоса частей: части одного целого одной тонкой полосой. Если
задана ёмкость, в конце полосы — свободный остаток. Подходит для диска, квоты,
контекста модели, бюджета по статьям. Под полосой список «название — значение —
доля», над ней — сколько занято. Есть подсказка, курсор с клавиатуры, описание
словами и те же данные таблицей.

## Данные

`items` — свойство: список записей или объект столбцов, одна часть на запись.

- `category` — поле названий частей (по умолчанию первое);
- `value` — поле значений (по умолчанию первое числовое);
- `names` — свойство `{категория: «Название»}`.

Частью полосы бывает только положительное значение. Ноль, отрицательное число и
пропуск остаются строками таблицы.

```html
<sf-chart-parts id="disk" label="Диск" category="kind" value="size" max="100" value-format="integer"></sf-chart-parts>
<script>
  disk.names = {system: 'Система', apps: 'Приложения'};
  disk.items = [{kind: 'system', size: 22}, {kind: 'apps', size: 13}];
</script>
```

## Ёмкость

- `max` — ёмкость. Полоса — вся ёмкость, а то, что осталось от частей, —
  последняя часть полосы, «Свободно» (`free-label` меняет название). Доли
  считаются от ёмкости. Над полосой: «45 из 100 (45 %)».
- Без `max` полоса — сумма частей, остатка нет, над полосой: «всего 1 000».
- Если части больше ёмкости, полоса заполнена целиком, доли считаются от суммы,
  а описание говорит: «Занято 45 из 40: больше на 5».

## Вид

- `legend="list"` (по умолчанию) — под полосой строка на часть: название,
  значение, доля; остаток последним. `inline` — названия с долями в одну
  переносимую строку, для плитки. `none` — только полоса.
- `max-parts` (по умолчанию 7): сверх этого числа самые маленькие части
  сводятся в «Другое». Таблица сохраняет все строки. Когда данные идут потоком,
  таблица обновляется не чаще раза в секунду и всегда догоняет последние данные;
  первые данные и редкие изменения видны в ней сразу.
- `total="none"` убирает «45 из 100» рядом с названием.
- `size`: `1/2` — тонкая полоса и мелкий текст для плитки, `2` — для отдельной
  страницы. Полоса рисуется без замера ширины, поэтому первая отрисовка — уже
  готовая полоса.
- `value-format`, `table`, `summary` — как у `sf-chart-pie`. В плитке удобно
  `table="hidden"`: таблица остаётся для экранных чтецов, кнопки нет.

## Цвета

`colors` — свойство, свой цвет части: объект «категория → цвет». Цвет — роль Framework
(`primary`, `secondary`, `tertiary`, `neutral`, `success`, `warning`, `error`, `info`): берётся её графический тон, и он сам меняется со светлой и тёмной
темой. Запасной путь — любой CSS-цвет или переменная (`#0a7f6f`,
`var(--brand)`).

```html
<sf-chart-parts id="disk" label="Диск" category="kind" value="size" max="100"></sf-chart-parts>
<script>
  disk.colors = {system: 'neutral', apps: 'primary'};
</script>
```

Свободный остаток красится своей переменной `--sf-chart-parts-free-color`.

- Без цвета часть (и «Другое») берёт цвет палитры по своему месту, как раньше.
- Цвет держится за ключ, а не за порядок: переставили данные — цвета остались.
  Сервер может напечатать его в JSON-блоке `data-sf-settings`, как `items`.
  Один и тот же `colors` на нескольких графиках страницы красит одну категорию
  одинаково.
- Не цвет (опечатка, текст) отбрасывается с сообщением в консоли. Цвет с
  контрастом ниже 3:1 к фону графика рисуется, но консоль предупреждает.
- В режиме высокой контрастности цвета заменяет система; ряды различаются
  штрихом и формой.

**Готовые наборы.** `palette` — набор цветов по порядку частей: каждый цвет —
пара для светлой и тёмной темы, контраст не ниже 3:1 к фонам 0–2 в обеих.

| `palette` | Цветов | Для чего |
|---|---|---|
| `theme` (по умолчанию) | 4 | тона темы, как раньше |
| `vivid` | 8 | разноцветный, первый — цвет бренда; первые пять различимы и при дальтонизме |
| `soft` | 8 | приглушённый |
| `warm` | 6 | тёплые тона |
| `cool` | 6 | холодные тона |
| `brand` | 4 | ступени основного цвета темы, для упорядоченных данных |

Когда частей больше, чем цветов в наборе, набор начинается сначала.
`colors` сильнее набора для тех частей, которые называет.

```html
<sf-chart-parts palette="vivid" …></sf-chart-parts>
```

## Клавиатура и доступность

Полоса — одна остановка Tab. Стрелки вправо и вниз идут к следующей части по
ходу чтения (на странице справа налево вправо — значит назад), влево и вверх —
назад, Home и End — к первой и последней части, остаток тоже. Шаг звучит:
«Система: 22 (22 %)». Enter и пробел выбирают часть (остаток не выбирается),
Escape убирает курсор.

Фраза о данных: «Занято 45 из 100 (45 %). Система: 22 (22 %). … Свободно: 55
(55 %).», части по убыванию.

## События

- `sf-chart-parts-select` `{series, index, x, value}`: `x` — категория, `index` —
  строка данных (у «Другое» — −1).
- `sf-chart-parts-refresh` — повтор из состояния ошибки.

## Параметры

Справочник собран из манифеста компонента в сборке набора с коммита `166cbbc09735` и обновляется вместе с ней. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `y-format` — `yFormat`.

| | |
|:---|:---|
| Тег | `<sf-chart-parts>` |
| Назначение | Полоса частей: части одного целого в виде одной тонкой полосы, разделённой на доли, со свободным остатком ёмкости (диск, квота, контекст модели), самые малые части сворачиваются в «Другое»; есть список частей со значениями и долями, подсказка, курсор с клавиатуры, описание словами и те же данные в виде таблицы. |
| Контракт | `smart.chart-parts`, версия `0.3.0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `label` — `string`, по умолчанию пусто. Что показывает график, в нескольких словах: его доступное имя, подпись таблицы и имя файла экспорта. На практике обязателен: без него график называется «Полоса частей».
- `palette` — `string`, по умолчанию `theme`, значения: `theme`, `vivid`, `soft`, `warm`, `cool`, `brand`. Цвета частей как именованный набор, по порядку; у каждого есть светлый и тёмный тон, которые меняются вместе с темой и держат контраст 3:1 к поверхностям 0-2: theme (собственные тона темы, как раньше), vivid (8, первый — цвет бренда), soft (8, приглушённые), warm (6), cool (6), brand (4 ступени семейства primary, для упорядоченных данных). Когда набор заканчивается, он начинается снова. colors приоритетнее для названных в нём частей.
- `category` — `string`, по умолчанию пусто. Поле с названиями частей; если не задано, берётся первое поле.
- `value` — `string`, по умолчанию пусто. Поле со значениями частей; если не задано, берётся первое числовое поле, кроме category.
- `max` — `number`. Ёмкость (диск, квота, контекст модели): полоса — это вся ёмкость, а то, что не заняли части, — свободный остаток, последняя часть полосы. Если не задана, полоса равна сумме частей. Части сверх ёмкости заполняют полосу, а описание словами говорит, на сколько они её превышают.
- `free-label` — `string`, по умолчанию пусто. Название свободного остатка, когда задан max; если не задано, «Свободно».
- `max-parts` — `number`, по умолчанию `7`. Если частей больше этого числа, самые малые сворачиваются в одну «Другое», чтобы не было узких щепок и хватало цветов; таблица сохраняет все строки.
- `total` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: в заголовке рядом с подписью указано целое: «45 из 100 (45 %)» при max, «всего 1 000» без него; none: только подпись.
- `legend` — `string`, по умолчанию `list`, значения: `list`, `inline`, `none`. list: под полосой строка на каждую часть с названием, значением и долей, свободный остаток последним; inline: названия с долями в одной переносимой строке, для плитки; none: только полоса (описание словами и таблица всё равно называют каждую часть).
- `tooltip` — `string`, по умолчанию `part`, значения: `part`, `none`. part: под указателем или курсором показываются название, значение и доля части.
- `category-label` — `string`, по умолчанию пусто. Название частей: первый столбец таблицы (если не задано, берётся имя поля category).
- `value-label` — `string`, по умолчанию пусто. Название значений: второй столбец таблицы (если не задано, имя поля `value`).
- `value-format` — `string`, по умолчанию `number`. number, integer, `decimal-<n>`, percent (доля 0..1), compact или `currency-<CODE>`, на языке страницы.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень размера: толщина полосы, текст и промежутки. 1/2 для плитки, 2 для отдельной страницы.
- `table` — `string`, по умолчанию `toggle`, значения: `toggle`, `visible`, `hidden`. Те же данные в виде таблицы: toggle добавляет кнопку, которая заменяет полосу таблицей, visible показывает таблицу под полосой, hidden оставляет её только для программ чтения с экрана. Значения none нет: таблица — это текст графика.
- `summary` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: предложение о целом (сколько ёмкости занято или итог; значение и доля каждой части, наибольшая первой; свободный остаток), доступно программам чтения с экрана. Слот description добавляет слова страницы.
- `data-state` — `string`, по умолчанию `auto`, значения: `auto`, `loading`, `ready`, `empty`, `error`. auto: ready при наличии данных, иначе empty. loading рисует дорожку полосы без частей; error предлагает «Повторить», что отправляет refresh.
- `items` — `array`, по умолчанию `[]`. Данные: список записей ([{kind, size}, …]) или объект столбцов; одна часть на категорию. Частью полосы становится только положительное значение; ноль, отрицательное или отсутствующее значение остаётся в таблице и отмечено там.
- `names` — `object`, по умолчанию `{}`. Как называется каждая часть, по её категории: {docs: «Документы»}. Часть без названия называется по своей категории.
- `colors` — `object`, по умолчанию `{}`. Какого цвета каждая часть, по её категории: {Видео: 'primary', Почта: 'tertiary'}. Цвет — это роль Framework (primary, secondary, tertiary, neutral, success, warning, error, info), которая следует теме, либо любой цвет или переменная CSS; всё остальное отбрасывается с сообщением в консоль, так же как цвет с контрастом ниже 3:1 к фону (он всё равно рисуется). Часть без цвета берёт палитру по своему месту; «Другое» тоже, а свободный остаток сохраняет --sf-chart-parts-free-color.

## События

События приходят на сам элемент и всплывают.

- `sf-chart-parts-select` — `detail`: `{ series: string, index: number, x: string, value: number }`. Пользователь выбрал часть: щёлкнул по ней или нажал Enter или Пробел на курсоре с клавиатуры. x — её категория так, как она задана в данных (пусто для «Другое»), index — её строка (-1 для «Другое»). Свободный остаток выбрать нельзя.
- `sf-chart-parts-refresh` — `detail` не описан. Человек снова запросил данные из состояния ошибки; страница загружает их и задаёт `items`.

## Методы

Публичных методов нет.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-chart-parts-thickness` | `length` | Толщина полосы. |
| `--sf-chart-parts-free-color` | `color` | Цвет свободного остатка. |
| `--sf-chart-parts-label-color` | `color` | Цвет подписей. |
| `--sf-chart-parts-gap-width` | `length` | Ширина промежутков между частями. |

## Доступность

- Роль: `figure`.
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, `Enter`, `Space`, `Escape`.
- Фокус: Одна остановка Tab на полосе, затем кнопка таблицы. Описание словами — это описание полосы; каждое перемещение курсора озвучивается вежливо.
