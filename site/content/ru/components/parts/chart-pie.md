# Круговая диаграмма sf-chart-pie

`<sf-chart-pie>` — круговая диаграмма: части одного целого секторами круга или
кольца с суммой в середине. Доли внутри секторов, легенда с долями, которая
скрывает части, подсказка, курсор с клавиатуры, описание словами и те же данные
таблицей.

## Данные

`items` — свойство: список записей или объект столбцов, одна часть на запись.

- `category` — поле названий частей (по умолчанию первое);
- `value` — поле значений (по умолчанию первое числовое);
- `names` — свойство `{категория: «Название»}`.

Сектор бывает только у положительного значения. Ноль, отрицательное число и
пропуск остаются строками таблицы.

```html
<sf-chart-pie id="orders" label="Заказы по каналам, октябрь" category="channel" value="orders" value-format="integer"></sf-chart-pie>
<script>
  orders.names = {web: 'Сайт', shop: 'Магазин'};
  orders.items = [{channel: 'web', orders: 540}, {channel: 'shop', orders: 310}];
</script>
```

## Вид

- `hole="ring"` — кольцо; `total="auto"` пишет в середине сумму видимых частей.
- `max-parts` (по умолчанию 7): сверх этого числа самые маленькие части
  сводятся в «Другое». Таблица сохраняет все строки. Когда данные идут потоком, таблица обновляется не чаще раза в секунду и всегда догоняет последние данные; первые данные и редкие изменения видны в ней сразу.
- `share-labels="inside"` — доля внутри сектора, где она помещается.
- `legend="visible"`: части с долями стоят справа от круга, когда диаграмма
  широкая (от 30rem), и под ним, когда узкая. Решает CSS, поэтому первая
  отрисовка не сдвигается.
- `value-format`, `size`, `table`, `summary` — как у `sf-chart-bar`.

## Цвета

`colors` — свойство, свой цвет части: объект «категория → цвет». Цвет — роль Framework
(`primary`, `secondary`, `tertiary`, `neutral`, `success`, `warning`, `error`, `info`): берётся её графический тон, и он сам меняется со светлой и тёмной
темой. Запасной путь — любой CSS-цвет или переменная (`#0a7f6f`,
`var(--brand)`).

```html
<sf-chart-pie id="orders" label="Заказы по каналам" category="channel" value="orders"></sf-chart-pie>
<script>
  orders.colors = {web: 'primary', shop: 'tertiary', phone: 'neutral'};
</script>
```

- Без цвета часть (и всегда «Другое») берёт цвет палитры по своему месту, как раньше.
- Цвет держится за ключ, а не за порядок: переставили данные — цвета остались.
  Сервер может напечатать его в JSON-блоке `data-sf-settings`, как `items`.
  Один и тот же `colors` на нескольких графиках страницы красит одну категорию
  одинаково.
- Не цвет (опечатка, текст) отбрасывается с сообщением в консоли. Цвет с
  контрастом ниже 3:1 к фону графика рисуется, но консоль предупреждает.
- В режиме высокой контрастности цвета заменяет система; ряды различаются
  штрихом и формой.

**Готовые наборы.** `palette` — набор цветов по порядку частей: каждый цвет —
пара для светлой и тёмной темы, контраст не ниже 3:1 к фонам 0–2 в обеих.

| `palette` | Цветов | Для чего |
|---|---|---|
| `theme` (по умолчанию) | 4 | тона темы, как раньше |
| `vivid` | 8 | разноцветный, первый — цвет бренда; первые пять различимы и при дальтонизме |
| `soft` | 8 | приглушённый |
| `warm` | 6 | тёплые тона |
| `cool` | 6 | холодные тона |
| `brand` | 4 | ступени основного цвета темы, для упорядоченных данных |

Когда частей больше, чем цветов в наборе, набор начинается сначала.
`colors` сильнее набора для тех частей, которые называет.

```html
<sf-chart-pie palette="vivid" …></sf-chart-pie>
```

## Клавиатура и доступность

Диаграмма — одна остановка Tab. Стрелки вправо и вниз идут к следующей части по
часовой стрелке, влево и вверх — назад, Home и End — к первой и последней. Шаг
звучит: «Сайт: 54 % (540)». Enter и пробел выбирают часть, Escape убирает курсор.

Фраза о данных: «Частей: 4, всего 1 000. Сайт: 54 % (540). …», по убыванию.

## События, действия и значения

- `sf-chart-pie-toggle` `{id, hidden}` — часть скрыта или показана кнопкой
  легенды. `hiddenParts` — категории скрытых частей (для «Другое» — `other`);
  доли остальных считаются от оставшегося.
- `sf-chart-pie-select` `{series, index, x, value}`: `x` — категория, `index` —
  строка данных (у «Другое» — −1).
- `sf-chart-pie-refresh` — повтор из состояния ошибки.
- `reset()` — показать все части.

## Параметры

Справочник собран из манифеста компонента в сборке набора с коммита `993536a2f943` и обновляется вместе с ней. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `y-format` — `yFormat`.

| | |
|:---|:---|
| Тег | `<sf-chart-pie>` |
| Назначение | Круговая диаграмма: части одного целого как секторы круга или кольца с итогом посередине, самые малые сворачиваются в «Другое»; доли внутри секторов, легенда, которая скрывает части, подсказка, курсор с клавиатуры, описание словами и те же данные в виде таблицы. |
| Контракт | `smart.chart-pie`, версия `0.3.0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `label` — `string`, по умолчанию пусто. Что показывает график, в нескольких словах: его доступное имя, подпись таблицы и имя файла экспорта. На практике обязателен: без него график называется «Диаграмма».
- `palette` — `string`, по умолчанию `theme`, значения: `theme`, `vivid`, `soft`, `warm`, `cool`, `brand`. Цвета частей как именованный набор, по порядку; у каждого есть светлый и тёмный тон, которые меняются вместе с темой и держат контраст 3:1 к поверхностям 0-2: theme (собственные тона темы, как раньше), vivid (8, первый — цвет бренда), soft (8, приглушённые), warm (6), cool (6), brand (4 ступени семейства primary, для упорядоченных данных). Когда набор заканчивается, он начинается снова. colors приоритетнее для названных в нём частей.
- `category` — `string`, по умолчанию пусто. Поле с названиями частей; если не задано, берётся первое поле.
- `value` — `string`, по умолчанию пусто. Поле со значениями частей; если не задано, берётся первое числовое поле, кроме category.
- `hole` — `string`, по умолчанию `none`, значения: `none`, `ring`. none: сплошной круг; ring: кольцо с итогом посередине.
- `total` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: кольцо пишет в середине итог показанных частей; none: середина остаётся пустой.
- `share-labels` — `string`, по умолчанию `inside`, значения: `inside`, `none`. inside: доля каждой части пишется в её секторе, где помещается; none: долю называют легенда и подсказка.
- `max-parts` — `number`, по умолчанию `7`. Если частей больше этого числа, самые малые сворачиваются в одну «Другое», чтобы не было узких секторов; таблица сохраняет все строки.
- `legend` — `string`, по умолчанию `visible`, значения: `visible`, `none`. visible: части с долями рядом с областью графика, когда график широкий, и под ней, когда узкий; каждая часть — кнопка, которая скрывает и показывает её.
- `tooltip` — `string`, по умолчанию `part`, значения: `part`, `none`. part: под указателем или курсором показываются название, доля и значение части.
- `category-label` — `string`, по умолчанию пусто. Название частей: первый столбец таблицы (если не задано, берётся имя поля category).
- `value-label` — `string`, по умолчанию пусто. Название значений: второй столбец таблицы (если не задано, имя поля `value`).
- `value-format` — `string`, по умолчанию `number`. number, integer, `decimal-<n>`, percent (доля 0..1), compact или `currency-<CODE>`, на языке страницы.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень размера: высота области графика (диаметр круга), текст и промежутки. 1/2 для карточки, 2 для отдельной страницы.
- `table` — `string`, по умолчанию `toggle`, значения: `toggle`, `visible`, `hidden`. Те же данные в виде таблицы: toggle даёт кнопку, которая заменяет область графика таблицей, visible показывает её под областью графика, hidden оставляет только для программ чтения с экрана. Никогда none: таблица — это текст графика.
- `summary` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: предложение о целом (сколько частей, итог, доля и значение каждой части, наибольшая первой); читается перед областью графика и доступно программам чтения с экрана. Слот description добавляет слова страницы.
- `data-state` — `string`, по умолчанию `auto`, значения: `auto`, `loading`, `ready`, `empty`, `error`. auto: ready при наличии данных, иначе empty. loading рисует рамку без секторов; error предлагает «Повторить», что отправляет refresh.
- `items` — `array`, по умолчанию `[]`. Данные: список записей ([{channel, orders}, …]) или объект столбцов; одна часть на категорию. Сектором становится только положительное значение; ноль, отрицательное или отсутствующее значение остаётся в таблице и отмечено там.
- `names` — `object`, по умолчанию `{}`. Как называется каждая часть, по её категории: {web: «Сайт»}. Часть без названия называется по своей категории.
- `colors` — `object`, по умолчанию `{}`. Какого цвета каждая часть, по её категории: {Сайт: 'primary', Почта: 'tertiary'}. Цвет — это роль Framework (primary, secondary, tertiary, neutral, success, warning, error, info), которая следует теме, либо любой цвет или переменная CSS; всё остальное отбрасывается с сообщением в консоль, так же как цвет с контрастом ниже 3:1 к фону (он всё равно рисуется). Часть без цвета берёт палитру по своему месту; «Другое» всегда.
- `hidden-parts` — `array`, по умолчанию `[]`. Категории частей, которые пользователь скрыл легендой («other» для «Другое»); доли остальных считаются от оставшегося.

## События

События приходят на сам элемент и всплывают.

- `sf-chart-pie-toggle` — `detail`: `{ id: string, hidden: boolean }`. Пользователь скрыл или показал часть кнопкой легенды; применяется сразу (локальное переключение из словаря).
- `sf-chart-pie-select` — `detail`: `{ series: string, index: number, x: string, value: number }`. Пользователь выбрал часть: щёлкнул по её сектору или нажал Enter или Пробел на курсоре с клавиатуры. x — её категория так, как она задана в данных (пусто для «Другое»), index — её строка (-1 для «Другое»).
- `sf-chart-pie-refresh` — `detail` не описан. Человек снова запросил данные из состояния ошибки; страница загружает их и задаёт `items`.

## Методы

- `reset()` — возвращает `object`. Снова показывает все части и убирает курсор.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-chart-pie-height` | `length` | Высота области графика. |
| `--sf-chart-pie-label-color` | `color` | Цвет подписей. |
| `--sf-chart-pie-hover-background-color` | `color` | Цвет фона при наведении. |
| `--sf-chart-pie-hidden-color` | `color` | Цвет скрытой части. |
| `--sf-chart-pie-gap-width` | `length` | Ширина промежутков между секторами. |

## Доступность

- Роль: `figure`.
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, `Enter`, `Space`, `Escape`.
- Фокус: Одна остановка Tab на области графика, затем кнопки легенды и кнопка таблицы. Описание словами служит описанием области графика; каждое движение курсора озвучивается вежливо.
