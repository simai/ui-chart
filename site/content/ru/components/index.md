# Компоненты SIMAI Chart

Девятнадцать графиков набора, сгруппированных по тому, что они показывают.
Каждый — тег `sf-chart-*`. У каждого есть подсказка, курсор с клавиатуры,
описание данных словами и те же данные таблицей. На странице графика — живые
примеры и полный справочник: атрибуты, события, методы, CSS-переменные.

Не знаете, какой график выбрать? Начните с рецепта
[Как выбрать график](/ru/guide/recipes/choose/).

## Динамика и сравнение

| Компонент | Что показывает |
|:---|:---|
| [Линейный график](trends/chart-line/) `sf-chart-line` | ряды по времени, числу или категориям линиями или стопкой площадей |
| [Столбчатая диаграмма](trends/chart-bar/) `sf-chart-bar` | значения по категориям рядом, стопкой или долями, гистограмма и столбцы с линиями |
| [Мини-график](trends/chart-sparkline/) `sf-chart-sparkline` | один ряд размером со слово для таблиц и плиток |
| [Свечной график](trends/chart-candlestick/) `sf-chart-candlestick` | открытие, максимум, минимум и закрытие за каждый период |
| [Каскадный график](trends/chart-waterfall/) `sf-chart-waterfall` | как начальное значение становится конечным через рост и падение |

## Доли и состав

| Компонент | Что показывает |
|:---|:---|
| [Круговая диаграмма](parts/chart-pie/) `sf-chart-pie` | части одного целого секторами круга или кольца |
| [Полоса частей](parts/chart-parts/) `sf-chart-parts` | части одного целого тонкой полосой, со свободным остатком ёмкости |
| [Плиточная диаграмма](parts/chart-treemap/) `sf-chart-treemap` | из каких частей состоит целое, площадями прямоугольников |
| [Солнечные круги](parts/chart-sunburst/) `sf-chart-sunburst` | иерархия кольцами вокруг центра |
