# Мини-график

:badge[sf-chart-sparkline]{variant=main scheme=on-surface size=1} :badge[Предварительная версия]{variant=tonal scheme=warning size=1}

`<sf-chart-sparkline>` — мини-график: один ряд линией, площадью или столбиками, без
осей. Ставится в ячейку таблицы, в строку текста или в слот `chart` плитки
`sf-chart-metric`.

## Данные

`items` — свойство: список чисел, список записей или объект столбцов.

- Для списка чисел порядок — порядок списка.
- Для записей `x` называет поле порядка (по умолчанию первое), `y` — поле значений
  (по умолчанию первое числовое).

Пропуск (`null`, пустая строка, слово) — разрыв, а не ноль.

```html
<sf-chart-sparkline id="visits" label="Посещения, 12 недель" y-format="integer"></sf-chart-sparkline>
<script>
  visits.items = [340, 362, 355, 401, 395, 410, 430, 452, 440, 461, 470, 488];
</script>
```

## Вид

- `shape` — `line` (по умолчанию), `area` (с заливкой) или `bar` (столбики от нуля).
- `curve` — `linear`, `step` или `smooth` (кривая не выходит за точки).
- `mark` — точка на последнем значении (`last`, по умолчанию), на наибольшем и
  наименьшем (`extremes`) или без точек (`none`).
- `y-zero` — шкала включает ноль; у `bar` всегда.
- `size` — высота по лестнице размеров: `1/2` (20 px, строка мелкого текста),
  `1` (32 px, строка таблицы), `2` (64 px, плитка показателя).
- Ширина — `--sf-chart-sparkline-width` (по умолчанию 128 px); в слоте плитки он
  растягивается по ширине.

## Цвет

`color` — цвет линии, заливки и столбиков. Роль Framework (`primary`, `secondary`, `tertiary`, `neutral`, `success`, `warning`, `error`, `info`) берёт
свой графический тон и меняется с темой; запасной путь — любой CSS-цвет или
переменная. Настройка сильнее переменной `--sf-chart-sparkline-color`. Не цвет
отбрасывается с сообщением в консоли; цвет с контрастом ниже 3:1 к фону
рисуется, но консоль предупреждает.

```html
<sf-chart-sparkline label="Оплаты" color="success"></sf-chart-sparkline>
```

## Доступность

Мини-график — изображение, а не элемент управления: у него нет места в порядке
Tab, подсказки и событий. Имя — подпись и фраза о данных:
«Посещения, 12 недель: от 340 до 488, наибольшее 488, наименьшее 340».
`summary="none"` оставляет одну подпись, когда текст рядом уже говорит это.
`y-format` задаёт, как числа звучат во фразе.

Если человеку нужны сами значения, это `sf-chart-line` с осями и таблицей.

## Состояния

- `data-state="auto"`: с данными — график, без них — пунктирная линия и «нет
  данных».
- `loading`: держит размер тихим блоком, ничего не сдвигается при приходе данных.
- Ошибку показывает окружение (таблица, `sf-chart-metric`).

## Параметры

Справочник собран из манифеста компонента в сборке набора с коммита `9a87c74363ea` и обновляется вместе с ней. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `y-format` — `yFormat`.

| | |
|:---|:---|
| Тег | `<sf-chart-sparkline>` |
| Назначение | Мини-график: один ряд в виде линии, области или столбцов размером со слово, без осей, для ячейки таблицы, строки текста или плитки с метрикой; назван своей подписью и предложением о том, что делают данные. |
| Контракт | `smart.chart-sparkline`, версия `0.2.0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `label` — `string`, по умолчанию пусто. Что показывает мини-график, в нескольких словах: начало его доступного имени, перед предложением о том, что делают данные. Без неё мини-график называется «Мини-график».
- `x` — `string`, по умолчанию пусто. Для записей: поле порядка (время, число или категории); если не задано — первое поле. Список чисел идёт в собственном порядке.
- `y` — `string`, по умолчанию пусто. Для записей: поле значений; если не задано — первое числовое поле, кроме x.
- `shape` — `string`, по умолчанию `line`, значения: `line`, `area`, `bar`. line: одна линия; area: линия с слегка залитой областью под ней; bar: один тонкий столбец на значение, от нуля.
- `curve` — `string`, по умолчанию `linear`, значения: `linear`, `step`, `smooth`. linear соединяет точки прямыми; step держит значение до следующей точки; smooth — кривая, которая не выходит за пределы своих точек.
- `mark` — `string`, по умолчанию `last`, значения: `last`, `extremes`, `none`. Точка на последнем значении (last), на наибольшем и наименьшем (extremes) или none. Для bar отмеченные столбцы рисуются полным тоном.
- `color` — `string`, по умолчанию пусто. Цвет линии, области и столбцов: роль цвета Framework (primary, secondary, tertiary, neutral, success, warning, error, info), которая следует теме, либо любой цвет или переменная CSS. Приоритет выше, чем у --sf-chart-sparkline-color; значение, не являющееся цветом, отбрасывается с сообщением в консоль, как и цвет с контрастом ниже 3:1 к фону (но он всё равно рисуется).
- `y-zero` — `boolean`, по умолчанию `false`. Ось значений включает ноль. bar делает так всегда.
- `y-format` — `string`, по умолчанию `number`. Как значения произносятся в доступном предложении: number, integer, `decimal-<n>`, percent (доля 0..1), compact или `currency-<CODE>`, на языке страницы.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень размера: высота. 1/2 подходит для строки мелкого текста или плотной таблицы, 1 — для строки таблицы, 2 — для плитки с метрикой.
- `summary` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: доступное имя после подписи говорит, что делают данные (первое и последнее значение, наибольшее и наименьшее); none: только подпись, когда окружающий текст уже это говорит.
- `data-state` — `string`, по умолчанию `auto`, значения: `auto`, `loading`, `ready`, `empty`. auto: ready при наличии данных, empty без них. loading держит рамку с тихой заглушкой; empty рисует пунктирную базовую линию и говорит «нет данных».
- `items` — `array`, по умолчанию `[]`. Данные: список чисел ([3, 5, 4]), список записей ([{day, visits}, …]) или объект со столбцами. Отсутствующее значение (null, '', слово) — пропуск, а не ноль.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-chart-sparkline-width` | `length` | Ширина мини-графика. |
| `--sf-chart-sparkline-height` | `length` | Высота мини-графика. |
| `--sf-chart-sparkline-color` | `color` | Цвет линии, области и столбцов. |
| `--sf-chart-sparkline-mark-color` | `color` | Цвет отметок. |
| `--sf-chart-sparkline-line-width` | `length` | Толщина линии. |

## Доступность

- Роль: `img`.
- Доступное имя: обязательно.
- Фокус: Нет: не входит в Tab-порядок. Доступное имя — подпись и предложение о том, что делают данные.
