# Линейный график sf-chart-line

`<sf-chart-line>` — линейный график: один или несколько рядов по времени, по
числу или по категориям. Оси, сетка, легенда, которая скрывает ряды, подсказка
под указателем, курсор с клавиатуры, описание словами и те же данные таблицей.

## Данные

`items` — свойство: список записей или объект столбцов. Поля называют атрибуты:

- `x` — поле по горизонтали (по умолчанию первое);
- `y` — поле значений или список через запятую, один ряд на поле;
- `series` — длинная форма: один ряд на каждое значение этого поля.

Пропущенное значение (`null`, пустая строка, слово) — разрыв линии, а не ноль.
`gaps="connect"` соединяет точки вокруг разрыва. `names` — свойство
`{ключ: «Название»}` для подписей рядов.

```html
<sf-chart-line id="sales" label="Продажи и план, 2026" x="month" y="sales,plan" y-format="integer"></sf-chart-line>
<script>
  sales.names = {sales: 'Продажи', plan: 'План'};
  sales.items = [
    {month: '2026-01', sales: 120, plan: 125},
    {month: '2026-02', sales: 132, plan: 130},
  ];
</script>
```

## Оси и вид

- `x-scale`: `auto` (даты — время, числа — числовая ось, остальное —
  категории), `time`, `linear`, `category`.
- `y-min`, `y-max`, `y-zero` — границы оси значений; `y-zero` включает ноль.
- `x-label`, `y-label` — названия осей; `x-format`, `y-format` — формат
  (`number`, `integer`, `decimal-2`, `percent`, `compact`, `currency-RUB`; для
  времени `auto`, `short`, `medium`, `long`, `full`). Числа и даты — на языке
  страницы.
- `curve`: `linear`, `step`, `smooth` (кривая не выходит за точки).
- `area` — заливка под линией; `markers`: `auto`, `always`, `none`.
- `grid`: `y`, `x`, `both`, `none`; `legend`: `auto`, `top`, `bottom`, `none`.
- `size`: `1/2`, `1`, `2` — высота графика, текст и отступы.

## Стопка

`stack` складывает ряды слоями:

- `none` (по умолчанию) — каждая линия по своим значениям;
- `stacked` — ряды лежат друг на друге: линия — верх своего слоя, заливка —
  полоса до слоя под ним; положительные значения растут вверх от нуля,
  отрицательные — вниз;
- `normalized` — в каждой точке слои составляют 100 %, ось подписана
  процентами, подсказка и курсор говорят долю и само значение: «Сайт: 50 %
  (42)».

Слой в стопке залит всегда, `area` для него не нужен. Пропуск остаётся
разрывом своего слоя и ничего не добавляет к стопке: слои над ним в этой
точке опускаются. Скрытый в легенде ряд выходит из стопки, остальные
складываются заново. Описание графика добавляет, что ряды сложены.

```html
<sf-chart-line id="channels" label="Доля каналов" x="month" y="web,shop,partners" stack="normalized"></sf-chart-line>
```

## Цвета

`colors` — свойство, свой цвет ряда: объект «ключ ряда → цвет». Цвет — роль Framework
(`primary`, `secondary`, `tertiary`, `neutral`, `success`, `warning`, `error`, `info`): берётся её графический тон, и он сам меняется со светлой и тёмной
темой. Запасной путь — любой CSS-цвет или переменная (`#0a7f6f`,
`var(--brand)`).

```html
<sf-chart-line id="sales" label="Продажи и план" x="month" y="sales,plan"></sf-chart-line>
<script>
  sales.colors = {sales: 'primary', plan: 'neutral'};
</script>
```

- Без цвета ряд берёт цвет палитры по своему месту, как раньше.
- Цвет держится за ключ, а не за порядок: переставили данные — цвета остались.
  Сервер может напечатать его в JSON-блоке `data-sf-settings`, как `items`.
  Один и тот же `colors` на нескольких графиках страницы красит одну категорию
  одинаково.
- Не цвет (опечатка, текст) отбрасывается с сообщением в консоли. Цвет с
  контрастом ниже 3:1 к фону графика рисуется, но консоль предупреждает.
- В режиме высокой контрастности цвета заменяет система; ряды различаются
  штрихом и формой.

**Готовые наборы.** `palette` — набор цветов по порядку рядов: каждый цвет —
пара для светлой и тёмной темы, контраст не ниже 3:1 к фонам 0–2 в обеих.

| `palette` | Цветов | Для чего |
|---|---|---|
| `theme` (по умолчанию) | 4 | тона темы, как раньше |
| `vivid` | 8 | разноцветный, первый — цвет бренда; первые пять различимы и при дальтонизме |
| `soft` | 8 | приглушённый |
| `warm` | 6 | тёплые тона |
| `cool` | 6 | холодные тона |
| `brand` | 4 | ступени основного цвета темы, для упорядоченных данных |

Когда рядов больше, чем цветов в наборе, набор начинается сначала.
`colors` сильнее набора для тех рядов, которые называет.

```html
<sf-chart-line palette="vivid" …></sf-chart-line>
```

## Доступность

График — `figure` с названием из `label`. Область графика — одна остановка
Tab (`role="group"`, «график»), описанная фразой о данных: диапазон, первое и
последнее значение каждого ряда, наибольшее и наименьшее. Свои слова хост
кладёт в слот `description`.

Клавиши на графике: ← → — по точкам, ↑ ↓ — по рядам, Home и End — к краям,
Page Up и Page Down — на десятую часть (больше 200 точек — шаг сотая часть).
Каждый шаг объявляется вежливо. Enter и Пробел выбирают точку, Esc убирает
курсор.

`table`: `toggle` (по умолчанию) — кнопка «Таблица» показывает те же данные
таблицей; `visible` — таблица под графиком; `hidden` — таблица только для
чтения с экрана. Варианта «без таблицы» нет.
Когда данные идут потоком, таблица обновляется не чаще раза в секунду и всегда догоняет последние данные; первые данные и редкие изменения видны в ней сразу.

Цвет — не единственное различие: в режиме высокой контрастности у каждого ряда
свой пунктир. Анимация выключена при `prefers-reduced-motion`.

## Состояния

`data-state`: `auto` (данные есть — `ready`, нет — `empty`), `loading` —
рамка без линий, `empty`, `error` — с кнопкой «Повторить», которая отправляет
`sf-chart-line-refresh`.

## События и действия

- `sf-chart-line-toggle {id, hidden}` — человек скрыл или показал ряд в легенде;
  значение `hiddenSeries` хранит скрытые.
- `sf-chart-line-select {series, index, x, value}` — выбрана точка.
- `sf-chart-line-refresh` — просьба загрузить данные заново.
- `reset()` — показать все ряды и убрать курсор.

## Много точек

Больше двух точек на столбец пикселей линия рисуется по первой, наименьшей,
наибольшей и последней точке столбца (`decimate="auto"`): 10 000 точек
выглядят как четыреста, пики остаются.

## Параметры

Справочник собран из манифеста компонента в сборке набора с коммита `993536a2f943` и обновляется вместе с ней. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `y-format` — `yFormat`.

| | |
|:---|:---|
| Тег | `<sf-chart-line>` |
| Назначение | График-линия: один или несколько рядов по времени, числу или категориям, с осями, легендой, которая скрывает ряды, подсказкой, курсором с клавиатуры, описанием словами и теми же данными в виде таблицы. |
| Контракт | `smart.chart-line`, версия `0.4.0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `label` — `string`, по умолчанию пусто. Что показывает график, в нескольких словах: его доступное имя, подпись таблицы и имя файла экспорта. На практике обязателен: без него график называется «График».
- `palette` — `string`, по умолчанию `theme`, значения: `theme`, `vivid`, `soft`, `warm`, `cool`, `brand`. Цвета рядов как именованный набор по порядку: у каждого светлый и тёмный тон, которые меняются с темой и держат контраст 3:1 с поверхностями 0–2. theme (собственные тона темы, как раньше), vivid (8, первый — цвет бренда), soft (8, приглушённые), warm (6), cool (6), brand (4 ступени семейства primary, для упорядоченных данных). Когда набор кончается, он начинается заново. `colors` главнее для названных в нём рядов.
- `x` — `string`, по умолчанию пусто. Поле для горизонтальной оси; если не задано, берётся первое поле.
- `y` — `string`, по умолчанию пусто. Поле значений или список полей через запятую, по одному ряду на поле (широкая форма); если не задано, берётся каждое числовое поле.
- `series` — `string`, по умолчанию пусто. Длинная форма: по одному ряду на каждое различное значение этого поля, значения берутся из первого поля `y`.
- `x-scale` — `string`, по умолчанию `auto`, значения: `auto`, `time`, `linear`, `category`. auto определяет тип по значениям x: даты — время, числа — линейная шкала, всё остальное — категории в заданном порядке.
- `y-min` — `number`. Низ оси значений; если не задан, берётся минимум данных.
- `y-max` — `number`. Верх оси значений; если не задан, берётся максимум данных.
- `y-zero` — `boolean`, по умолчанию `false`. Ось значений включает ноль, чтобы изменение было видно относительно целого, а не только диапазона.
- `curve` — `string`, по умолчанию `linear`, значения: `linear`, `step`, `smooth`. linear соединяет точки прямыми; step держит значение до следующей точки; smooth — кривая, которая не выходит за пределы своих точек.
- `area` — `boolean`, по умолчанию `false`. Слегка заливает область под каждой линией, до нуля или до низа оси.
- `stack` — `string`, по умолчанию `none`, значения: `none`, `stacked`, `normalized`. none: каждая линия по своим значениям; stacked: ряды слоями друг на друге, каждая линия — верх своего слоя, а её область — зона под ним, положительные значения вверх от нуля, отрицательные вниз; normalized: слои как доли целого в каждой точке x, 0–100 %.
- `gaps` — `string`, по умолчанию `break`, значения: `break`, `connect`. break: линия обрывается там, где нет значения; connect: она соединяет точки по обе стороны от пропуска.
- `markers` — `string`, по умолчанию `auto`, значения: `auto`, `always`, `none`. Точка у каждого значения: auto рисует их, пока хватает места (не меньше 12 px на точку), always и none задают явно.
- `legend` — `string`, по умолчанию `auto`, значения: `auto`, `top`, `bottom`, `none`. auto показывает легенду над областью графика, когда рядов два или больше. Каждая запись — кнопка, которая скрывает и показывает свой ряд.
- `tooltip` — `string`, по умолчанию `axis`, значения: `axis`, `none`. axis: под указателем или курсором показываются значения всех рядов при этом x.
- `grid` — `string`, по умолчанию `y`, значения: `y`, `x`, `both`, `none`. Какие направляющие линии график рисует поперёк области графика.
- `x-label` — `string`, по умолчанию пусто. Название горизонтальной оси, подписывается под ней; если не задано, заголовком первого столбца таблицы служит имя поля x.
- `y-label` — `string`, по умолчанию пусто. Название оси значений, подписывается над ней.
- `x-format` — `string`, по умолчанию `auto`. Для оси времени: auto или стиль даты Intl (short, medium, long, full). Для линейной оси: числовой формат, как у y-format.
- `y-format` — `string`, по умолчанию `number`. number, integer, `decimal-<n>`, percent (доля 0..1), compact или `currency-<CODE>`, на языке страницы.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень размера: высота области графика, текст и промежутки. 1/2 для карточки, 2 для отдельной страницы.
- `table` — `string`, по умолчанию `toggle`, значения: `toggle`, `visible`, `hidden`. Те же данные в виде таблицы: toggle даёт кнопку, которая заменяет область графика таблицей, visible показывает её под областью графика, hidden оставляет только для программ чтения с экрана. Никогда none: таблица — это текст графика.
- `summary` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: предложение о том, что делают данные (диапазон, первое и последнее значение каждого ряда, его пик); читается перед областью графика и показывается под ней для программ чтения с экрана. Слот description добавляет слова страницы.
- `data-state` — `string`, по умолчанию `auto`, значения: `auto`, `loading`, `ready`, `empty`, `error`. auto: ready при наличии данных, иначе empty. loading рисует рамку без линий; error предлагает «Повторить», что отправляет refresh.
- `decimate` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: если точек больше двух на пиксельный столбец, линия оставляет в каждом столбце первую, наименьшую, наибольшую и последнюю точки, поэтому десять тысяч точек рисуются как четыреста и каждый пик сохраняется.
- `items` — `array`, по умолчанию `[]`. Данные: список записей ([{month, sales}, …]) или объект столбцов ({month: [...], sales: [...]}). Отсутствующее значение (null, '', слово) — пропуск, а не ноль.
- `names` — `object`, по умолчанию `{}`. Как называется каждый ряд, по его ключу: {sales: «Продажи»}. Ряд без имени называется своим ключом.
- `colors` — `object`, по умолчанию `{}`. Какого цвета каждый ряд, по его ключу: {fact: 'primary', plan: 'neutral'}. Цвет — роль цвета Framework (primary, secondary, tertiary, neutral, success, warning, error, info), которая следует за темой, или любой цвет или переменная CSS; всё остальное отбрасывается с записью в консоль, как и цвет с контрастом ниже 3:1 к фону (но всё равно рисуется). Ряд без цвета берёт палитру по порядку. В режиме принудительных цветов ряд различается штрихом.
- `hidden-series` — `array`, по умолчанию `[]`. Ключи рядов, которые человек скрыл через легенду.

## События

События приходят на сам элемент и всплывают.

- `sf-chart-line-toggle` — `detail`: `{ id: string, hidden: boolean }`. Человек скрыл или показал ряд кнопкой легенды; применяется сразу (локальное переключение из словаря).
- `sf-chart-line-select` — `detail`: `{ series: string, index: number, x: string, value: number }`. Пользователь выбрал точку: щёлкнул по области графика или нажал Enter или Пробел на курсоре с клавиатуры.
- `sf-chart-line-refresh` — `detail` не описан. Человек снова запросил данные из состояния ошибки; страница загружает их и задаёт `items`.

## Методы

- `reset()` — возвращает `object`. Снова показывает все ряды и убирает курсор.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-chart-line-height` | `length` | Высота области графика. |
| `--sf-chart-line-grid-color` | `color` | Цвет линий сетки. |
| `--sf-chart-line-baseline-color` | `color` | Цвет базовой линии. |
| `--sf-chart-line-label-color` | `color` | Цвет подписей. |
| `--sf-chart-line-hover-background-color` | `color` | Цвет фона при наведении. |
| `--sf-chart-line-hidden-color` | `color` | Цвет скрытого ряда. |
| `--sf-chart-line-line-width` | `length` | Толщина линий. |

## Доступность

- Роль: `figure`.
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, `PageUp`, `PageDown`, `Enter`, `Space`, `Escape`.
- Фокус: Одна остановка Tab на области графика, затем кнопки легенды и кнопка таблицы. Описание словами служит описанием области графика; каждое движение курсора озвучивается вежливо.
