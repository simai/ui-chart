# Каскадный график sf-chart-waterfall

`<sf-chart-waterfall>` — каскадный график: как начальное значение
превращается в конечное через шаги роста и снижения. Например, мост
прибыли от прошлого года к этому. Подсказка, курсор с клавиатуры, описание
словами и те же данные таблицей.

Не подходит для независимых значений, которые не складываются: их рисует
`sf-chart-bar`. Изменение по многим периодам лучше показывает
`sf-chart-line`.

## Данные

`items` — свойство: список записей или объект столбцов, строка на шаг.

- `x` — поле названия шага. По умолчанию первое поле, кроме значения и
  отметки итога.
- `y` — поле значения: на шаге это изменение (плюс или минус), на итоговой
  строке — сам итог. По умолчанию первое числовое поле.
- `total` — поле отметки итога (`true`, `1`, «yes» или «да»); по умолчанию
  `total`. Итог стоит на нуле. Без значения он показывает накопленную
  сумму, со значением — сумма дальше считается от него, как от начального
  остатка.
- Шаг без значения пропускается; описание говорит, сколько таких.

```html
<sf-chart-waterfall id="bridge" label="Выручка: 2025 → 2026" x="step" y="value"
  y-label="млн ₽" y-format="integer"></sf-chart-waterfall>
<script>
  bridge.items = [
    {step: 'Выручка 2025', value: 820, total: true},
    {step: 'Новые клиенты', value: 240},
    {step: 'Отток', value: -130},
  ];
</script>
```

## Вид

- Шаг висит от прежней суммы до новой, итог стоит на нуле. Тонкая линия
  соединяет конец каждого столбца с началом следующего.
- В конце сам добавляется итог «Итого», если последняя строка не итог.
  `end="none"` его убирает.
- На каждом столбце написано его значение: изменение со знаком («+240»,
  «−130»), итог — как есть. Если хоть одна подпись не помещается в свою
  полосу, подписей нет совсем. `value-labels="none"` убирает их всегда.
- Ось значений всегда включает ноль: итог — это сумма.
- `y-format`, `x-label`, `y-label`, `grid`, `size` — как у других
  графиков пакета.
- Горизонтальный вид и шаги из нескольких частей в 0.1.0 не рисуются.

## Цвета

По умолчанию рост — тон роли `success`, снижение — `error`, итог —
`neutral`; они меняются со светлой и тёмной темой. `colors` — свойство
`{up, down, total}`: роль Framework или любой CSS-цвет. Знак у значения
остаётся при любом цвете. В режиме высокой контрастности рост — полый
столбец, снижение — залитый, итог — пунктирный.

```html
<script>
  bridge.colors = {up: 'primary', down: 'warning', total: 'secondary'};
</script>
```

## Клавиатура и доступность

График — одна остановка Tab. Стрелки влево и вправо идут от шага к шагу,
Home и End — к краям, Page Up и Page Down — на десятую часть. Каждый шаг
звучит: «Новые клиенты: +240, итог 1 060», итог — «Итого: 1 000». Enter и пробел выбирают шаг
(`sf-chart-waterfall-select`), Escape убирает курсор.

Фраза о данных — число шагов, начальное и конечное значение с изменением,
шаг, который прибавил больше всех, и шаг, который больше всех убавил,
сколько шагов было в плюс и в минус. Таблица всегда есть: кнопкой
(`table="toggle"`), под графиком (`visible`) или только для чтения с экрана
(`hidden`).

## События и действия

- `sf-chart-waterfall-select` `{index, row, x, kind, value, total}` — выбран
  шаг; `index` — его место среди столбцов, `row` — строка в `items` (`-1`
  у добавленного итога), `kind` — `up`, `down` или `total`, `value` —
  изменение (у итога — сам итог), `total` — сумма после шага.
- `sf-chart-waterfall-refresh` — повтор из состояния ошибки.
- `reset()` — убрать курсор.

## Состояния

`data-state`: `auto` (с данными — график, без — «Нет данных»), `loading`
(рамка той же высоты), `empty`, `error` (с «Повторить»).

## Параметры

Справочник собран из манифеста компонента в сборке набора с коммита `35a92dd04007` и обновляется вместе с ней. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `y-format` — `yFormat`.

| | |
|:---|:---|
| Тег | `<sf-chart-waterfall>` |
| Назначение | Каскадная диаграмма: как начальное значение становится конечным через положительные и отрицательные шаги; столбец на шаг на оси значений от нуля, изменение висит от текущей суммы, а итог стоит на нуле, столбцы соединены тонкими линиями, в тонах success, error и neutral, у каждого значения подписан знак; добавляется закрывающий итог; ключ; подсказка; курсор с клавиатуры по шагам; описание словами; те же данные в таблице. |
| Контракт | `smart.chart-waterfall`, версия `0.1.0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `label` — `string`, по умолчанию пусто. Что показывает график, в нескольких словах: его доступное имя и подпись таблицы. На практике обязателен: без него график называется «График».
- `x` — `string`, по умолчанию пусто. Поле имён шагов, в порядке данных; если не задано — первое поле, кроме значения и отметки итога.
- `y` — `string`, по умолчанию пусто. Поле значений: изменение (положительное или отрицательное) на шаге, сам итог в строке итога; если не задано — первое числовое поле, кроме x и отметки итога.
- `total` — `string`, по умолчанию `total`. Поле, которое отмечает строку итога (true, 1, «yes» или «да»). Строка итога стоит на нуле: без значения она показывает текущую сумму, со значением текущая сумма начинается заново от него, как начальный остаток.
- `end` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto закрывает шаги итогом с именем «Итого», если последняя строка уже не итог; none рисует только строки.
- `value-labels` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto пишет значение на каждом столбце, изменение со знаком, а итог как есть, если каждое помещается в свою полосу; none оставляет их подсказке и таблице.
- `legend` — `string`, по умолчанию `auto`, значения: `auto`, `top`, `bottom`, `none`. auto показывает ключ роста, падения и итога над областью графика.
- `tooltip` — `string`, по умолчанию `step`, значения: `step`, `none`. step: под указателем или курсором — имя шага, его изменение и итог, до которого он доходит.
- `grid` — `string`, по умолчанию `value`, значения: `value`, `none`. value рисует направляющие линии поперёк области графика на делениях значений.
- `x-label` — `string`, по умолчанию пусто. Название шагов: под осью и первым столбцом таблицы; если не задано — имя поля x.
- `y-label` — `string`, по умолчанию пусто. Название значения, над осью.
- `y-format` — `string`, по умолчанию `number`. Формат значений: number, integer, `decimal-<n>`, compact, `currency-<CODE>` или `unit-<unit>`, на языке страницы.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень размера: высота области графика, текст и промежутки. 1/2 для карточки, 2 для отдельной страницы.
- `table` — `string`, по умолчанию `toggle`, значения: `toggle`, `visible`, `hidden`. Те же данные в виде таблицы: toggle даёт кнопку, которая заменяет область графика таблицей, visible показывает её под областью графика, hidden оставляет только для программ чтения с экрана. Никогда none: таблица — это текст графика.
- `summary` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: предложение о том, что делают данные (число изменений, начало и конец с изменением между ними, шаг, который добавил больше всего, и шаг, который убрал больше всего, сколько выросло и упало); звучит перед областью графика. Слот description добавляет слова страницы.
- `data-state` — `string`, по умолчанию `auto`, значения: `auto`, `loading`, `ready`, `empty`, `error`. auto: ready при наличии шагов, empty без них. loading рисует рамку без отметок; error предлагает «Повторить», что отправляет refresh.
- `items` — `array`, по умолчанию `[]`. Данные: список записей, по одной на шаг ([{step, value, total}, …]), или объект со столбцами. Шаг — изменение от текущей суммы; строка, отмеченная как итог, стоит на нуле. Изменение без значения отбрасывается; описание словами говорит, сколько их.
- `colors` — `object`, по умолчанию `{}`. Цвета роста, падения и итога: по умолчанию {up: 'success', down: 'error', total: 'neutral'}. Цвет — роль цвета Framework, которая следует теме, либо любой цвет или переменная CSS; всё остальное отбрасывается с сообщением в консоль, как и цвет с контрастом ниже 3:1 к фону (но он всё равно рисуется). Значение каждого столбца сохраняет знак при любом цвете.

## События

События приходят на сам элемент и всплывают.

- `sf-chart-waterfall-select` — `detail`: `{ index: number, row: number, x: string, kind: string, value: number, total: number }`. Человек выбрал шаг: щелчок по его полосе или Enter или Space на курсоре с клавиатуры. index — его место среди столбцов, row — его строка в items (-1 для закрывающего итога, который добавляет график), x — его имя, kind — up, down или total, value — изменение (сам итог для итога), total — уровень, до которого он доходит.
- `sf-chart-waterfall-refresh` — `detail` не описан. Человек снова запросил данные из состояния ошибки; страница загружает их и задаёт `items`.

## Методы

- `reset()` — возвращает `object`. Убирает курсор.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-chart-waterfall-height` | `length` | Высота области графика. |
| `--sf-chart-waterfall-grid-color` | `color` | Цвет линий сетки. |
| `--sf-chart-waterfall-baseline-color` | `color` | Цвет базовой линии. |
| `--sf-chart-waterfall-label-color` | `color` | Цвет подписей. |
| `--sf-chart-waterfall-hover-background-color` | `color` | Цвет фона при наведении. |

## Доступность

- Роль: `figure`.
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `Home`, `End`, `PageUp`, `PageDown`, `Enter`, `Space`, `Escape`.
- Фокус: Одна остановка Tab на области графика, затем кнопка таблицы. Описание словами служит описанием области графика; каждое движение курсора озвучивается вежливо.
