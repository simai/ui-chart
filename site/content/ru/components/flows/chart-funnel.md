# Воронка

:badge[sf-chart-funnel]{variant=main scheme=on-surface size=1} :badge[Предварительная версия]{variant=tonal scheme=warning size=1}

`<sf-chart-funnel>` — воронка: этапы процесса, где каждый следующий — часть
предыдущего. Подходит для воронки продаж, регистрации, пути заказа. Каждый
этап — строка: название, полоса, значение и доля перехода. Есть подсказка,
курсор с клавиатуры, описание словами и те же данные таблицей.

Полосы начинаются от одного края, поэтому их длины сравниваются точно. Форма
трапеции не используется: её скошенные края не несут данных.

## Данные

`items` — свойство: список записей, по одной на этап, в порядке процесса, или
объект столбцов.

- `stage` — поле этапов (по умолчанию первое);
- `value` — поле значений (по умолчанию первое числовое после него);
- `names` — свойство `{ключ: «Название»}` для этапов.

Этапы идут в том порядке, в каком даны: порядок — это сам процесс, воронка
его не сортирует. Этап без значения — пропуск: строка с пунктирной рамкой, без
полосы; доля перехода через пропуск не считается. Этап больше предыдущего
рисуется как есть (доля больше 100 %), а описание говорит, что этапы не
вложены.

```html
<sf-chart-funnel id="order" label="Воронка заказа" stage="step" value="people" value-format="integer"></sf-chart-funnel>
<script>
  order.names = {visit: 'Визиты', cart: 'Корзина', paid: 'Оплата'};
  order.items = [{step: 'visit', people: 12400}, {step: 'cart', people: 2900}, {step: 'paid', people: 860}];
</script>
```

## Вид

- `conversion` — какая доля пишется рядом с этапом: `previous` (по
  умолчанию) — от предыдущего этапа, сколько прошли дальше; `first` — от
  первого, сколько осталось от начала; `none` — только значения. Подсказка,
  описание и таблица всегда говорят обе доли.
- `align` — `start` (по умолчанию): полосы от одного края; `center`: по
  центру, привычная форма воронки — для картинки больше, чем для сравнения.
- `color` — цвет полос: роль Фреймворка (`primary`, `tertiary`, `success` …)
  или любой цвет CSS. Воронка — одна величина, поэтому цвет один на все этапы.
- `size` — высота строки 20, 28 или 36 px и размер текста. Высота воронки —
  это её строки, она известна до первой отрисовки.
- На узком месте (уже 30rem) название этапа стоит над полосой.
- Длинные названия обрезаются с «…».

## Клавиатура и доступность

Этапы — одна остановка Tab, группа с описанием «воронка».

- Вниз и вправо — к следующему этапу, вверх и влево — к предыдущему.
- Home и End — к первому и последнему этапу.
- Каждый шаг говорится вежливо: «Каталог: 7 800, 62,9 % от предыдущего,
  62,9 % от первого».
- Enter и Пробел выбирают этап (`select`), Escape убирает курсор.

Описание говорит число этапов, от какого значения к какому, итоговую
конверсию, где теряется больше всего и сколько пропусков. Таблица: этап,
значение, доля от предыдущего, доля от первого. В режиме высокой
контрастности полосы сплошные, текущая — системным цветом выделения.

## События

- `sf-chart-funnel-select` — `{series, index, x, value}`: поле значений,
  место этапа, его ключ, как в данных, и значение (`null` для пропуска).
- `sf-chart-funnel-refresh` — из состояния ошибки нажали «Повторить».

## Состояния

`data-state`: `auto` (готово с данными, пусто без них), `loading`, `ready`,
`empty`, `error`.

## Параметры

Справочник собран из манифеста компонента в сборке набора с коммита `41a2b6ccf3da` и обновляется вместе с ней. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `y-format` — `yFormat`.

| | |
|:---|:---|
| Тег | `<sf-chart-funnel>` |
| Назначение | Воронка: этапы процесса, каждый — часть предыдущего (визиты, корзина, оплата), в виде полос на общей базовой линии, со значением и конверсией рядом с каждым этапом, подсказкой, курсором с клавиатуры, описанием словами (общая конверсия, где теряется больше всего) и теми же данными в таблице. |
| Контракт | `smart.chart-funnel`, версия `0.1.0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `label` — `string`, по умолчанию пусто. Что показывает график, в нескольких словах: его доступное имя, подпись таблицы и имя файла экспорта. На практике обязателен: без него график называется «Воронка».
- `stage` — `string`, по умолчанию пусто. Поле ключей этапов; если не задано, первое поле.
- `value` — `string`, по умолчанию пусто. Поле значений этапов; если не задано, первое числовое поле, кроме `stage`.
- `conversion` — `string`, по умолчанию `previous`, значения: `previous`, `first`, `none`. Доля, которая пишется рядом с каждым этапом после первого: previous — от предыдущего этапа (сколько прошло дальше); first — от первого этапа (сколько осталось от начала); none — только значения. Подсказка, описание словами и таблица в любом случае приводят обе.
- `align` — `string`, по умолчанию `start`, значения: `start`, `center`. start: все полосы начинаются от одного края, длины сравниваются на общей базовой линии (более надёжное чтение); center: полосы по центру, привычная форма воронки, для картинки, а не для сравнения.
- `color` — `string`, по умолчанию пусто. Цвет полос: роль цвета Framework (primary, secondary, tertiary, neutral, success, warning, error, info), которая следует за темой, или любой цвет или переменная CSS. Главнее `--sf-chart-funnel-color`; значение, не являющееся цветом, отбрасывается с записью в консоль, как и цвет с контрастом ниже 3:1 к фону (но всё равно рисуется). Одна величина, один цвет: этапы различаются по именам и порядку.
- `tooltip` — `string`, по умолчанию `stage`, значения: `stage`, `none`. stage: под указателем или курсором имя этапа, значение, его доля от предыдущего этапа и от первого.
- `stage-label` — `string`, по умолчанию пусто. Название этапов: первый столбец таблицы (если не задано, имя поля `stage`).
- `value-label` — `string`, по умолчанию пусто. Название значений: второй столбец таблицы (если не задано, имя поля `value`).
- `value-format` — `string`, по умолчанию `number`. number, integer, `decimal-<n>`, percent (доля 0..1), compact или `currency-<CODE>`, на языке страницы.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень размера: толщина полос, текст и промежутки. 1/2 для плитки, 2 для отдельной страницы.
- `table` — `string`, по умолчанию `toggle`, значения: `toggle`, `visible`, `hidden`. Те же данные в виде таблицы: toggle даёт кнопку, которая заменяет воронку таблицей, visible показывает её под воронкой, hidden оставляет только для программ чтения с экрана. Никогда none: таблица — это текст графика.
- `summary` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: предложение о целом (сколько этапов, от чего до чего, общая конверсия, где теряется больше всего, пропуски), остаётся для программ чтения с экрана. Слот `description` добавляет слова страницы.
- `data-state` — `string`, по умолчанию `auto`, значения: `auto`, `loading`, `ready`, `empty`, `error`. auto: ready при данных, empty без них. loading рисует места этапов без полос; error предлагает «Повторить», что отправляет `refresh`.
- `items` — `array`, по умолчанию `[]`. Данные: список записей ([{stage, count}, …]) или объект столбцов, по записи на этап в порядке процесса. Этап без значения — пропуск: о нём говорится и он остаётся в таблице, но без полосы и конверсии.
- `names` — `object`, по умолчанию `{}`. Как называется каждый этап, по его ключу: {cart: «Корзина»}. Этап без имени называется своим ключом.

## События

События приходят на сам элемент и всплывают.

- `sf-chart-funnel-select` — `detail`: `{ series: string, index: number, x: string, value: number }`. Человек выбрал этап: щелчок по нему или Enter или Space на курсоре с клавиатуры. `x` — его ключ как в данных, `index` — номер, `value` — значение (null для пропуска).
- `sf-chart-funnel-refresh` — `detail` не описан. Человек снова запросил данные из состояния ошибки; страница загружает их и задаёт `items`.

## Методы

Публичных методов нет.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-chart-funnel-color` | `color` | Цвет полос. |
| `--sf-chart-funnel-label-color` | `color` | Цвет подписей. |
| `--sf-chart-funnel-bar-radius` | `length` | Скругление полос. |

## Доступность

- Роль: `figure`.
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, `Enter`, `Space`, `Escape`.
- Фокус: Одна остановка Tab на этапах, затем кнопка таблицы. Описание словами служит описанием этапов; каждое движение курсора озвучивается вежливо.
