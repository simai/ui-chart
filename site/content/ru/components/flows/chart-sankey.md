# Диаграмма Санки sf-chart-sankey

`<sf-chart-sankey>` — диаграмма Санки: как величина перетекает между
этапами или категориями. Узлы стоят столбцами, от узла к узлу идёт лента,
ширина которой равна потоку. Например, выручка от продуктов и услуг
расходится на зарплаты, маркетинг, аренду и прибыль, а маркетинг — на
поиск и соцсети. Подсказка, курсор с клавиатуры, описание словами и все
потоки таблицей.

Не подходит, когда нужны только числа на этапах: это `sf-chart-funnel`.
Потоки по кругу (из «Корзины» обратно в «Каталог») диаграмма не рисует:
она идёт в одну сторону.

## Данные

`items` — свойство: список записей или объект столбцов, строка на поток.

- `source` и `target` — поля источника и цели, по умолчанию `source` и
  `target`.
- `value` — поле величины потока. По умолчанию первое числовое поле,
  кроме источника и цели.
- Одна и та же пара дважды — один поток с суммой.
- Строка без источника, цели или положительной величины, поток из узла в
  самого себя и поток, который замкнул бы круг, пропускаются; описание
  говорит, сколько таких.

```html
<sf-chart-sankey id="budget" label="Бюджет компании, млн ₽"
  source="from" target="to" value="amount" y-format="integer"></sf-chart-sankey>
<script>
  budget.items = [
    {from: 'Продукты', to: 'Выручка', amount: 520},
    {from: 'Услуги', to: 'Выручка', amount: 280},
    {from: 'Выручка', to: 'Зарплаты', amount: 360},
    {from: 'Выручка', to: 'Прибыль', amount: 210},
  ];
</script>
```

## Вид

- Столбец узла — самый длинный путь до него от узла, в который ничего не
  входит. Узлы, из которых ничего не выходит, стоят в последнем столбце.
- Высота узла — большее из того, что входит и выходит, в одном масштабе
  для всех столбцов. Порядок в столбце подбирается так, чтобы ленты
  меньше пересекались.
- Рядом с узлом — его название и значение (у последнего столбца —
  слева). Название обрезается многоточием по месту между столбцами.
  Слишком тонкий узел остаётся без подписи: его слова — в подсказке и
  таблице. `labels="none"` убирает подписи всегда.
- `y-format` и `size` — как у других графиков пакета. Доля всегда в
  процентах.
- Потоки по кругу, ручная расстановка узлов и приближение в 0.1.0 не
  рисуются.

## Цвета

Узел берёт цвет графиков Framework по своему месту (в порядке первого
появления), его исходящие ленты — светлую заливку того же цвета. `colors` —
свойство `{узел: цвет}`: роль Framework или любой CSS-цвет. В режиме
высокой контрастности узлы — цвета текста, ленты — цвета фона с линией.

## Клавиатура и доступность

График — одна остановка Tab. Курсор ходит по узлам: вверх и вниз — внутри
столбца, вправо — по самому большому исходящему потоку в следующий
столбец, влево — по самому большому входящему назад. Home и End — к
первому и последнему узлу. Каждый узел звучит со своими потоками:
«Выручка: 800; приходит из «Продукты» 520, «Услуги» 280; уходит в
«Зарплаты» 360, «Прибыль» 210, «Маркетинг» 140 и ещё 1». Enter и пробел
выбирают узел (`sf-chart-sankey-select`), Escape убирает курсор. Ленты
показывает указатель: подсказка называет поток, его величину и долю от
источника.

Фраза о данных — число узлов, потоков и этапов, сколько всего входит,
крупнейший поток и узел, в который приходит больше всего. Таблица всегда
есть, строка на поток: кнопкой (`table="toggle"`), под графиком
(`visible`) или только для чтения с экрана (`hidden`).

## События и действия

- `sf-chart-sankey-select` `{index, node, value, in, out}` — выбран узел;
  `index` — его место в порядке первого появления, `node` — название,
  `in` и `out` — что входит и выходит.
- `sf-chart-sankey-refresh` — повтор из состояния ошибки.
- `reset()` — убрать курсор.

## Состояния

`data-state`: `auto` (с данными — график, без — «Нет данных»), `loading`
(рамка той же высоты), `empty`, `error` (с «Повторить»).

## Параметры

Справочник собран из манифеста компонента в сборке набора с коммита `35a92dd04007` и обновляется вместе с ней. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `y-format` — `yFormat`.

| | |
|:---|:---|
| Тег | `<sf-chart-sankey>` |
| Назначение | Диаграмма Санкея: величины, которые перетекают между этапами или категориями; узлы стоят в столбцах по самому длинному пути от начала потоков, полоса от узла к узлу так же широка, как её поток, узел — в цвете графика, а его полосы — в его светлой заливке; названия и значения рядом с узлами, где помещаются; подсказка для узла или полосы; курсор с клавиатуры по узлам вдоль самых больших потоков; описание словами; каждый поток — строка таблицы. |
| Контракт | `smart.chart-sankey`, версия `0.1.0` |
| Жизненный цикл | экспериментальный: API может меняться между выпусками |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `label` — `string`, по умолчанию пусто. Что показывает график, в нескольких словах: его доступное имя и подпись таблицы. На практике обязателен: без него график называется «График».
- `source` — `string`, по умолчанию пусто. Поле источников потоков; если не задано — source.
- `target` — `string`, по умолчанию пусто. Поле получателей потоков; если не задано — target.
- `value` — `string`, по умолчанию пусто. Поле величин потоков, положительных; если не задано — первое числовое поле, кроме источника и получателя.
- `labels` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto пишет имя и значение узла рядом с ним — после него, а в последнем столбце — перед ним, с многоточием по месту между столбцами, если узел и его промежуток высотой в строку. none оставляет их подсказке, живой строке и таблице.
- `tooltip` — `string`, по умолчанию `flow`, значения: `flow`, `none`. flow: под указателем или курсором — имя узла с тем, что входит и что выходит, либо источник и получатель полосы, её значение и доля от источника.
- `y-format` — `string`, по умолчанию `number`. Формат значений: number, integer, `decimal-<n>`, compact, `currency-<CODE>` или `unit-<unit>`, на языке страницы. Доли всегда в процентах.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень размера: высота области графика, текст и промежутки. 1/2 для карточки, 2 для отдельной страницы.
- `table` — `string`, по умолчанию `toggle`, значения: `toggle`, `visible`, `hidden`. Те же данные в виде таблицы: toggle даёт кнопку, которая заменяет область графика таблицей, visible показывает её под областью графика, hidden оставляет только для программ чтения с экрана. Никогда none: таблица — это текст графика.
- `summary` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: предложение о том, что делают данные (узлы, потоки, этапы и общий входящий итог, самый большой поток с долей от источника, узел, в который приходит больше всего); звучит перед областью графика. Слот description добавляет слова страницы.
- `data-state` — `string`, по умолчанию `auto`, значения: `auto`, `loading`, `ready`, `empty`, `error`. auto: ready при наличии потоков, empty без них. loading рисует рамку без отметок; error предлагает «Повторить», что отправляет refresh.
- `items` — `array`, по умолчанию `[]`. Данные: список записей, по одной на поток ([{source, target, value}, …]), или объект со столбцами. Одна пара, названная дважды, — один поток с суммой. Строка без источника, получателя или положительного значения, а также от узла к нему самому отбрасывается; поток, который замкнул бы цикл, тоже отбрасывается, потому что диаграмма идёт в одну сторону; описание словами говорит, сколько их.
- `colors` — `object`, по умолчанию `{}`. Цвета узлов по имени ({Бюджет: 'primary'}): роль цвета Framework, которая следует теме, либо любой цвет или переменная CSS; всё остальное отбрасывается с сообщением в консоль, как и цвет с контрастом ниже 3:1 к фону (но он всё равно рисуется). Узел без цвета берёт цвет графика своего места в порядке, в котором строки впервые называют узлы; полоса берёт цвет своего источника, светлый.

## События

События приходят на сам элемент и всплывают.

- `sf-chart-sankey-select` — `detail`: `{ index: number, node: string, value: number, in: number, out: number }`. Человек выбрал узел: щелчок по нему или Enter или Space на курсоре с клавиатуры. index — его место в порядке, в котором строки впервые называют узлы, node — его имя, value — большее из входящего и исходящего, in и out — эти два значения.
- `sf-chart-sankey-refresh` — `detail` не описан. Человек снова запросил данные из состояния ошибки; страница загружает их и задаёт `items`.

## Методы

- `reset()` — возвращает `object`. Убирает курсор.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-chart-sankey-height` | `length` | Высота области графика. |
| `--sf-chart-sankey-label-color` | `color` | Цвет подписей. |
| `--sf-chart-sankey-hover-background-color` | `color` | Цвет фона при наведении. |

## Доступность

- Роль: `figure`.
- Доступное имя: обязательно.
- Клавиши: `Tab`, `ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`, `Home`, `End`, `PageUp`, `PageDown`, `Enter`, `Space`, `Escape`.
- Фокус: Одна остановка Tab на области графика, затем кнопка таблицы. Описание словами служит описанием области графика; каждое движение курсора озвучивается вежливо.
