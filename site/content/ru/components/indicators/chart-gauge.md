# Шкала sf-chart-gauge

`<sf-chart-gauge>` — шкала: одно измеренное значение на шкале от `min` до
`max`, с зонами (норма, внимание, критично) и отметкой цели. Подходит для
загрузки сервера, оценки, температуры, выполнения плана. Значение написано
крупно, под ним — название зоны; цель и расстояние до неё — строкой под
шкалой.

Шкала — не прогресс задачи: для него есть `sf-progress-bar`,
`sf-progress-ring` и `sf-progress-scale`. Значение относительно лимита в
плитке — `sf-chart-metric` с `max`.

## Данные

- `value` — значение. Без него шкала пустая. Значение за пределами шкалы
  рисуется у её конца и попадает в зону у этого конца (выше «Критично» — тоже
  «Критично»), а описание говорит, что оно за пределами.
- `min`, `max` — начало и конец шкалы (по умолчанию 0 и 100).
- `bands` — свойство: зоны по порядку. Зона начинается там, где кончилась
  предыдущая (первая — с `min`), если не задано `from`. `role` — роль
  Фреймворка: цвет зоны и, без `label`, её название («Норма», «Внимание»,
  «Критично»).
- `target` — опорное значение: план, лимит, среднее. `target-label` — его
  название («Цель» по умолчанию).

```html
<sf-chart-gauge id="cpu" label="Загрузка процессора" value="72" target="80" value-format="unit-percent"></sf-chart-gauge>
<script>
  cpu.bands = [{to: 70, role: 'success'}, {to: 90, role: 'warning'}, {to: 100, role: 'error'}];
</script>
```

## Вид

- `shape` — `arc` (по умолчанию): полукруг со значением внутри, для
  отдельной плитки; `linear`: полоса со значением над ней, для строки или
  тесного места.
- Значение закрашено цветом своей зоны. Вне зон — цветом `color` (роль или
  цвет CSS), по умолчанию основным.
- `size` — ширина дуги (до 160, 256 или 448 px) или толщина полосы и размер
  числа. Высота дуги следует из её ширины, поэтому шкала не «прыгает» при
  загрузке.

## Доступность

Шкала — `meter`: у неё есть начало, конец, значение и текст значения с
названием зоны («72 %, Внимание»). Она не берёт фокус. Описание говорит
значение на шкале и его долю, зону с её границами и расстояние до цели.
Цвет — не единственный признак: зона названа словом. Таблица (по умолчанию
только для экранного диктора): значение, цель и каждая зона с границами. В
режиме высокой контрастности дорожка — рамка, значение и зоны — сплошные,
цель — системным цветом выделения.

## События

- `sf-chart-gauge-refresh` — из состояния ошибки нажали «Повторить».

## Состояния

`data-state`: `auto` (готово со значением, пусто без него), `loading`,
`ready`, `empty`, `error`.

Справочник собран из манифеста компонента в сборке набора с коммита `35a92dd04007` и обновляется вместе с ней. Каждому атрибуту соответствует свойство элемента с тем же именем в camelCase: `y-format` — `yFormat`.

| | |
|:---|:---|
| Тег | `<sf-chart-gauge>` |
| Назначение | Шкала: одно измеренное значение на фиксированной шкале (нагрузка сервера, оценка, температура) в виде полукруга или полосы, с зонами (норма, внимание, критично), каждая своего цвета и имени по роли, меткой цели с расстоянием до неё, значением посередине с именем его зоны, индикатором для программ чтения с экрана, описанием словами и теми же данными в таблице. |

### Атрибуты

- `template` — `string`, по умолчанию `default`. Имя варианта шаблона для внешних шаблонов SfBaseElement.
- `root-class` — `string`, по умолчанию пусто. Классы, которые добавляются корневому элементу, который рисует компонент.
- `root-style` — `string`, по умолчанию пусто. Встроенные стили корневого элемента, который рисует компонент, включая пользовательские свойства.
- `label` — `string`, по умолчанию пусто. Что за значение, в нескольких словах: доступное имя индикатора и подпись таблицы. На практике обязателен: без него шкала называется «Шкала».
- `value` — `number`. Измеренное значение. Если не задано, шкала пустая (`data-state` auto). Значение за пределами шкалы рисуется на её конце, о нём говорится, что оно за пределами, и оно попадает в зону на этом конце (за концом критической зоны — критично).
- `min` — `number`, по умолчанию `0`. Начало шкалы.
- `max` — `number`, по умолчанию `100`. Конец шкалы; он должен быть больше `min`, иначе шкала рисует пустую шкалу и сообщает об этом в консоль.
- `target` — `number`. Опорное значение (план, предел, среднее): метка поперёк шкалы, под ней написано, насколько значение от неё отстоит.
- `target-label` — `string`, по умолчанию пусто. Название цели; если не задано, «Цель».
- `shape` — `string`, по умолчанию `arc`, значения: `arc`, `linear`. arc: полукруг со значением посередине, для отдельной плитки; linear: полоса со значением над ней (по сути bullet-график), для строки или тесного места.
- `color` — `string`, по умолчанию пусто. Цвет значения, когда оно вне зон: роль цвета Framework или любой цвет или переменная CSS (если не задан, primary). Главнее `--sf-chart-gauge-color`; значение, не являющееся цветом, отбрасывается с записью в консоль, как и цвет с контрастом ниже 3:1 к фону (но всё равно рисуется).
- `value-format` — `string`, по умолчанию `number`. number, integer, `decimal-<n>`, percent (доля 0..1), compact или `currency-<CODE>`, на языке страницы.
- `size` — `string`, по умолчанию `1`, значения: `1/2`, `1`, `2`. Ступень размера: ширина дуги (не больше 160, 256 или 448 px) или толщина полосы и текст значения. 1/2 для плитки в ряду, 2 для отдельной страницы.
- `table` — `string`, по умолчанию `hidden`, значения: `toggle`, `visible`, `hidden`. Те же данные в виде таблицы (значение, цель, каждая зона с диапазоном): hidden оставляет её только для программ чтения с экрана, это по умолчанию, так как значение написано на шкале; toggle даёт кнопку, которая заменяет шкалу таблицей; visible показывает её под шкалой.
- `summary` — `string`, по умолчанию `auto`, значения: `auto`, `none`. auto: предложение о целом (значение на шкале и его доля, зона, в которой оно находится, насколько оно от цели), остаётся для программ чтения с экрана. Слот `description` добавляет слова страницы.
- `data-state` — `string`, по умолчанию `auto`, значения: `auto`, `loading`, `ready`, `empty`, `error`. auto: ready при значении, empty без него. loading рисует пустую шкалу; error предлагает «Повторить», что отправляет `refresh`.
- `bands` — `array`, по умолчанию `[]`. Зоны шкалы по порядку: [{to: 70, role: 'success', label: 'Норма'}, {to: 90, role: 'warning'}, {to: 100, role: 'error'}]. Зона начинается там, где кончается предыдущая (с `min` для первой), если не задан `from`. `role` — роль цвета Framework (success, warning, error, neutral …): цвет зоны и, когда нет `label`, её имя («Норма», «Внимание», «Критично»). Значение рисуется цветом своей зоны, а имя зоны пишется под ним, так что цвет никогда не единственный признак.

## События

События приходят на сам элемент и всплывают.

- `sf-chart-gauge-refresh` — `detail` не описан. Человек снова запросил данные из состояния ошибки; страница загружает их и задаёт `items`.

## Методы

Публичных методов нет.

## CSS-переменные

Задаются на элементе или на любом предке.

| Переменная | Тип | Что задаёт |
|:---|:---|:---|
| `--sf-chart-gauge-color` | `color` | Цвет значения. |
| `--sf-chart-gauge-track-color` | `color` | Цвет дорожки шкалы. |
| `--sf-chart-gauge-label-color` | `color` | Цвет подписей. |

## Доступность

- Роль: `figure`.
- Доступное имя: обязательно.
- Клавиши: `Tab`.
- Фокус: Собственной остановки Tab нет: индикатор с текстом значения, описанный словами. Кнопка таблицы, когда она показана, — отдельная кнопка.
