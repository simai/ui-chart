# Данные

Все графики набора принимают данные в одной форме: список записей в
свойстве `items` и атрибуты, которые называют поля. Одни и те же записи
можно отдать линии, столбцам и таблице без пересборки.

## Как это устроено

### Записи и столбцы

`items` — свойство элемента. Оно принимает список записей:

```js
chart.items = [
  {month: '2026-01', sales: 120, plan: 125},
  {month: '2026-02', sales: 132, plan: 130},
];
```

или объект столбцов — те же данные, по списку значений на поле:

```js
chart.items = {
  month: ['2026-01', '2026-02'],
  sales: [120, 132],
  plan: [125, 130],
};
```

Столбцы удобны, когда точек тысячи: такой объект короче, а график читает его
так же, как записи.

### Какое поле что значит

Атрибуты называют поля записи. У линии, столбцов и радара это:

| Атрибут | Что называет |
|:---|:---|
| `x` | поле по горизонтали — месяц, город, навык; без атрибута — первое поле |
| `y` | поле значений или список полей через запятую, один ряд на поле |
| `series` | поле, по значениям которого записи делятся на ряды |

У других графиков поля названы по их смыслу:

| График | Поля |
|:---|:---|
| круговая и полоса частей | `category`, `value` |
| воронка | `stage`, `value` |
| точечная | `x`, `y`, `bubble` (площадь пузырька), `series`, `point` (название точки) |
| ящик с усами | `x` (группы), `y` (мера), `series`; `stats="given"` — готовые `min`, `q1`, `median`, `q3`, `max` |
| свечной | `x`, `open`, `high`, `low`, `close` |
| каскадный | `x`, `y`, `total` (отметка итоговой строки) |
| плиточная | `x`, `y`, `group` |
| тепловая карта | `x` (столбцы), `y` (строки), `value` |
| Санки | `source`, `target`, `value` |
| солнечные круги | `node`, `parent`, `name` или `path`, `value` |
| Ганта | `row`, `start`, `end`, `status` |
| карта | `region`, `value` и границы областей в `shapes` |

Мини-графику достаточно списка чисел: `[340, 362, 355, 401]`. Плитке
показателя и шкале записи не нужны: у них одно значение в атрибуте `value`.
Точные поля каждого графика — на его странице в разделе
[Компоненты](/ru/components/).

### Широкая и длинная форма

Данные приходят в двух формах, и график принимает обе.

**Широкая форма** — как в электронной таблице: одна запись на месяц, ряд —
столбец. Ряды перечисляет `y`:

```html
<sf-chart-line label="Заказы по каналам" x="month" y="web,shop,partners"></sf-chart-line>
```

**Длинная форма** — как из базы данных: одна запись на месяц и канал, ряд —
значение поля. Его называет `series`, а значения берутся из первого поля
`y`:

```html
<sf-chart-line label="Заказы по каналам" x="month" y="orders" series="channel"></sf-chart-line>
```

```js
chart.items = [
  {month: '2026-07', channel: 'web', orders: 42},
  {month: '2026-07', channel: 'shop', orders: 30},
];
```

### Названия рядов

Ключ ряда — имя поля (`sales`) или значение поля `series` (`web`). Человеку
нужны слова, поэтому `names` — свойство «ключ → название»:

```js
chart.names = {web: 'Сайт', shop: 'Магазин', partners: 'Партнёры'};
```

Ряд без названия называется своим ключом.

### Что лежит по горизонтали

Атрибут `x-scale` у линейного графика решает, как читать поле `x`. По
умолчанию (`auto`) даты становятся временем, числа — числовой осью, всё
остальное — категориями в порядке данных. Датой считается текст ISO 8601
(`2026-01`, `2026-01-15`, `2026-11-04T09:40`) или объект `Date`. `time`,
`linear` и `category` задают ось явно.

### Пропуски

Пропущенное значение — `null`, пустая строка или слово вместо числа — это
пропуск, а не ноль:

- у линии — разрыв; `gaps="connect"` соединяет точки вокруг него;
- у столбцов — нет столбца, и в стопку он ничего не добавляет;
- у тепловой карты — пустая ячейка с пунктирной рамкой;
- у воронки — строка без полосы, и доля перехода через неё не считается;
- у карты — область без заливки с пунктирным контуром.

Строки, которые нарисовать нельзя (точка без одной из мер, свеча без одной
из цен), график пропускает, а описание говорит, сколько таких строк.

## Почему так

Данные продукта приходят из двух мест. База отдаёт длинные строки — там ряд
это поле. Электронная таблица отдаёт широкие — там ряд это столбец. Поэтому
график принимает обе формы, а не заставляет страницу переделывать данные под
каждый вид графика. Пропуск остаётся пропуском, потому что ноль — это
тоже значение: «продаж не было» и «данных нет» — разные утверждения.

## Ограничения

- Числа нужны числами: `1234.5` или `"1234.5"`. Оформленная строка
  `"1 234,5 ₽"` читается как пропуск. Как показать число красиво, говорит
  формат — см. [Форматы чисел и дат](../../recipes/formats/).
- График не складывает и не группирует данные. Если тепловая карта получила
  одну пару дважды, остаётся последнее значение; сумму готовит страница или
  сервер.
- Рисунок может упрощаться при большом числе точек, но таблица всегда держит
  все строки — см. [Большие данные](../../large-data/).
