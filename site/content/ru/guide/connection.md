# Подключение

Страница подключает SIMAI Framework и называет наборы, которые использует.
Loader — загрузчик SIMAI Framework — сам находит набор, загружает его
правила и подгружает только те графики, которые есть на странице.

## Одна строка

```html
<script src="https://cdn.jsdelivr.net/npm/@simai-studio/ui@5.20261107.829/distr/core/js/core.min.js" data-sf-sets="chart"></script>
```

Атрибут `data-sf-sets` перечисляет наборы через пробел. Без версии Loader
выбирает по общему индексу совместимости самый новый выпуск набора,
который подходит к подключённому Core — ядру SIMAI Framework.

**Версия 1.0.2.** Все девятнадцать графиков в ней — предварительные версии 0.x: их настройки ещё могут меняться между
выпусками.

## Из своей копии

Если страница раздаёт сборку набора сама — со своего сервера или из своей
сборки сайта, — она указывает адрес до запуска Core:

```html
<script>
  window.SF_BOOT_CONFIG = {
    packages: {
      chart: {base: '/assets/ui-chart/smart/'}
    }
  };
</script>
<script src="/assets/ui/distr/core/js/core.min.js"></script>
```

`base` — папка `smart/` сборки набора: в ней лежат `rule.js` и папки
графиков. Этот сайт подключает набор именно так, из своей сборки.

## Графики на странице

После подключения графики пишут обычной разметкой:

```html
<sf-chart-bar label="Продажи по городам, 2026" x="city" y="q1,q2"></sf-chart-bar>
```

Данные передают свойством `items` или JSON-блоком в разметке — см.
[Основы](../concepts/) и страницы [компонентов](/ru/components/).

## Из npm

Набор опубликован в npm как `@simai-studio/chart`. Пакет нужен,
когда страница раздаёт файлы набора со своего сервера или собирает их своей
сборкой: из него берут папку `smart/` и указывают её в `SF_BOOT_CONFIG`, как
в разделе [Из своей копии](#из-своей-копии).

## Версии и совместимость

Версия набора — версия его npm-пакета. Каждый выпуск собирается и
проверяется ровно над одним выпуском SIMAI Framework и называет
наименьший Core, с которым работает.

| Набор | Состояние | Собран над SIMAI Framework | Нужен Core |
|:---|:---|:---|:---|
| 1.0.2 (2026-11-07) | графики 0.x, предварительные | `ui-b58b5dec35e4` (npm `@simai-studio/ui@5.20261107.829`) | `core.runtime` 1.25.0 или новее |
| 1.0.1 (2026-11-07) | те же графики | `ui-1ec283e856cd` (npm `@simai-studio/ui@5.20261106.1926`) | `core.runtime` 1.25.0 или новее |
| 1.0.0 (2026-11-06) | те же графики | `ui-e7b79c3a9e05` (npm `@simai-studio/ui@5.20261105.2041`) | `core.runtime` 1.25.0 или новее |

Версии каждого графика — в [истории изменений](../changes/). Закрепите версию набора в рабочем сайте: обновление станет вашим решением,
а не случайностью. Как переходить на новую версию — в разделе
[Обновление](../upgrading/).

Наборы не зависят друг от друга: SIMAI Chart не требует других наборов.

## Лицензия

SIMAI Chart распространяется по лицензии SIMAI Pro, общей для платных
наборов:

- бесплатно для малого бизнеса — PolyForm Small Business 1.0.0;
- бесплатно для некоммерческого использования — PolyForm Noncommercial 1.0.0;
- остальным — коммерческая лицензия SIMAI (SIMAI Commercial License) по
  запросу.

Использование в составе Larena — системы управления сайтом SIMAI —
покрывает лицензия самой Larena.

Автор и правообладатель — Рим Забаров. Сам SIMAI Framework распространяется
по лицензии Apache-2.0.
