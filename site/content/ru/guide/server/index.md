# Серверная часть

Графики набора не ходят в сеть и не знают, на чём написан сервер. Им нужен
только список записей — `items`. Сервер отдаёт его одним из двух способов:
адресом, который отвечает JSON, или JSON-блоком прямо в разметке страницы.

## Начните здесь

:::diagram {engine=mermaid title="Путь данных"}
sequenceDiagram
  participant C as sf-chart-line
  participant P as Скрипт страницы
  participant S as Сервер
  P->>C: data-state="loading"
  P->>S: GET /api/sales?year=2026
  S-->>P: [{"month": "2026-01", "sales": 120}, …]
  P->>C: items = ответ, data-state="auto"
:::

Что сервер делает всегда, на любой платформе:

- **проверяет права** — в ответ попадают только те данные, которые этому
  человеку положено видеть;
- **считает сам** — суммы по месяцам, доли, медианы для `stats="given"`:
  график не складывает и не группирует записи;
- **отдаёт числа числами**, даты — в ISO 8601 (`2026-01`, `2026-01-15`),
  пропуск — `null`, а не ноль;
- **ограничивает объём** — отдаёт столько строк, сколько нужно показать.

## Платформы

- [Обычный REST](rest/) — любой сервер, который отвечает JSON; пример на
  простом PHP.
- [Laravel и Larena](laravel/) — маршрут Laravel, который возвращает JSON.
- [1С-Битрикс](bitrix/) — контроллер модуля и вызов из страницы.
