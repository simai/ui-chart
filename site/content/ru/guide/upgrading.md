# Обновление

Набор выпускается с 1.0.0, текущая версия — 1.0.2. Графики в нём — предварительные версии 0.x,
и между версиями их настройки ещё могут меняться. Каждый выпуск набора
собран и проверен над одним выпуском SIMAI Framework, а обновление — это
смена номера в строке подключения.

## Перед началом

- Прочитайте [историю изменений](../changes/): что изменилось в графиках,
  которые есть на ваших страницах.
- Посмотрите в таблице [версий и совместимости](../connection/#версии-и-совместимость),
  какой Core нужен набору.

## Шаги

1. Найдите на своих страницах прежние имена тегов. 2026-11-02 графики
   первого уровня получили имена по общему правилу SIMAI Framework
   `sf-[набор]-<блок>[-<вариант>]`, блок `chart`:

   | Сейчас | Прежде |
   |:---|:---|
   | `<sf-chart-line>` | `<sf-line-chart>` |
   | `<sf-chart-bar>` | `<sf-bar-chart>` |
   | `<sf-chart-pie>` | `<sf-pie-chart>` |
   | `<sf-chart-sparkline>` | `<sf-sparkline>` |
   | `<sf-chart-parts>` | `<sf-parts-bar>` |
   | `<sf-chart-metric>` | `<sf-metric>` |

2. Замените их новыми. Переименование было до любого выпуска, поэтому
   прежних имён нет совсем: старый тег не работает и ни во что не
   превращается. Вместе с тегами так же переименованы события
   (`sf-chart-bar-select`), правила Loader (`cl-chart-bar`), классы и
   публичные CSS-переменные (`--sf-chart-bar-height`).

3. Сверьте настройки с [историей изменений](../changes/): пока версии 0.x,
   у графика могут появиться новые настройки и измениться значения по
   умолчанию.

4. Закрепите версию набора в рабочем сайте — тогда новая версия придёт
   только тогда, когда вы её выберете:

   ```html
   <script src="https://cdn.jsdelivr.net/npm/@simai-studio/ui@5.20261107.829/distr/core/js/core.min.js" data-sf-sets="chart@1.0.2"></script>
   ```

5. Пройдите свои экраны: данные, легенду, подсказку, клавиатуру, таблицу и
   обе темы.

## Результат

На страницах только имена `sf-chart-*`, и каждый график показывает свои
данные. Номер версии в строке подключения меняется вашим решением.
