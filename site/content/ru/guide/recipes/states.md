# Загрузка, пусто и ошибка

У графика четыре состояния данных: `loading` — данные идут, `ready` —
график нарисован, `empty` — данных нет, `error` — загрузить не удалось.
Состояние задаёт страница атрибутом `data-state`; по умолчанию (`auto`)
график сам выбирает между `ready` и `empty` по тому, есть ли данные.

## Перед началом

- Данные загружает страница — см. [Данные с сервера](../load-from-server/).

## Шаги

1. Перед запросом поставьте `data-state="loading"`. График рисует рамку
   той же высоты без отметок — когда данные придут, ничего не сдвинется:

   ```js
   chart.setAttribute('data-state', 'loading');
   ```

2. Когда данные пришли, отдайте их в `items` и верните `auto`. С записями
   будет график, с пустым списком — «Нет данных»:

   ```js
   chart.items = rows;
   chart.setAttribute('data-state', 'auto');
   ```

3. Если запрос не удался, поставьте `data-state="error"`. График покажет
   ошибку с кнопкой «Повторить».

4. Ответьте на повтор. Кнопка отправляет событие
   `sf-chart-<имя>-refresh` — у столбцов это `sf-chart-bar-refresh`.
   Загрузите данные снова:

   ```js
   chart.addEventListener('sf-chart-bar-refresh', () => load());
   ```

5. У плитки и мини-графика своё поведение:

   - `sf-chart-metric` знает `auto`, `loading` и `empty`; без значения
     пишет «—». Ошибку загрузки страница показывает статусом:
     `status="error"` и подсказка `hint`.
   - `sf-chart-sparkline` без данных рисует пунктирную линию и «нет
     данных», в загрузке держит размер тихим блоком. Ошибку показывает
     окружение — таблица или плитка, в которой он стоит.

## Результат

Переключите состояние кнопками над графиком. В состоянии «Ошибка» нажмите
«Повторить» — страница загрузит данные снова.
