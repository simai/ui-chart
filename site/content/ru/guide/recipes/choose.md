# Как выбрать график

График выбирают не по виду, а по вопросу, на который он отвечает. Один и тот
же список продаж можно нарисовать линией, столбцами или кругом, но верно
ответит на вопрос только один из них.

## Перед началом

- Сформулируйте вопрос одной фразой: «как менялись продажи за год»,
  «какой канал приносит больше заказов».
- Посмотрите на данные: сколько в них рядов, категорий и строк, есть ли
  время.

## Шаги

1. Найдите свой вопрос в таблице и возьмите компонент из второй колонки.

   | Вопрос | График |
   |:---|:---|
   | **Как меняется во времени?** | [`sf-chart-line`](/ru/components/trends/chart-line/) — один или несколько рядов, стопка площадей |
   | …одно значение в строке таблицы или в плитке | [`sf-chart-sparkline`](/ru/components/trends/chart-sparkline/) — мини-график без осей |
   | …цена за период: открытие, максимум, минимум, закрытие | [`sf-chart-candlestick`](/ru/components/trends/chart-candlestick/) |
   | **Из чего состоит целое?** | [`sf-chart-pie`](/ru/components/parts/chart-pie/) — несколько частей одного целого |
   | …занято из ёмкости: диск, квота, бюджет | [`sf-chart-parts`](/ru/components/parts/chart-parts/) — полоса со свободным остатком |
   | …много частей, части в группах | [`sf-chart-treemap`](/ru/components/parts/chart-treemap/) |
   | …иерархия в несколько уровней | [`sf-chart-sunburst`](/ru/components/parts/chart-sunburst/) |
   | …как начальное значение стало конечным | [`sf-chart-waterfall`](/ru/components/trends/chart-waterfall/) — рост и падение по шагам |
   | …доли по месяцам или категориям | [`sf-chart-bar`](/ru/components/trends/chart-bar/) с `stack="normalized"` |
   | **Как связаны две меры?** | [`sf-chart-scatter`](/ru/components/relations/chart-scatter/) — точки, третья мера пузырьками |
   | …как распределена одна мера | [`sf-chart-bar`](/ru/components/trends/chart-bar/) с `bin` — гистограмма |
   | …как разбросана мера по группам | [`sf-chart-box`](/ru/components/relations/chart-box/) — ящик с усами |
   | …два-три объекта по нескольким мерам одной шкалы | [`sf-chart-radar`](/ru/components/relations/chart-radar/) |
   | **Как идёт процесс?** | [`sf-chart-funnel`](/ru/components/flows/chart-funnel/) — этапы и конверсия между ними |
   | …куда перетекает величина | [`sf-chart-sankey`](/ru/components/flows/chart-sankey/) |
   | …задачи и состояния во времени | [`sf-chart-timeline`](/ru/components/flows/chart-timeline/) — диаграмма Ганта |
   | **Где больше?** | [`sf-chart-bar`](/ru/components/trends/chart-bar/) — по категориям; `orientation="horizontal"` для рейтинга |
   | …по двум категориям: дни и часы, команды и недели | [`sf-chart-heatmap`](/ru/components/grids/chart-heatmap/) |
   | …по областям на карте | [`sf-chart-map`](/ru/components/grids/chart-map/) |
   | **Одно число** | [`sf-chart-metric`](/ru/components/indicators/chart-metric/) — с изменением, пределом и статусом |
   | …на шкале с зонами нормы и целью | [`sf-chart-gauge`](/ru/components/indicators/chart-gauge/) |

2. Проверьте, что график не попал в свой «не подходит»:

   - **круговая** — для нескольких частей: сверх `max-parts` (по умолчанию 7)
     самые маленькие сводятся в «Другое»; точно сравнить части проще
     столбцами;
   - **карта** — для доли или показателя на душу, а не для количества:
     большие области кажутся «больше»; количество — столбцами;
   - **радар** — для мер одной шкалы; рубли рядом с процентами — это
     столбцы рядом;
   - **точечная** — не для ряда во времени: это линия;
   - **свечной** — для тех, кто читает цены; широкой публике понятнее линия
     цен закрытия;
   - **каскадный** — для шагов, которые складываются; независимые значения
     — это столбцы;
   - **шкала** — для измеренного значения, а не прогресса задачи: прогресс
     показывают `sf-progress-bar`, `sf-progress-ring` и `sf-progress-scale`
     SIMAI Framework.

3. Посмотрите живые примеры на странице выбранного компонента и сверьте
   форму данных: какие поля он читает и что делает с пропусками.

4. Поставьте график со своими данными и откройте таблицу кнопкой
   «Таблица». Если в таблице то, что вы хотели показать, а описание
   отвечает на ваш вопрос — график выбран верно.

## Результат

У вас график, который отвечает на один вопрос. Если вопросов два —
«как менялись продажи» и «какой канал главный», — поставьте два графика,
а не один сложный.
