# Быстрый старт

За пять минут вы соберёте страницу с линейным графиком: продажи и план по
месяцам, легенда, подсказка, курсор с клавиатуры и таблица. Понадобятся
только текстовый редактор и браузер — ни npm, ни сборка не нужны.

## Перед началом

- Браузер последних версий: Chrome, Edge, Firefox или Safari.
- Доступ в интернет: SIMAI Framework и набор загружаются с jsDelivr.
- Набор ещё не выпущен. Строка подключения из первого шага заработает с
  первого выпуска набора. До него результат этих шагов можно посмотреть в
  живом примере внизу страницы.

## Шаги

1. Создайте файл `index.html` и подключите SIMAI Framework с набором
   `chart` одной строкой. Атрибут `data-sf-sets="chart"` говорит
   Loader — загрузчику SIMAI Framework, — что странице нужен набор
   SIMAI Chart:

   ```html
   <!doctype html>
   <html lang="ru">
   <head>
     <meta charset="utf-8">
     <meta name="viewport" content="width=device-width, initial-scale=1">
     <title>Продажи</title>
     <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@simai-studio/ui@5.20261105.2041/distr/core/css/core.min.css">
   </head>
   <body class="p-4">
     <script src="https://cdn.jsdelivr.net/npm/@simai-studio/ui@5.20261105.2041/distr/core/js/core.min.js" data-sf-sets="chart"></script>
   </body>
   </html>
   ```

2. Поставьте график в `<body>`, перед строкой со скриптом. Атрибут `label`
   — что показывает график, в нескольких словах. Это его имя для экранного
   диктора и подпись таблицы; без него график называется просто «График».
   `x` называет поле месяцев, `y` — поля двух рядов через запятую:

   ```html
   <sf-chart-line id="sales" label="Продажи и план, 2026" x="month" y="sales,plan" y-format="integer"></sf-chart-line>
   ```

3. Дайте графику данные. Компонент загружается сам, поэтому сначала
   дождитесь его готовности — `customElements.whenDefined`. Списки и
   объекты передают свойствами элемента:

   ```html
   <script>
     customElements.whenDefined('sf-chart-line').then(() => {
       const chart = document.querySelector('#sales');
       chart.names = {sales: 'Продажи', plan: 'План'};
       chart.items = [
         {month: '2026-01', sales: 120, plan: 125},
         {month: '2026-02', sales: 132, plan: 130},
         {month: '2026-03', sales: 128, plan: 135},
         {month: '2026-04', sales: 150, plan: 145},
         {month: '2026-05', sales: 171, plan: 160},
         {month: '2026-06', sales: 165, plan: 165},
       ];
     });
   </script>
   ```

   `items` — записи, по одной на месяц. `names` — как называть ряды в
   легенде, подсказке и таблице. Месяцы записаны как `2026-01`, поэтому
   график сам понимает, что по горизонтали время. `y-format="integer"`
   печатает значения целыми числами на языке страницы.

4. Откройте `index.html` в браузере. Наведите указатель на график —
   подсказка покажет продажи и план за месяц. Нажмите в легенде «План» —
   ряд скроется, нажмите ещё раз — вернётся.

5. Нажмите `Tab`, чтобы перейти на график, и пройдите месяцы стрелками
   `←` и `→`; `↓` переводит курсор на другой ряд. Кнопка «Таблица»
   показывает те же данные таблицей.
