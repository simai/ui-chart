# SIMAI Chart

Smart chart components for [SIMAI Framework](https://ui.simai.io/): line, bar,
area, pie and the other charts a product needs, built the same way as every
other Smart component and loaded by the same Loader.

- Tags: `sf-chart-*` (one prefix `sf-`, one registry of names with the
  Framework and SIMAI Pro).
- Delivery: the component set `chart` (standard `simai.component-set`
  1.0.0; passport [`package/set.json`](package/set.json)), built over one
  pinned SIMAI Framework release. A page connects it in one line,
  `data-sf-sets="chart"` on the SIMAI Framework script.
- Source: [`package/`](package/README.md), the set.
- Site: [`site/`](site/README.md), the documentation and demonstration
  site (Docara), local only.

Nineteen charts, all 0.x previews, made the first release of the set,
1.0.0; the current one is 1.0.2 (npm `@simai-studio/chart`, [changelog](package/CHANGELOG.md)). See
[docs/STATUS.md](docs/STATUS.md) for the state and
[docs/START.md](docs/START.md) for how the work began.
