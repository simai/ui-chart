# Smart Box Plot

`<sf-chart-box>` — ящик с усами: как разбросана одна мера по группам. Для
каждой группы — медиана, середина значений (от нижнего до верхнего
квартиля), усы и выбросы. Ряды рядом в группе, легенда, которая скрывает
ряды, подсказка, курсор с клавиатуры, описание словами и та же статистика
таблицей.

Подходит, чтобы сравнить группы: время доставки по складам, зарплаты по
отделам. Форму одной группы лучше показывает гистограмма (`sf-chart-bar` с
`bin`), а меньше пяти значений в группе — сами точки (`sf-chart-scatter`).

## Данные

`items` — свойство: список записей или объект столбцов.

- `x` — поле групп (по умолчанию первое), в порядке, в каком группы
  встречаются в данных;
- `y` — поле меры (по умолчанию первое числовое, кроме `x` и `series`);
- `series` — ряды: свой ящик для каждого значения этого поля, рядом в группе.

`stats` говорит, что лежит в строках:

- `raw` (по умолчанию) — каждая строка одно наблюдение (заказ, сотрудник);
  график сам считает медиану, квартили, усы и выбросы. Квартили — линейно
  между двумя ближайшими значениями, как в таблицах Excel и Google.
- `given` — каждая строка одна группа с готовыми полями `min`, `q1`,
  `median`, `q3`, `max` (и `mean`), например посчитанными на сервере. Усы
  тогда до `min` и `max`, выбросов нет. Строка без одного из полей или с
  полями не по порядку пропускается.

Строка без значения не попадает в расчёт; описание говорит, сколько таких.

```html
<sf-chart-box id="delivery" label="Время доставки по складам" x="warehouse" y="hours"
  x-label="Склад" y-label="Часов в пути" y-format="integer"></sf-chart-box>
<script>
  delivery.items = [
    {warehouse: 'Москва', hours: 18},
    {warehouse: 'Казань', hours: 27},
    // …
  ];
</script>
```

## Вид

- `whiskers` — `tukey` (по умолчанию): ус доходит до самого дальнего
  значения в пределах полутора высот ящика, значения дальше — выбросы,
  кружки на линии ящика. `range`: усы до самого малого и самого большого
  значения, выбросов нет.
- `mean` — ромбик на среднем; среднее есть и в подсказке, и в таблице.
- `y-min`, `y-max`, `y-zero` — границы оси значений; по умолчанию ось по
  данным.
- `grid` — `value` (линии на делениях) или `none`; `y-format`, `x-label`,
  `y-label`, `legend`, `size` — как у других графиков пакета.
- Длинное название группы сокращается многоточием, полное — в подсказке и
  таблице.

## Цвета

`colors` и `palette` — как у `sf-chart-bar`: роль Framework (`primary`,
`neutral`…) или любой CSS-цвет по ключу ряда, либо готовый набор. Ряд
узнаётся и без цвета: по месту в группе, как в легенде, а в режиме высокой
контрастности — по штриху обводки ящика.

## Клавиатура и доступность

График — одна остановка Tab. Стрелки влево и вправо идут от группы к
группе, вверх и вниз — по рядам в группе. Home и End — к краям, Page Up и
Page Down — на десятую часть. Каждый шаг звучит: «Москва: медиана 18,
квартили 15 – 21, усы 12 – 24, выбросов 1». Enter и пробел выбирают ящик
(`sf-chart-box-select`), Escape убирает курсор.

Фраза о данных («Групп: 4, значений: 36. Часов в пути: медиана выше всего —
Пермь (36)…») — описание графика для чтения с экрана. Таблица всегда есть:
кнопкой (`table="toggle"`), под графиком (`visible`) или только для чтения с
экрана (`hidden`). В ней по строке на ящик: число значений, пять чисел,
среднее (с `mean`) и сами выбросы.

## События, действия и значения

- `sf-chart-box-toggle` `{id, hidden}` — ряд скрыт или показан кнопкой
  легенды; `hiddenSeries` — ключи скрытых рядов.
- `sf-chart-box-select` `{series, index, group, median}` — выбран ящик.
- `sf-chart-box-refresh` — повтор из состояния ошибки.
- `reset()` — показать все ряды и убрать курсор.

## Состояния

`data-state`: `auto` (с данными — график, без — «Нет данных»), `loading`
(рамка той же высоты), `empty`, `error` (с «Повторить»).

## Переменные CSS

`--sf-chart-box-height`, `--sf-chart-box-grid-color`,
`--sf-chart-box-baseline-color`, `--sf-chart-box-label-color`,
`--sf-chart-box-hover-background-color`, `--sf-chart-box-hidden-color`.
