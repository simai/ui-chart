# Smart Sunburst

`<sf-chart-sunburst>` — солнечные круги: иерархия кольцами вокруг центра.
Внутреннее кольцо — верхний уровень, каждое следующее — уровень глубже,
а дуга занимает долю от дуги родителя. Например, выручка по направлениям,
а внутри направлений — по товарам; место на диске по папкам. В центре —
общая сумма. Подсказка, курсор с клавиатуры, описание словами и все части
таблицей.

Не подходит, когда размеры нужно сравнить точно: это `sf-chart-bar` или
`sf-chart-treemap`. Отрицательные значения дуга не покажет.

## Данные

`items` — свойство: список записей или объект столбцов. Два способа задать
иерархию.

**Узел и родитель.** Строка — узел со своим `id` и `parent`.

- `node` — поле id узла, по умолчанию `id`. (Настройка называется не `id`:
  это собственный атрибут элемента.)
- `parent` — поле родителя, по умолчанию `parent`. Узел, чей родитель не
  найден среди id, становится верхним.
- `name` — поле названия на дуге; по умолчанию сам id.

**Путь.** Строка — конечная часть со своим путём, списком названий сверху
вниз: `{path: ['Фото', '2026', 'Отпуск'], size: 35}`. Промежуточные узлы
создаются сами, один и тот же путь дважды складывается.

- `path` — поле пути. Без `node` и `parent` поле со списком находится само.

**Значения.**

- `value` — поле величины. По умолчанию первое числовое поле, кроме id,
  родителя и пути.
- Значение родителя — его собственное плюс значения детей. Собственное
  остаётся пустым местом после детей на следующем кольце.
- Строка без id или пути, узел без положительного значения и без детей,
  повторный id и цепочка родителей, которая замыкается в круг,
  пропускаются; описание говорит, сколько таких.

```html
<sf-chart-sunburst id="revenue" label="Выручка по направлениям, млн ₽"
  y-format="integer"></sf-chart-sunburst>
<script>
  revenue.items = [
    {id: 'Электроника'},
    {id: 'Смартфоны', parent: 'Электроника', value: 420},
    {id: 'Ноутбуки', parent: 'Электроника', value: 310},
    {id: 'Дом'},
    {id: 'Мебель', parent: 'Дом', value: 260},
  ];
</script>
```

## Вид

- Верхние узлы делят круг по часовой стрелке от двенадцати часов, крупные
  первыми; ребёнок занимает часть угла родителя по своей доле.
- Кольца делят радиус поровну, внутри — отверстие с общей суммой (когда
  она в нём помещается).
- Название пишется по середине дуги, в нижней половине круга
  перевёрнутым, чтобы читалось. Оно обрезается многоточием по месту в дуге.
  Слишком маленькая дуга остаётся без подписи: её слова — в подсказке и
  таблице. `labels="none"` убирает подписи всегда.
- `y-format` и `size` — как у других графиков пакета. Доли всегда в
  процентах.

## Цвета

Верхний узел берёт цвет графиков Framework по своему месту, а вся его ветвь
сохраняет этот цвет: светлая заливка с линией цвета вокруг каждой дуги,
дальше первого кольца — светлее. Названия пишутся цветом текста страницы.
`colors` — свойство `{верхний узел: цвет}`: роль Framework или любой
CSS-цвет. В режиме высокой контрастности дуги — цвета фона с линией цвета
текста.

## Клавиатура и доступность

График — одна остановка Tab. Курсор ходит по дугам: вправо и влево — по
кольцу (вправо — по часовой стрелке, по кругу), вниз — наружу к самому
крупному ребёнку, вверх — назад к родителю, Home и End — к первой и
последней дуге кольца. Каждая дуга звучит с путём и долями: «Дом /
Мебель: 260; 59,1 % от «Дом», 14,7 % всего». Enter и пробел выбирают дугу
(`sf-chart-sunburst-select`), Escape убирает курсор. Указатель тоже
показывает дугу.

Фраза о данных — число уровней и частей, общая сумма, крупнейшая ветвь и
крупнейшая конечная часть с долями, пропущенные строки. Таблица всегда
есть, строка на узел, каждая ветвь под своим родителем: кнопкой
(`table="toggle"`), под графиком (`visible`) или только для чтения с
экрана (`hidden`).

## События и действия

- `sf-chart-sunburst-select` `{index, node, name, path, depth, value,
  share}` — выбрана дуга; `index` — её место в порядке клавиатуры (кольцо
  за кольцом, по часовой), `node` — id, `path` — названия сверху вниз,
  `depth` — кольцо с нуля, `share` — доля всего, от 0 до 1.
- `sf-chart-sunburst-refresh` — повтор из состояния ошибки.
- `reset()` — убрать курсор.

## Состояния

`data-state`: `auto` (с данными — график, без — «Нет данных»), `loading`
(рамка той же высоты), `empty`, `error` (с «Повторить»).

## Переменные CSS

`--sf-chart-sunburst-height`, `--sf-chart-sunburst-label-color` (сумма в
центре), `--sf-chart-sunburst-hover-background-color`.

Приближение к ветви, легенда и ручная расстановка дуг в 0.1.0 не входят.
