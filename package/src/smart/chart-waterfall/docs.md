# Smart Waterfall Chart

`<sf-chart-waterfall>` — каскадный график: как начальное значение
превращается в конечное через шаги роста и снижения. Например, мост
прибыли от прошлого года к этому. Подсказка, курсор с клавиатуры, описание
словами и те же данные таблицей.

Не подходит для независимых значений, которые не складываются: их рисует
`sf-chart-bar`. Изменение по многим периодам лучше показывает
`sf-chart-line`.

## Данные

`items` — свойство: список записей или объект столбцов, строка на шаг.

- `x` — поле названия шага. По умолчанию первое поле, кроме значения и
  отметки итога.
- `y` — поле значения: на шаге это изменение (плюс или минус), на итоговой
  строке — сам итог. По умолчанию первое числовое поле.
- `total` — поле отметки итога (`true`, `1`, «yes» или «да»); по умолчанию
  `total`. Итог стоит на нуле. Без значения он показывает накопленную
  сумму, со значением — сумма дальше считается от него, как от начального
  остатка.
- Шаг без значения пропускается; описание говорит, сколько таких.

```html
<sf-chart-waterfall id="bridge" label="Выручка: 2025 → 2026" x="step" y="value"
  y-label="млн ₽" y-format="integer"></sf-chart-waterfall>
<script>
  bridge.items = [
    {step: 'Выручка 2025', value: 820, total: true},
    {step: 'Новые клиенты', value: 240},
    {step: 'Отток', value: -130},
  ];
</script>
```

## Вид

- Шаг висит от прежней суммы до новой, итог стоит на нуле. Тонкая линия
  соединяет конец каждого столбца с началом следующего.
- В конце сам добавляется итог «Итого», если последняя строка не итог.
  `end="none"` его убирает.
- На каждом столбце написано его значение: изменение со знаком («+240»,
  «−130»), итог — как есть. Если хоть одна подпись не помещается в свою
  полосу, подписей нет совсем. `value-labels="none"` убирает их всегда.
- Ось значений всегда включает ноль: итог — это сумма.
- `y-format`, `x-label`, `y-label`, `grid`, `size` — как у других
  графиков пакета.
- Горизонтальный вид и шаги из нескольких частей в 0.1.0 не рисуются.

## Цвета

По умолчанию рост — тон роли `success`, снижение — `error`, итог —
`neutral`; они меняются со светлой и тёмной темой. `colors` — свойство
`{up, down, total}`: роль Framework или любой CSS-цвет. Знак у значения
остаётся при любом цвете. В режиме высокой контрастности рост — полый
столбец, снижение — залитый, итог — пунктирный.

```html
<script>
  bridge.colors = {up: 'primary', down: 'warning', total: 'secondary'};
</script>
```

## Клавиатура и доступность

График — одна остановка Tab. Стрелки влево и вправо идут от шага к шагу,
Home и End — к краям, Page Up и Page Down — на десятую часть. Каждый шаг
звучит: «Новые клиенты: +240, итог 1 060», итог — «Итого: 1 000». Enter и пробел выбирают шаг
(`sf-chart-waterfall-select`), Escape убирает курсор.

Фраза о данных — число шагов, начальное и конечное значение с изменением,
шаг, который прибавил больше всех, и шаг, который больше всех убавил,
сколько шагов было в плюс и в минус. Таблица всегда есть: кнопкой
(`table="toggle"`), под графиком (`visible`) или только для чтения с экрана
(`hidden`).

## События и действия

- `sf-chart-waterfall-select` `{index, row, x, kind, value, total}` — выбран
  шаг; `index` — его место среди столбцов, `row` — строка в `items` (`-1`
  у добавленного итога), `kind` — `up`, `down` или `total`, `value` —
  изменение (у итога — сам итог), `total` — сумма после шага.
- `sf-chart-waterfall-refresh` — повтор из состояния ошибки.
- `reset()` — убрать курсор.

## Состояния

`data-state`: `auto` (с данными — график, без — «Нет данных»), `loading`
(рамка той же высоты), `empty`, `error` (с «Повторить»).

## Переменные CSS

`--sf-chart-waterfall-height`, `--sf-chart-waterfall-grid-color`,
`--sf-chart-waterfall-baseline-color`, `--sf-chart-waterfall-label-color`,
`--sf-chart-waterfall-hover-background-color`.
